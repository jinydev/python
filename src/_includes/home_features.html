💡
CS 기반 원리 탐구

단순한 API 호출이 아닌 메모리 주소, 참조 카운팅, 가비지 컬렉션의 동작 원리를 명확하게 이해합니다.

객체지향(OOP) 설계

단일 책임 원칙, 디자인 패턴, 추상화와 캡슐화를 통해 유지보수 가능한 소프트웨어 아키텍처를 세웁니다.

실전 시스템 & 비동기

GUI 앱, SQLite 데이터베이스, 소켓 네트워크와 AsyncIO 비동기 이벤트 루프를 융합하여 실전 서비스를 구현합니다.

PEP 8 & 클린 코드
