# PART 10 데이터의 이름표와 변하지 않는 약속: 딕셔너리와 튜플

리스트가 데이터를 한 줄로 나란히 세워 순서대로 관리하는 파일 철이라면, 이번에 배울 **딕셔너리(Dictionary)**는 이름표(라벨)를 붙여 데이터를 쏙쏙 뽑아 쓰는 고급 수납장입니다. 그리고 한 번 정하면 절대 바꿀 수 없는 강력한 약속인 **튜플(Tuple)**까지, 파이썬의 필수 자료형 삼총사를 모두 완성해 보겠습니다.

# 28 이름표로 부르는 수납장: 딕셔너리

리스트에서는 데이터를 찾을 때 `0번`, `1번` 같은 방 번호(인덱스)로 데이터를 가져왔습니다. 하지만 "홍길동의 전화번호"를 찾을 때 몇 번째 방인지 기억하는 것은 어렵습니다. 방 번호 대신 '홍길동'이라는 이름표(키, Key)로 직관적으로 데이터를 뽑아 쓰고 싶을 때 바로 딕셔너리를 사용합니다.

**코드: 딕셔너리 만들기**
```python
# 중괄호 {} 를 사용하여 딕셔너리를 만듭니다.
# '키': '값' 의 세트로 묶어주며 쉼표로 연결합니다.
contact = {
    '홍길동': '010-1234-5678',
    '파이썬': '010-9876-5432'
}

# 값을 꺼낼 때는 대괄호 안에 방 번호 대신 '이름표(키)'를 적습니다.
print(contact['파이썬'])
```

**실행 결과**
```text
010-9876-5432
```
정말 마법처럼 이름표 하나만으로 정확한 데이터를 척척 가져옵니다. 
키(Key)에는 문자열이나 숫자 모두 쓸 수 있고, 값(Value)쪽에는 리스트처럼 다른 복잡한 데이터도 마음껏 담을 수 있습니다.

# 29 딕셔너리 요리하기 (수정, 추가, 삭제)

딕셔너리 역시 리스트만큼이나 유연해서 내용을 쉽게 바꾸고 지울 수 있습니다.
그런데 리스트처럼 `.append()` 같은 함수를 쓰지 않습니다. 더 직관적인 방법을 씁니다.

### 1. 수정 및 추가하기
새로운 이름표에 값을 쓱 밀어 넣으면, 파이썬이 알아서 자리를 만들어 줍니다. 이미 있는 이름표라면 예전 값을 쿨하게 덮어버립니다.

```python
monster_hp = {'슬라임': 10, '고블린': 50}

# 수정: 기존에 있던 고블린의 체력을 30으로 수정
monster_hp['고블린'] = 30

# 추가: 못 보던 드래곤 등장!
monster_hp['드래곤'] = 9999

print(monster_hp)
# 출력: {'슬라임': 10, '고블린': 30, '드래곤': 9999}
```

### 2. 삭제하기 (`del`, `pop()`)
지울 때도 특정 이름표만 콕 집어서 날려버릴 수 있습니다.

```python
# del 키워드를 써서 슬라임 파괴
del monster_hp['슬라임']

# pop() 함수를 쓰면 지우는 동시에 지운 값을 보여줍니다.
dragon_hp = monster_hp.pop('드래곤') 
```

# 30 딕셔너리와 for 반복문의 완벽한 조화

딕셔너리 안에 든 수십 개의 항목을 화면에 예쁘게 출력하려면 `for`문을 쓰면 완벽합니다. 단, 리스트와 달리 딕셔너리는 '키(Key)'와 '값(Value)'이라는 두 가지 요소가 있기 때문에 반복문을 돌리는 세 가지 방법이 존재합니다.

1. **키(Key)만 뽑기**: `for key in dict.keys():` (또는 그냥 `dict:`)
2. **값(Value)만 뽑기**: `for value in dict.values():`
3. **둘 다 뽑기**: `for key, value in dict.items():` (가장 자주 쓰입니다!)

**코드: 딕셔너리 순회하기**
```python
scores = {'국어': 90, '수학': 100, '영어': 85}

# .items()를 쓰면 과목(키)과 점수(값)가 동시에 튀어나옵니다.
for subject, point in scores.items():
    print(f'{subject} 과목의 점수는 {point}점 입니다!')
```

# 31 리스트 vs 딕셔너리 총정리

때로는 리스트를, 때로는 딕셔너리를 선택해야 합니다. 둘의 특징을 요약해 봅니다.

* **접근 방식**: 리스트는 `인덱스(0, 1)`, 딕셔너리는 `이름표('키')`.
* **데이터 추가**: 리스트는 `append()`, 딕셔너리는 `dict['새키'] = 값`.
* **데이터 합치기**: 리스트는 `+` 기호로 이어 붙이고, 딕셔너리는 `.update()` 함수로 덮어씌웁니다.

```python
# 딕셔너리의 update() 주의점: 키가 같으면 기존 값을 파괴(덮어쓰기)함
dict_A = {'사과': 1000}
dict_B = {'사과': 2000, '포도': 3000}

dict_A.update(dict_B)
print(dict_A) # {'사과': 2000, '포도': 3000}
```

# 32 절대 변하지 않는 단단한 상자: 튜플(Tuple)

파이썬에는 리스트와 똑같이 생겼는데 소괄호 `()`를 쓰는 자료형이 있습니다. 바로 **튜플(Tuple)**입니다.

튜플이 리스트와 결정적으로 다른 단 한 가지 특징은 **"한 번 만들면 절대 안에 있는 값을 바꿀 수도, 지울 수도 없다"**는 점입니다. 

```python
tup = (1, 2, 3)
print(tup[0]) # 1 출력 (거져오는 건 가능)

# 아래와 같이 수정이나 삭제를 시도하면 자비 없이 TypeError를 뿜어냅니다!
# tup[0] = 99 
# del tup[1]
```

괄호 없이 값을 나열하기만 해도 튜플로 취급되며, 1개짜리 튜플을 만들려면 반드시 뒤에 쉼표 `,`를 붙여야 합니다. `(1,)` 처럼 말이죠.

왜 굳이 수정도 안 되는 불편한 튜플을 쓸까요?
1. 절대로 변해선 안 되는 중요한 보안 데이터나 좌표 결괏값을 담을 때
2. 함수의 결괏값 등을 빠르고 가볍게 처리할 때

# 33 언패킹(Unpacking) 마술과 두 변수 맞바꾸기

튜플을 이용하면 아주 재미있고 세련된 파이썬만의 문법을 쓸 수 있습니다.
바로 여러 변수의 묶음을 한방에 풀고 조립하는 기능입니다.

**코드: 변수 값 맞바꾸기(Swap)**
```python
x = 10
y = 20

# 다른 언어라면 temp 라는 임시 변수를 써야 하지만, 파이썬은 튜플 덕분에 한 줄로 끝납니다!
x, y = y, x

print("x:", x, "/ y:", y)  # x: 20 / y: 10
```
이 밖에도 함수에서 한 번에 2개 이상의 값을 되돌려 줄(`return`) 때, 자동으로 튜플로 묶어서 반환(`Packing`)되고, 받을 때 여러 변수로 나눠 담는 것(`Unpacking`)도 이 튜플의 특징 덕분입니다.

# 34 튜플의 숨겨진 비기: 별표(*) 폭발 연산자

만약 튜플에 묶여있는 값들을 통째로 쪼개어 각각 전달하고 싶다면 튜플 변수 앞에 별표 `*`를 달아주면 펑! 하고 낱개로 쪼개집니다. 
이를 전문 용어로 Unpacking Operator 라고 부릅니다. 아주 유용한 스킬이니 눈에 익혀두세요!

**코드: 별표 연산으로 쪼개기**
```python
user_info = ("홍길동", "서울", "도적")

# 튜플을 통째로 넣지 않고, * 를 붙여서 각각의 자리 구멍에 맞춰 털어 넣습니다.
message = "이름: {}, 출신: {}, 직업: {}".format(*user_info)
print(message)
```

이로써 리스트부터 딕셔너리, 튜플에 이르기까지 파이썬의 핵심 3대 자료형을 모두 마스터했습니다. 데이터들을 자유롭게 묶고 이름표를 붙여보며 실력을 키워보세요!
