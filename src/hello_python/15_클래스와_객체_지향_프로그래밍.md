# PART 15 코드에 생명을 불어넣는 마법, 객체 지향 프로그래밍

지금까지 여러분은 변수에 데이터를 담고, 반복문과 조건문으로 데이터를 요리했습니다. 하지만 프로그램이 거대해지면 데이터와 기능이 뿔뿔이 흩어져 관리가 불가능해집니다.
그래서 등장한 것이 **객체 지향 프로그래밍(OOP)**입니다. 데이터(상태)와 기능(행동)을 하나로 단단하게 묶어서, 마치 살아있는 생명체(객체)처럼 설계하는 현대 프로그래밍의 핵심 기술을 배워 보겠습니다.

# 47 너의 정체가 무엇이냐? 자료형 검사기

파이썬의 세계에서는 모든 것이 저마다의 '소속(자료형, Type)'을 가지고 있습니다. 
숫자 10과 문자열 "10"은 사람 눈에는 비슷해 보여도 파이썬에게는 완전히 다른 종족입니다.

* **`type(값)`**: 데이터의 본래 근본(소속 클래스)을 까발립니다.
* **`isinstance(값, 자료형)`**: 데이터가 특정 소속인지 아닌지 맞다/틀리다(True/False)로 판별해 줍니다. 

**REPL 실습: 신분증 검사**
```python
>>> type("안녕")
<class 'str'> # 문자열(string)을 뜻합니다.
>>> type(3.14)
<class 'float'> # 소수(부동소수점)를 뜻합니다.
>>> isinstance(100, int)
True # 100은 정수(int)가 맞습니다!
>>> isinstance(100, float)
False # 100은 소수가 아닙니다! (100.0 이 소수입니다.)
```

# 48 붕어빵 틀(클래스)과 붕어빵(인스턴스)

우리가 평소에 썼던 `[1, 2, 3]` 같은 리스트는 사실 파이썬이 미리 만들어둔 `list`라는 거대한 '붕어빵 틀(클래스)'에서 구워져 나온 '하나의 붕어빵(인스턴스)'입니다.

* **클래스 (Class)**: 설계도, 틀 (예: '인간'이라는 종족)
* **인스턴스 (Instance)**: 설계도를 통해 실제로 화면에 태어난 실체 (예: '나', '너', '스티브 잡스')

**REPL 실습: == 와 is 의 차이**
```python
>>> a = [1, 2, 3]
>>> b = [1, 2, 3]
>>> a == b 
True # 값(내용물)이 똑같다는 뜻입니다. (같은 단팥 붕어빵이다)
>>> a is b
False # 하지만 물리적으로 일치하는 녀석은 아닙니다. (a를 베어 먹었다고 b가 줄어들지 않습니다)
```

# 49 & 50 나만의 붕어빵 틀 만들기 (모델링)

이제 우리도 파이썬이 만들어둔 틀(`list`, `str`) 말고, 내가 직접 세상의 사물을 코드로 찍어내는 틀(`class`)을 조각해 볼 시간입니다.
RPG 게임의 '몬스터'를 설계(모델링)해 보겠습니다.

**코드: 몬스터 설계도 만들기**
```python
# class 키워드를 쓰고 이름을 대문자로 시작하는 것이 파이썬의 관례입니다.
class Monster():
    pass

# 설계도를 이용해 슬라임과 고블린이라는 실체(인스턴스)를 창조합니다!
slime = Monster()
goblin = Monster()

# 방금 태어난 녀석들에게 각각의 개성(속성값)을 부여합니다.
slime.name = "초록 슬라임"
slime.hp = 30

goblin.name = "망치 고블린"
goblin.hp = 100

print(f"{slime.name}의 체력은 {slime.hp}입니다.")
```

**실행 결과**
```text
초록 슬라임의 체력은 30입니다.
```

# 51 스스로 움직이게 하라: 메서드(Method)

클래스 안에는 데이터(이름, 체력)뿐만 아니라 **행동(함수)**도 담을 수 있습니다. 클래스 안에 찰싹 달라붙어 있는 이 특별한 함수를 우리는 **메서드(Method)**라고 부릅니다.

클래스 안에 메서드를 만들 때는 딱 하나만 기억하세요. **무조건 첫 번째 구멍(매개변수)은 `self` 라고 적는다!**
이 `self`는 "나 자신"을 뜻합니다. "내 체력(`self.hp`)을 깎아라", "내 이름(`self.name`)을 출력해라"라고 명령할 때 쓰이는 아주 중요한 주인공입니다.

**코드: 공격받는 몬스터**
```python
class Monster():
    # 클래스 안에 들어온 함수(메서드)는 언제나 첫 번째 자리에 self를 써야 합니다.
    def take_damage(self, damage):
        self.hp = self.hp - damage
        print(f"아야! {self.name}이(가) {damage}의 피해를 입었습니다! (남은 체력: {self.hp})")

# 몬스터 생성
orc = Monster()
orc.name = "오크 전사"
orc.hp = 200

# 우리는 take_damage를 호출할 때 damage인 50만 넘겨줍니다.
# 앞의 self는 파이썬이 알아서 'orc' 자신으로 쏙 집어넣어 줍니다.
orc.take_damage(50) 
orc.take_damage(100)
```

**실행 결과**
```text
아야! 오크 전사가 50의 피해를 입었습니다! (남은 체력: 150)
아야! 오크 전사가 100의 피해를 입었습니다! (남은 체력: 50)
```

# 52 파이썬의 숨겨진 마법: 매직 메서드 (Magic Method)

메서드들 가운데 앞뒤로 밑줄이 두 개씩(`__`) 붙어 있는 녀석들을 매직 메서드라고 부릅니다. 이들은 내가 직접 `orc.뭐시기()`라고 부르지 않아도 **특정 상황에 파이썬이 몰래 알아서 실행**해 주는 은밀한 마법입니다.

### 1. 탄생의 마법: `__init__`
인스턴스가 세상에 `Monster()` 하고 태어나는 그 순간, 축포를 터뜨리듯 딱 한 번 자동 실행되는 '초기화(Initialize)' 메서드입니다. 귀찮게 밖에서 이름을 하나하나 지어줄 필요 없이, 태어날 때 강제로 이름을 받도록 세팅해 줍니다.

### 2. 자기소개의 마법: `__str__`
인스턴스를 `print()` 로 화면에 찍었을 때 깨진 글자 대신 "어떻게 예쁘게 보여줄지"를 결정해 반환해 줍니다.

**코드: 마법이 깃든 궁극의 클래스**
```python
class Hero():
    # 영웅이 태어날 때 이름과 직업을 필수로 받게 세팅합니다.
    def __init__(self, name, job):
        self.name = name     # 태어난 녀석(self)의 이름에 넘겨받은 이름을 집어넣습니다.
        self.job = job
        print(f"축하합니다! 빛의 전사 {self.name} 님이 탄생하셨습니다!")

    # 영웅을 print로 출력할 때 보여줄 멋진 문구를 세팅합니다.
    def __str__(self):
        return f"[{self.job}] 레벨 1 초보자 {self.name}"

# 영웅이 소환되는 순간 __init__ 이 폭발적으로 실행됩니다!
my_hero = Hero("루크", "마법사")

# 객체를 바로 print에 밀어 넣으면 파이썬이 몰래 __str__ 을 발동시킵니다.
print(my_hero)
```

**실행 결과**
```text
축하합니다! 빛의 전사 루크 님이 탄생하셨습니다!
[마법사] 레벨 1 초보자 루크
```
이제 여러분은 데이터와 함수를 멋지게 하나로 묶어 현실 세계를 코드로 조각할 수 있는 건축가가 되었습니다!
