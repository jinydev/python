# PART 08 누군가 만들어둔 마법의 상자, 모듈

파이썬이 전 세계적으로 가장 인기 있는 언어가 된 비결은 무수히 많은 전 세계의 프로그래머들이 만들어 둔 유용한 도구들을 '레고 블록'처럼 내 코드에 쉽게 끼워 맞출 수 있기 때문입니다. 수천 줄의 코드를 직접 짤 필요 없이, 남들이 견고하게 만들어 둔 부품을 조립하는 강력한 기능, **모듈(Module)**에 대해 배웁니다.

# 24 내장 모듈 가져다 쓰기 (import)

자동차를 만들 때 바퀴의 고무부터 직접 농사지어 만드는 사람은 없습니다. 타이어 공장에서 완성된 타이어를 사와서 끼우면 됩니다. 파이썬에서도 수학 계산, 무작위 뽑기, 심지어 인터넷 접속까지 수많은 도구가 미리 준비되어 있습니다.

이런 도구 상자를 내 코드로 가져오는 마법의 주문이 바로 **`import`**입니다.

### 1. math 모듈: 수학 천재의 계산기
원주율인 무한소수 파이($\pi$)를 직접 3.141592... 하고 입력할 필요가 없습니다. 파이썬의 수학 모듈인 `math`를 불러옵니다.

**REPL 실습: math 모듈**
```python
>>> import math
>>> radius = 10
>>> area = math.pi * radius * radius  # 원의 넓이 계산
>>> print(area)
314.1592653589793
```
모듈 안의 도구를 꺼낼 때는 항상 **`모듈이름.도구이름`** 형식으로 마침표(`.`)를 찍어 접근합니다.
`math` 모듈에는 반올림이 아닌 완전한 올림처리를 하는 `math.ceil()`, 내림 연산을 하는 `math.floor()` 같은 다양한 수학 전용 도구들이 숨어 있습니다.

> **⚠️ 주의:** 우리가 자주 쓰는 반올림 함수 `round()`는 워낙 자주 쓰여 굳이 `math` 모듈을 불러오지 않아도 파이썬이 기본으로 제공하는 특별한 내장 함수입니다.

### 2. random 모듈: 예측 불가의 주사위
게임에서 몬스터가 무작위로 등장하고, 뽑기에서 랜덤 아이템이 나오게 하려면 어떻게 해야 할까요? 바로 `random` 모듈을 사용합니다.
특히 리스트 안에 있는 요소 중 아무거나 하나를 무작위로 뽑아주는 `choice` 함수는 그야말로 꿀 같은 기능입니다.

**코드: random_choice.py**
```python
import random

lotto = [7, 12, 23, 31, 40, 45]
lucky_number = random.choice(lotto)
print(f"오늘의 추천 로또 번호: {lucky_number}")
```

### 3. 인터넷을 긁어오는 무서운 도구들 (맛보기)
파이썬의 모듈은 상상을 초월합니다. 단 세 줄의 코드만으로 특정 웹사이트의 HTML 코드를 통째로 긁어오는 놀라운 마술도 가능합니다. (이 코드는 아직 완벽히 이해하지 않아도 됩니다. "아하, 이런 것도 가능하구나!" 정도만 느끼고 넘어가세요.)

**코드: 웹 페이지 긁어오기**
```python
import urllib.request

url = "http://example.com/"
response = urllib.request.urlopen(url)
print(response.read().decode('utf-8'))
```
이처럼 `import` 한 줄로 우리는 파이썬이 가진 무한한 생태계와 연결됩니다.

# 25 나만의 모듈 직접 만들기

파이썬이 주는 모듈만 쓰란 법은 없습니다. 내가 만든 유용한 함수나 변수들을 모아놓은 파이썬 파일(`.py`) 하나하나가 사실상 전부 하나의 **독립적인 모듈**입니다!

나만의 도구 상자를 만들어 봅시다.

### 1단계: 도구 상자(모듈 파일) 만들기
바탕화면이나 작업 폴더에 `my_tools.py` 라는 새 파일을 만들고, 아래와 같이 내가 즐겨 쓰는 함수와 상수를 정의해 둡니다.

**코드: my_tools.py (만들기)**
```python
# 여러 곳에서 돌려 쓸 나만의 도구들을 이곳에 선언해 둡니다.
WIND_SPEED = 15
MAX_PLAYERS = 100

def say_hello(name):
    return f"환영합니다, {name}님! 즐거운 파이썬 세계입니다."

def roll_dice():
    import random
    return random.choice([1, 2, 3, 4, 5, 6])
```

### 2단계: 다른 파일에서 불러와서 쓰기
이제 같은 폴더에 전혀 다른 새 파일 `main_game.py` 를 만듭니다. 그리고 방금 만든 도구 상자의 이름을 `import` 명령어로 불러오기만 하면 됩니다.

**코드: main_game.py (불러 쓰기)**
```python
import my_tools  # .py 확장자는 절대 붙이지 않습니다!

# 모듈 안의 변수 꺼내 쓰기
print(f"최대 접속 인원은 {my_tools.MAX_PLAYERS}명 입니다.")

# 모듈 안의 함수 꺼내 쓰기
msg = my_tools.say_hello("용사")
print(msg)

result = my_tools.roll_dice()
print(f"주사위 결과: {result}")
```

이 코드를 실행해보면 완벽하게 내가 만든 도구들이 작동하는 것을 볼 수 있습니다. 마치 장인이 만들어 놓은 도구를 꺼내어 쓰듯, 코드의 재사용성이 폭발적으로 증가합니다.

### 🚨 모듈 생성 시 지켜야 할 주의사항

1. **`.py` 확장자를 빼고 import 할 것**
   `import my_tools.py` 라고 쓰면 파이썬은 모듈을 찾지 못해 지독한 에러를 뿜어냅니다. 무조건 확장자를 뗀 이름만 적으세요.
2. **같은 폴더에 둘 것**
   현재 수준에서는 도구 상자 파일(`my_tools.py`)과 이를 사용하는 메인 파일(`main_game.py`)이 무조건 **같은 폴더(디렉토리)** 안에 나란히 놓여 있어야 파이썬이 쉽게 모듈을 찾아냅니다.
3. **거인들의 이름과 겹치지 말 것**
   파이썬 기본 모듈 이름과 똑같은 이름표를 사용해선 안 됩니다. 만약 내 파일 이름을 무심코 `math.py` 나 `random.py` 로 짓는다면, 파이썬은 진짜 수학 모듈 대신 비어있는 복제품을 불러오게 되어 프로그램 전체가 마비되는 대참사가 일어납니다! 반드시 겹치지 않는 나만의 독특한 파일명(`my_math.py` 등)을 사용하세요.
