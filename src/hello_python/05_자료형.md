# 16 문자열을 내 마음대로, 포매팅(Formatting)

지금까지 우리는 여러 개의 변수와 텍스트를 이을 때 `print()` 함수 안에 쉼표(`,`)를 나열하거나 `+` 기호를 썼습니다. 하지만 문장이 길어지고 변수가 많아지면 따옴표를 여닫느라 코드가 지저분해지고 오타가 나기 십상입니다. 이를 해결해주는 구원자가 바로 **문자열 포매팅**입니다.

그중 파이썬에서 가장 널리 쓰이는 `.format()` 방식을 알아보겠습니다.

**코드: format_test.py**
```python
# 기존의 번거로운 방식
year = 2026
month = 3
day = 15

print('오늘은', year, '년', month, '월', day, '일입니다.')

# 🌟 스마트한 format() 방식
template = '오늘은 {}년 {}월 {}일입니다.'
print(template.format(year, month, day))
```

**실행 결과**
```text
오늘은 2026년 3월 15일입니다.
오늘은 2026년 3월 15일입니다.
```

원리는 간단합니다. 문자열 안에서 변수가 들어갈 자리를 마치 빈칸 뚫기 문제처럼 중괄호 `{}` 로 비워둡니다. 그리고 문자열 맨 끝에 마침표(`.`)를 찍어 찰싹 달라붙게 한 뒤, `format(들어갈 변수들...)` 을 순서대로 꼼꼼히 채워주면 완성입니다!

물론 이렇게 변수를 따로 빼지 않고, `print` 안에서 바로 텍스트 뒤에 붙여 써도 완벽하게 작동합니다.

**코드: 게임 결과 출력하기**
```python
player = '용사'
monster = '슬라임'
damage = 999

print('[전투 결과] {}가 {}에게 {}의 피해를 입혔습니다!'.format(player, monster, damage))
```

> **💥 만약 중괄호와 변수 개수가 맞지 않는다면?**
> 중괄호 `{}`는 3개인데 `format` 안에 변수를 2개만 주면 파이썬은 빈칸을 채우지 못하고 쩔쩔매다가 `IndexError`를 발생시킵니다. 짝을 정확히 맞춰주세요!

*(+ 최신 파이썬 트렌드: `f-string`)*
최근 파이썬에서는 `format()`보다 더 직관적인 `f-string`을 대세로 사용합니다. 문자열 따옴표 바로 앞에 알파벳 `f`를 붙이고, 중괄호 안에 매칭할 변수 이름을 직접 써버리는 매우 매력적인 문법입니다.
`print(f'오늘은 {year}년 {month}월 {day}일입니다.')` 가 바로 그것입니다!

# 17 줄바꿈이 있는 긴 텍스트 다루기

시나 경고문처럼 엔터(줄바꿈)가 여러 번 포함된 아주 긴 텍스트를 출력하려면 어떻게 해야 할까요?
파이썬은 작은따옴표(`'`) 세 개, 혹은 큰따옴표(`"`) 세 개를 연달아 쓰면 그 사이의 모든 엔터와 띄어쓰기를 입력한 화면 그대로 인식하는 놀라운 능력을 갖추고 있습니다.

**코드: 장문 출력하기**
```python
long_text = '''어느 맑은 날,
파이썬이 나에게 물었다.
"당신은 코딩을 좋아하나요?"
나는 '물론이지!' 라고 대답했다.'''

print(long_text)
```

이 방식의 또 다른 장점은, 안에 일반 작은따옴표나 큰따옴표를 마음껏 섞어 쓸 수 있다는 점입니다.

# 18 디테일이 다르다: 정수(int)와 실수(float)

자판기의 '1,000원'과 체중계의 '65.4kg'. 우리 눈엔 다 같은 숫자지만 파이썬은 이 둘을 엄격하게 차별 대우합니다.

파이썬 숫자 세계의 두 기둥은 바로 소수점이 없는 **정수(Integer, `int`)**와 소수점 아래까지 정밀하게 표현하는 **실수(Floating Point, `float`)**입니다.

```python
score = 100       # 평범한 정수
weight = 65.4     # 소수점을 품은 실수
exact_num = 100.0 # '.0'이 붙는 순간 파이썬은 무조건 실수로 취급합니다.
```

대부분의 사칙연산(`+, -, *`)에서 정수끼리 계산하면 결과도 든든한 정수로 나옵니다.
하지만 **나눗셈(`/`)**만큼은 예외입니다. 값이 딱 떨어지더라도 나눗셈의 결과는 언제나 '실수'로 변환됩니다.

**코드: 나눗셈의 법칙**
```python
print(10 / 2)   # 결과: 5.0 (실수)
print(7 / 3)    # 결과: 2.3333333333333335
```

몫만 깔끔하게 정수로 얻고 싶다면 나눗셈 기호를 두 번 연달아 쓴 `//` 연산자를 사용하면 됩니다. 앞서 배웠던 나머지 기호 `%`와 단짝입니다.

**코드: 몫과 나머지**
```python
print(10 // 3)  # 버림 나눗셈(몫). 결과: 3
print(10 % 3)   # 나머지. 결과: 1
```

> **🧠 깊게 알기: 실수의 치명적인 비밀**
> 파이썬 뿐만 아니라 세상의 모든 컴퓨터는 소수점 계산(부동소수점 연산)에서 미세한 오차가 발생합니다. 
> `print(0.1 + 0.1 + 0.1 == 0.3)` 을 실행하면 어이없게도 `False`가 튀어나옵니다! 컴퓨터가 0.1을 이진수로 번역하는 과정에서 아주 미세한 오차가 쌓이기 때문입니다.

때문에 우리는 상황에 맞게 자료형을 강제로 변환할 수 있어야 합니다.
* `int(3.8)` -> `3` (소수점을 가차없이 버리고 정수만 취함)
* `float(5)` -> `5.0` (명시적으로 실수 형태로 변환함)

# 19 소통하는 프로그램 만들기: 사용자 입력(`input`)

프로그래밍의 꽃은 상호작용입니다. 사용자가 화면을 쳐다만 보는 게 아니라, 직접 타이핑하여 값을 밀어 넣고 그에 반응하는 프로그램을 만들어 봅시다. 이 환상적인 기능은 `input()` 이라는 단 하나의 내장 함수로 구현됩니다.

**코드: user_input.py**
```python
print('여러분이 가장 좋아하는 파이썬의 기능은 무엇인가요?')
answer = input()
print('멋지네요!', answer, '기능을 좋아하시는군요!')
```

이 코드를 실행하면 파워셸(터미널)에 첫 문장이 출력된 뒤, 프로그램이 숨을 죽이고 **커서를 깜빡이며 일시 정지**합니다. 파이썬이 여러분의 키보드 입력을 오매불망 기다리고 있는 것입니다.

아무 문장이나 타이핑하고 `[Enter]`를 치는 순간, 타이핑했던 모든 내용이 고스란히 `answer` 변수 상자 안으로 빨려 들어가며 멈췄던 코드가 다시 힘차게 굴러가기 시작합니다.

한층 더 세련되게 만들려면, `input` 함수의 괄호 안에 질문(프롬프트 메시지)을 직접 넣을 수도 있습니다.

**코드: 더 짧고 명확한 입력**
```python
name = input('당신의 이름을 입력해주세요: ')
print(f'반갑습니다, {name}님!')
```

**실행 흐름**
```text
당신의 이름을 입력해주세요: 파이썬마스터 (엔터 입력)
반갑습니다, 파이썬마스터님!
```

> **🚨 비상 탈출구: 프로그램 강제 종료**
> 만약 실수로 무한 루프에 빠지거나, 입력을 기다리는 상태에서 즉시 프로그램을 죽이고 바탕화면으로 나가고 싶다면 무적의 단축키 **`Ctrl` + `C`** 를 기억하세요! 키보드 인터럽트(KeyboardInterrupt)를 발생시켜 어떤 고집불통 프로그램이라도 즉결 처형(!)시킬 수 있습니다.
