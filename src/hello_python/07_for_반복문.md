# PART 07 멈출 수 없는 기계 장치, for 반복문

리스트 안에 수십, 수백 개의 데이터가 담겨 있다고 상상해 보세요. 이것들을 일일이 꺼내어 출력하거나 계산하려면 수백 줄의 똑같은 코드를 타건(打鍵)해야 할 것입니다. 이렇게 반복되는 노동으로부터 우리를 구원해 줄 프로그래밍의 핵심 문법, **`for` 반복문**을 파헤쳐 봅니다.

---

# 22 데이터를 타고 흐르는 마법의 루프, for ~ in

파이썬에서 리스트 안에 든 내용물을 한 바퀴 쭉 순회하며 똑같은 작업을 반복하고 싶을 때 쓰는 도구가 바로 `for ... in` 블록입니다.

百聞이 不如一見! 예제 코드를 먼저 보겠습니다.

**코드: loop_test.py**
```python
# 여러 과일이 들어 있는 리스트
fruits = ['사과', '바나나', '포도', '딸기']

# 과일 리스트를 순회하는 for 반복문
for fruit in fruits:
    print(f"맛있는 {fruit}를 먹습니다.")
```

**실행 결과**
```text
맛있는 사과를 먹습니다.
맛있는 바나나를 먹습니다.
맛있는 포도를 먹습니다.
맛있는 딸기를 먹습니다.
```

코드가 단 2줄에 불과하지만, 실행 결과는 4줄이나 출력되었습니다. 이 짧은 코드 이면에서는 엄청난 일들이 벌어지고 있습니다!

`for` 반복문은 다음과 같은 순서대로 동작합니다.
1. `in` 뒤쪽에 있는 `fruits` 리스트(또는 상자)를 봅니다.
2. 상자 안에서 제일 앞에 있는 값('사과')을 무심하게 쑥 꺼냅니다.
3. 꺼낸 값을 `in` 앞쪽에 있는 `fruit`라는 새 변수에 임시로 쏙 집어넣습니다! (여기서 파이썬이 알아서 `=` 대입을 해주는 셈입니다.)
4. 들여쓰기 된 블록 안의 코드를 실행합니다. 이때 `fruit`는 '사과'이므로 "맛있는 사과를 먹습니다."가 출력됩니다.
5. 블록이 끝나면 다시 1번으로 돌아가 그 다음 값('바나나')을 꺼내어 다시 3, 4번 작업을 반복합니다.
6. 상자가 완전히 텅 비게 되면(마지막 '딸기'까지 끝내면), 비로소 지옥의 반복 루프를 탈출하여 다음 코드로 넘어갑니다.

만약 이 `for`문을 쓰지 않고 노가다를 했다면 아래처럼 끔찍한 코드가 탄생했을 것입니다.

**코드: (비교용) for문이 없다면 생기는 끔찍한 일**
```python
# for 문과 완전히 똑같이 동작하는 쌩(raw) 노가다 코드
fruit = fruits[0]
print(f"맛있는 {fruit}를 먹습니다.")
fruit = fruits[1]
print(f"맛있는 {fruit}를 먹습니다.")
fruit = fruits[2]
print(f"맛있는 {fruit}를 먹습니다.")
# ... 리스트 개수만큼 무한 반복 ...
```
데이터가 천 개라면 천 번을 복사 붙여넣기 해야 하지만, `for` 반복문을 쓰면 천 번, 만 번이라도 단 2줄이면 깔끔하게 끝납니다.

# 23 숫자를 찍어내는 팩토리, for in range

`for-in` 구문은 리스트 안에 있는 값을 꺼낼 때 최고의 위력을 발휘합니다. 그런데 만약 "안녕하세요!"를 딱 100번만 외치고 싶거나, 1부터 50까지 숫자를 세고 싶을 때는 어떡할까요?
`[1, 2, 3, 4, ... 100]` 처럼 백 개의 숫자가 든 무식한 리스트를 손수 만들 수는 없는 노릇입니다.

이럴 때 구원투수처럼 등장하는 파이썬의 요술 지팡이 함수가 바로 **`range()`**입니다.

**코드: range()의 위력**
```python
# 0부터 시작해서 5번 반복(0, 1, 2, 3, 4)
for i in range(5):
    print(i)
```
**실행 결과**
```text
0
1
2
3
4
```

`range(5)`를 쓰면 파이썬 내부의 기계 장치가 투명한 리스트 `[0, 1, 2, 3, 4]`를 순식간에 찍어냅니다. (이전 시간에도 강조했듯, 파이썬 숫자는 항상 **0부터** 시작한다는 점, 그리고 `5`가 적혀있으면 5 직전인 `4`까지만 만들어진다는 점을 꼭 기억하세요!)

그렇다면, 특정한 리스트를 순회하면서 그 리스트의 항목이 "몇 번째"인지 번호표를 붙여서 출력하고 싶을 땐 어떻게 할까요?
`range()`와 리스트의 길이(`len()`)를 섞어 쓰는 전통적인 방식을 사용할 수 있습니다.

**코드: 리스트와 번호표**
```python
members = ['아이언맨', '캡틴', '토르', '헐크']

# len(members)는 4이므로, range(4)가 만들어져 0, 1, 2, 3 이 생성됩니다.
for i in range(len(members)):
    member = members[i]
    print(f'{i + 1}번 멤버: {member}')
```
**실행 결과**
```text
1번 멤버: 아이언맨
2번 멤버: 캡틴
3번 멤버: 토르
4번 멤버: 헐크
```

### 💎 진정한 고수의 스킬: enumerate
위처럼 `for i in range(len(...))` 방식도 좋지만, 코드가 살짝 지저분해집니다.
파이썬은 순서(인덱스)와 들어있는 값(데이터)을 동시에 쏙쏙 뽑아주는 기적의 함수 **`enumerate()`** (열거하다)를 제공합니다.

**코드: 세련된 enumerate 활용법**
```python
members = ['아이언맨', '캡틴', '토르', '헐크']

# i 에는 0, 1, 2가, name 에는 실제 값이 들어갑니다. (변수 2개를 쉼표로 받음)
for i, name in enumerate(members):
    print(f'{i + 1}번 멤버: {name}')
```
위와 똑같은 결과가 훨씬 파이썬다운 아름다운 코드로 탄생했습니다!

상황에 맞게 두 가지 도구를 적절히 골라 쓰세요.
* **`range()`**: 0부터 특정 횟수만큼 반복하거나 특정 번호 목록 자체가 필요할 때.
* **`enumerate()`**: 리스트 안의 데이터를 살펴볼 때 그 데이터의 '인덱스 번호'까지 동시에 알고 싶을 때.
