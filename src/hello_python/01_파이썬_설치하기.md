# PART 01

## 시작하기

Part 1에서는 본격적인 파이썬 학습에 앞서 개발 환경을 구축하는 방법을 알아봅니다. 파이썬을 컴퓨터에 설치하고, 소스 코드를 작성할 에디터(편집기)를 준비하는 단계입니다. 처음에는 낯설고 번거로울 수 있지만, 한 번 설정해 두면 이후에는 프로그래밍에만 집중할 수 있습니다. 

---

# 01 파이썬 설치 가이드

파이썬 기반의 프로그램을 작성하고 실행하려면 가장 먼저 여러분의 PC에 파이썬 언어 실행 환경을 구축해야 합니다.

윈도우(Windows) 운영체제에는 기본적으로 파이썬이 포함되어 있지 않으므로 직접 설치해야 합니다. 반면 리눅스(Linux)나 macOS 환경에는 파이썬이 미리 설치되어 있는 경우가 많으나, 구버전(Python 2.x)일 수 있으므로 최신 버전(Python 3.x)을 새로 설치하는 것을 권장합니다. 공식 홈페이지를 통해 안전하게 파이썬을 내려받아 설치해 봅시다.

> **💡 참고**
> 여기서는 많은 분들이 사용하시는 윈도우 환경을 중심으로 설명하지만, macOS 환경에서의 기본 설치 가이드도 함께 제공합니다.

1. **파이썬 공식 홈페이지 접속하기**
   웹 브라우저를 켜고 파이썬 공식 사이트의 다운로드 페이지(https://www.python.org/downloads/)로 이동합니다. 화면에 나타나는 'Download Python 3.x.x' 버튼을 클릭하여 설치 파일을 다운로드합니다. 여러분이 학습하시는 시점에 숫자(버전)는 조금씩 다를 수 있으나, 맨 앞자리가 '3'으로 시작하는 버전이라면 무방합니다.

2. **설치 파일 실행 및 PATH 설정**
   다운로드가 완료된 설치 파일(예: `python-3.x.x-amd64.exe`)을 실행합니다. 
   **[주의점]** 설치 마법사 첫 화면의 하단에 있는 **'Add Python 3.x to PATH'** 항목을 반드시 체크한 후 **'Install Now'**를 클릭하세요. 이 옵션을 설정해야 터미널이나 명령 프롬프트에서 `python`이라는 명령어만으로 파이썬을 쉽게 실행할 수 있습니다. 만약 이 설정을 놓치면 매번 파이썬이 설치된 복잡한 전체 경로를 입력해야 하는 불편함이 따릅니다.

3. **설치 확인 (파워셸 실행)**
   설치가 끝났다면 정상적으로 동작하는지 확인해 볼 차례입니다. `[윈도우 키] + [R]`을 눌러 '실행' 창을 띄운 뒤, `powershell`을 입력하고 [확인]을 누릅니다. (또는 윈도우 시작 메뉴 검색창에서 'powershell'을 검색하여 실행할 수도 있습니다.)

4. **파이썬 프롬프트 확인**
   파워셸의 검은(또는 파란) 화면이 열리면 `python`이라고 입력하고 `[Enter]` 키를 누릅니다. 화면에 파이썬 버전 정보가 출력되고, 그 아래에 `>>>` 기호(프롬프트)가 나타난다면 파이썬이 성공적으로 설치된 것입니다.

```text
Windows PowerShell

PS C:\Users\Username> python
Python 3.X.X ... on win32
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

> **오류가 발생하나요?**
> 파워셸에서 명령어를 찾을 수 없다는 식의 붉은 글씨 오류가 뜬다면, 앞서 강조했던 'Add Python to PATH' 옵션을 체크하지 않았을 확률이 높습니다. 이 경우 제어판에서 파이썬을 완전히 제거한 후, 옵션을 체크하여 다시 설치하는 것을 추천합니다.

---

> **💻 macOS 환경에서 파이썬 3.x 설치 및 설정**
>
> 1. 공식 홈페이지에서 macOS용 파이썬 3 설치 버전(.pkg 파일)을 내려받아 실행하고, 안내에 따라 설치를 완료합니다.
> 2. `[Command] + [Space]`를 눌러 Spotlight 검색창을 띄우고, '터미널(Terminal)'을 입력하여 실행합니다.
> 3. 터미널 창에 `python3`을 입력합니다. (macOS에는 시스템 기본 파이썬이 존재하므로 명시적으로 `python3`라고 입력해야 최신 버전이 실행됩니다.)
> 4. `Python 3.x.x`와 같은 문구가 보이면 설치 성공입니다.
>
> **편의 설정: `python`으로 실행되게 만들기**
> 매번 `python3`를 입력하기 번거롭다면, 다음 방법으로 단축키(Alias) 설정을 할 수 있습니다. 
> 1. 터미널에 `nano ~/.zprofile` (또는 과거 macOS 버전의 경우 `open -a TextEdit ~/.bash_profile`)을 입력하여 설정 파일을 엽니다.
> 2. 파일 맨 아래에 `alias python=python3` 이라는 내용을 추가합니다.
> 3. 저장 후 터미널을 완전히 종료했다가 다시 실행합니다.
> 4. 이제 `python`만 입력해도 Python 3 버전이 실행되는 것을 확인할 수 있습니다.

# 02 파이썬 제대로 설치했는지 확인하기

터미널이나 파워셸에서 `python` 명령어를 입력해 `>>>` 프롬프트를 확인했다면, 이제 파이썬 코드를 한 줄씩 입력하여 바로 결과를 볼 수 있는 **대화형 모드(Interactive Mode)**에 진입한 것입니다. 

파이썬 대화형 모드를 종료하고 일반 쉘 환경으로 돌아가고 싶다면, `exit()`라고 입력하고 `[Enter]`를 누르거나, 윈도우에서는 `[Ctrl]+[Z]`, macOS에서는 `[Ctrl]+[D]`를 누른 후 `[Enter]`를 입력하시면 됩니다.

```text
PS C:\Users\Username> python
Python 3.X.X ...
>>> exit()
PS C:\Users\Username>
```

이제 본격적으로 코딩의 세계로 들어갈 모든 준비를 마쳤습니다!

---

> **🛠 파이썬 소스 코드 편집기 (IDE / Editor)**
> 
> 실제 프로젝트에서는 파워셸에 직접 코드를 치는 대신, 전용 편집기(Editor)에 코드를 작성하고 별도의 `.py` 파일로 저장한 뒤 한 번에 실행하는 방식이 일반적입니다.
> 
> 초보자에게는 직관적이고 가벼운 텍스트 에디터(예: Notepad++, VS Code, Sublime Text)나, 파이썬 개발에 특화된 통합 개발 환경(예: PyCharm)을 사용하는 것을 권장합니다. 이러한 도구들은 문법 강조(Syntax Highlighting) 기능이 있어 변수, 함수, 텍스트 등을 각기 다른 색상으로 보여주어 코드의 가독성을 크게 높여줍니다.
> 
> **예시: 간단한 코드 작성하고 실행해 보기**
> 1. 원하시는 에디터를 열고 새 파일을 생성합니다.
> 2. `print('Hello!')` 라고 한 줄을 입력합니다.
> 3. 이 파일을 여러분이 기억하기 쉬운 위치(예: 내 문서 `Documents` 폴더)에 `test.py`라는 이름으로 저장합니다.
> 4. 다시 파워셸(터미널)을 열고, `cd Documents` 명령어를 입력해 해당 폴더로 이동합니다. (`cd`는 디렉터리를 변경하는 Change Directory의 약자입니다.)
> 5. 현재 폴더의 파일 목록을 확인하는 `ls` 명령어를 입력하여 `test.py` 파일이 있는지 확인합니다.
> 6. `python test.py` 명령어를 입력하면 `Hello!` 라는 글자가 화면에 뜰 것입니다.

# 03 첫 파이썬 프로그램, Hello World!

프로그래밍 언어를 처음 배울 때는 무조건 "Hello, world!"를 화면에 출력해 보는 것이 전통입니다. 이제 파이썬을 통해 우리도 첫인사를 나눠보겠습니다.

에디터에서 새 파일을 열고, 아래 코드를 작성한 뒤 `hello.py`라는 이름으로 저장해 보세요.

**코드: hello.py**
```python
print('Hello, world!')
```

올바른 코드 에디터를 사용 중이라면 문법에 맞게 색상이 구분되어 표시될 것입니다. 
이제 터미널(또는 파워셸)을 열어 조금 전 코드를 저장한 폴더로 이동(cd)한 다음, 파이썬 명령어로 파일을 실행해 봅니다.

**실행 결과**
```text
PS C:\Users\Username\Documents> python hello.py
Hello, world!
```

화면에 `Hello, world!`가 정상적으로 출력되었다면 완벽하게 성공한 것입니다. 만약 오류가 표시된다면 다음 사항을 점검해보세요.

> **💡 코드가 실행되지 않고 오류가 발생하나요?**
> 
> 1. **저장 여부**: 코드를 에디터에 타이핑만 하고 깜빡하고 저장을 누르지 않은 상태일 수 있습니다. 단축키 `[Ctrl]+[S]`(macOS: `[Cmd]+[S]`)를 눌러 파일을 확실히 저장해 주세요.
> 2. **오타 확인**: 괄호나 따옴표를 하나 빼먹었을 확률이 높습니다. `print('Hello, world!)` 처럼 뒤쪽 따옴표를 지우면 `SyntaxError: EOL while scanning string literal`과 같은 문법 에러가 발생합니다.

위에서 작성한 코드의 핵심 구성 요소를 간단히 짚고 넘어가 볼까요?

*   `print`: 파이썬이 제공하는 내장 **함수(Function)의 이름**입니다. 화면에 무언가를 출력(print)하라는 역할을 맡고 있으며, 모두 소문자로 작성해야 합니다.
*   `()`: 소괄호는 함수를 실행시키면서 괄호 안의 내용을 전달해 주는 역할을 합니다. 시작 괄호가 있다면 반드시 닫는 괄호도 짝을 맞춰 존재해야 합니다.
*   `'Hello, world!'`: 화면에 실제로 출력하고 싶은 **문자열(String)** 데이터입니다.
*   따옴표 (`'` 또는 `"`): "이 안의 내용은 프로그램 코드가 아니라 단순히 화면에 보여질 일반 글자(텍스트)입니다!"라고 컴퓨터에게 알려주는 필수 기호입니다. 

기호들이 각자 어떤 역할을 하는지 어렴풋이나마 이해되시나요? 처음에는 기호 하나하나의 위치가 헷갈려 에러를 자주 만날 수 있지만, 계속 코드를 작성하다 보면 자연스레 손에 익을 것입니다.
