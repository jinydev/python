# PART 12 에러를 두려워하지 않는 용기, 예외 처리

초보자가 코딩하면서 가장 짜증 나는 순간은, 단 하나의 사소한 실수(예컨대 글자를 숫자로 바꾼다든가) 때문에 잘 돌아가던 프로그램 전체가 멈추고 새빨간 에러 메시지를 뿜어낼 때입니다.
하지만 베테랑 프로그래머는 에러를 탓하지 않습니다. 에러가 날 만한 구간에 완충 장치를 달아, 에러가 나더라도 프로그램이 죽지 않고 유연하게 넘어갈 수 있게 설계합니다. 이것이 바로 **예외 처리(Exception Handling)**입니다.

# 37 에러의 충격을 흡수하는 에어백: try ~ except

파이썬에는 수많은 종료(crash) 사유가 있습니다. 빈 리스트에서 0번째 인덱스를 찾으려고 하면 발생하는 `IndexError`, 글자를 숫자로 억지로 바꾸려고 하면 생기는 `ValueError` 등이 바로 그것입니다.

**코드: 끔찍한 파멸 (에러 발생)**
```python
text = "백퍼센트"
# 파이썬은 "백퍼센트"라는 글자를 절대 숫자로 바꿀 수 없으므로 여기서 장렬하게 전사합니다!
number = int(text) 
print(number)
```

이 코드를 살리기 위해서는 위험한 코드를 안전한 `try` (시도해 보기) 블록에 넣고, 만약 에러가 났을 때 우회할 경로를 `except` (예외 처리) 블록에 적어두면 됩니다.

**코드: 튼튼한 방어벽**
```python
text = "백퍼센트"

try:
    # 일단 겁내지 말고 시도해 봅니다.
    number = int(text)
    print(f"변환된 숫자: {number}")
except ValueError:
    # 만약 ValueError가 발생했다면 프로그램이 죽는 대신 이 블록으로 피신합니다!
    print(f"주의: '{text}'는(은) 숫자로 변환할 수 없습니다. 기본값 0을 사용합니다.")
    number = 0
```
`try-except`를 사용하면 에러가 던져지더라도 프로그램이 강제 종료되지 않고 끝까지 정상적으로 돌아갑니다.

# 38 어떤 에러가 올지 모를 때: 만능 방패

위에서는 우리가 직접 `ValueError`라는 예외 이름을 찍어서 방어했습니다. 하지만 네트워크 문제, 파일 권한 문제 등 도대체 어떤 종류의 에러가 터질지 가늠할 수 없을 때는 어떻게 할까요?

이럴 때는 모든 에러를 포괄하는 `Exception` 방패를 쓰거나 이름조차 적지 않는 방법을 씁니다.

**코드: 정체불명의 에러 방어하기**
```python
try:
    my_list = []
    print(my_list[5]) # 100% 에러 발생
except Exception as ex:
    # 무슨 에러인지 모르겠을 때는 Exception as ex 라고 적어두면 
    # 파이썬이 에러의 정체를 ex 변수에 담아줍니다.
    print(f"앗! 뭔가 문제가 발생했습니다. 에러 원인: {ex}")
```
이 방식은 24시간 내내 돌아가야 하는 웹 서버 프로그램 등을 만들 때 서버가 절대 죽지 않게 꽉 잡아주는 아주 중요한 기술입니다. 단, 너무 남발하면 "진짜로 당장 고쳐야 할 치명적 에러"조차 조용히 묻혀버릴 수 있으니 주의하세요.

# 39 내가 심판이 되어 경고장 던지기: raise

지금까지 우리는 파이썬이 던지는 에러를 수동적으로 막아내는 법만 배웠습니다. 하지만 여러분이 프로그램을 만들다 보면, 파이썬 입장에서는 문법적으로 아무 에러가 나지 않지만 **여러분의 규칙**에는 어긋나서 코드가 계속 실행되면 안 되는 상황이 옵니다.

예컨대 '성인 인증' 프로그램인데 나이가 '마이너스 5살'로 들어왔다고 가정해 봅시다.

이럴 때 프로그래머가 **직접 능동적으로 에러를 일으켜서(raise)** 주변에 경고장을 붉게 흩날릴 수 있습니다.

**코드: 억지로 에러 일으키기**
```python
def check_age(age):
    if age < 0:
        # 이건 파이썬이 아니라 내가 정한 규칙 위반입니다! 강제로 에러를 폭발시킵니다.
        raise ValueError(f"나이가 어떻게 음수({age}살)일 수 있죠? 다시 입력하세요!")
    print(f"당신의 나이는 {age}살 이군요. 환영합니다.")

try:
    check_age(-5)
except ValueError as e:
    print(f"입력 오류 발생: {e}")
```

### 💎 진정한 고수의 스킬: 이중 반복문 탈출하기
`raise`의 또 다른 재미있는 활용법이 있습니다.
저번 장에서 배운 `break`는 자기가 속한 가장 가까운 반복문 1개만 탈출합니다. 즉 겹겹이 쌓인 `for`문 안에 있다면 한 칸밖에 벗어나지 못해 결국 다음 바퀴가 돌아갑니다.

이때, 가장 바깥쪽까지 한 번에 초고속으로 탈출하고 싶다면 짓궂게도 에러(`raise`)를 발생시켜 바깥 `try`가 잡아채게 만드는 트릭을 씁니다.

**코드: 이중 반복문 초고속 탈출 트릭**
```python
boxes = {
    'A박스': ['연필', '지우개'],
    'B박스': ['가위', '보석', '볼펜'],
    'C박스': ['자', '칼']
}

try:
    for box_name, contents in boxes.items():
        for item in contents:
            if item == '보석':
                print(f"!!! {box_name}에서 전설의 보석을 찾았습니다 !!!")
                # 더 겉에 있는 A박스, C박스로 넘어갈 필요가 없으므로 
                # 여기서 에러를 날려서 반복문 2개를 한 방에 찢고 탈출합니다.
                raise StopIteration 
            
            print(f"{box_name} 안의 {item} 확인 완료")
except StopIteration:
    print("보석 탐색을 완전히 종료합니다.")
```
이러한 트릭을 쓰면 복잡하게 얽힌 코드도 명쾌하게 끊어버릴 수 있습니다. 여러분도 `try`, `except`, `raise` 삼총사를 활용해 절대 무너지지 않는 견고한 프로그램을 설계해 보세요!
