# PART 04 코드의 마술 상자, 함수

코드의 길이가 길어지고 비슷한 동작을 여러 번 반복해야 한다면 어떻게 해야 할까요? 매번 코드를 복사해서 붙여넣기를 반복하다 보면 프로그램은 지저분해지고 오류를 수정하기도 힘들어집니다. 이번 파트에서는 반복되는 기능들을 하나의 '상자'로 깔끔하게 묶어주는 **함수(Function)**의 완벽한 활용법을 배웁니다.

# 13 나만의 코드 조립 블록, 함수 만들기

수학 시간에 지겹도록 외운 '근의 공식'을 파이썬 코드로 작성해 보겠습니다.

**코드: root_calc.py**
```python
# 일반적인 이차방정식의 해를 구하는 코드
a = 1
b = 2
c = -8

# 근의 공식 계산
ans1 = (-b + (b ** 2 - 4 * a * c) ** 0.5) / (2 * a)
ans2 = (-b - (b ** 2 - 4 * a * c) ** 0.5) / (2 * a)

print(f'방정식의 해는 {ans1}, {ans2} 입니다.')
```

만약 파라미터 `a, b, c`의 값을 여러 번 바꿔가며 다시 계산을 해야 한다면 어떨까요? 똑같이 복잡한 공식 코드를 세 번, 네 번 복사해야 할 것입니다. 이런 중복을 드라마틱하게 줄여주는 구원자가 바로 기능의 재사용 단위인 '함수'입니다.

위 코드를 함수로 묶어봅시다.

**코드: 함수로 개선하기**
```python
def print_root():
    # 이 들여쓰기 된 블록 전체가 함수에 속해 있습니다.
    ans1 = (-b + (b ** 2 - 4 * a * c) ** 0.5) / (2 * a)
    ans2 = (-b - (b ** 2 - 4 * a * c) ** 0.5) / (2 * a)
    print(f'해는 {ans1}, {ans2}')

a = 1
b = 2
c = -8
print_root()  # 첫 번째 계산 실행

a = 2
b = -6
c = -8
print_root()  # 두 번째 계산 실행
```

코드가 훨씬 더 읽기 편해졌습니다. 함수를 만드는 마법의 키워드는 **`def`** (define: 정의하다) 입니다.

1. `def`를 적고, 내가 원하는 함수의 이름(여기서는 `print_root`)을 지어줍니다.
2. 이름 바로 뒤에 **소괄호 `()`**와 쌍점 **`:`**을 붙여줍니다.
3. 그 다음 줄부터 `if`문 때처럼 4칸을 들여쓰고 묶어둘 코드를 마음껏 작성합니다.

가장 주의해야 할 점은 **"함수는 정의(def)만 해둔다고 해서 스스로 작동하지 않는다"**는 점입니다. 함수는 일종의 설명서에 불과합니다. 실제 작동을 원한다면 `함수이름()` 과 같이 소괄호를 열고 닫아 직접 "호출(Call)"을 해주어야만 내부 코드가 실행됩니다.

우리가 자주 써오던 `print()` 역시 사실은 파이썬 개발자들이 미리 만들어둔, 글자를 화면에 찍어주는 내장 함수입니다.

# 14 함수에게 재료 전달하기: 매개변수와 인수

앞서 작성한 `print_root()` 함수는 완벽해 보이지만 한 가지 치명적인 문제가 있습니다. 무조건 자기보다 먼저 `a, b, c`라는 변수가 바깥에 선언되어 있어야만 눈치껏 가져다 쓴다는 점입니다. 만약 하나라도 빠뜨린다면 이름표를 찾을 수 없다는 뜻의 무시무시한 `NameError`를 만나게 됩니다.

이때 함수를 완전히 **독립적인 공장**으로 만들어주는 것이 바로 **매개변수(Parameter)**입니다.

소괄호 `()`의 असली(진짜) 용도가 여기서 밝혀집니다. 함수가 기능을 수행하기 위해 외부에서 받아야 할 '재료'들의 이름을 나열하는 공간입니다.

**코드: 매개변수를 갖춘 함수**
```python
def print_root(a, b, c):  # a, b, c라는 3개의 재료(매개변수)를 받겠다고 선언
    ans1 = (-b + (b ** 2 - 4 * a * c) ** 0.5) / (2 * a)
    ans2 = (-b - (b ** 2 - 4 * a * c) ** 0.5) / (2 * a)
    print(f'해는 {ans1}, {ans2}')

# 사용할 때는 순서에 맞게 값을 넘겨주면 됩니다.
print_root(1, 2, -8)
print_root(2, -6, -8)
```

위의 예시를 보면, 외부의 귀찮은 변수 선언 없이, 호출할 때 `(1, 2, -8)` 과 같이 재료들을 쉼표로 나열하여 쏙쏙 던져주기만 하면 됩니다. 이렇게 호출할 때 던지는 실제 값을 **인수(Argument)**라고 부릅니다. 
함수에 매개변수를 3개 받겠다고 선언해 두고 인수를 2개만 주거나 4개를 주면 에러(`TypeError`)가 발생하니 개수를 꼭 맞춰야 합니다.

또 다른 예로, 파이썬이 제공하는 내장 함수 `round()` (반올림 함수)를 살펴보겠습니다.
```python
number = round(4.6)
print(number)  # 5 출력
```
여기서 `4.6` 역시 `round` 함수에게 반올림할 재료를 던져준 인수입니다.

# 15 함수의 결과 도출: return

지금까지 만든 함수들은 계산한 결과를 단순히 `print`를 써서 화면에 보여주고 일을 마쳤습니다. 그런데 만약 함수가 구한 결괏값을 다음 변수에 저장하여 또 다른 계산에 쓰고 싶다면 어떻게 할까요? 화면에 글자만 띄우는 `print`만 있어서는 불가능합니다.

함수가 자신이 이룬 결과물을 밖으로 **'제출'**하도록 지시하는 마법의 키워드가 바로 `return`입니다.

**코드: return의 활용**
```python
def add_ten(value):
    result = value + 10
    return result

# 함수가 제출(return)한 52라는 결과를 my_number에 담습니다.
my_number = add_ten(42)
print("결과:", my_number)
```

`return`의 역할은 다음과 같습니다.
1. **값의 반환**: `return` 바로 오른쪽의 값을 함수를 호출했던 본래 자리로 던져줍니다.
2. **과감한 종료 기능**: `return`을 만나는 즉시 함수는 **무조건 실행을 강제 종료**합니다. 그 아래에 어떤 코드가 천 줄이 쓰여 있든 철저하게 무시되고 밖으로 탈출합니다.

**코드: return의 종료 특성**
```python
def check_password(password):
    if password == "1234":
        return "로그인 성공!"
    
    # 위에서 패스워드가 맞아서 return을 만나 탈출했다면,
    # 아래 코드는 영원히 실행되지 않습니다.
    return "로그인 실패. 비밀번호를 확인하세요."
```

마지막으로 꿀팁 하나! 하나의 엑셀 파일이나 한 상자에 물건이 여러 개 들어갈 수 있듯이, 파이썬의 `return`은 여러 개의 값도 한 번에 쉼표(`,`)로 묶어 동시에 반환할 수 있는 엄청난 기능을 지원합니다.

**코드: 여러 결괏값을 동시에 던지기**
```python
def calc_root(a, b, c):
    ans1 = (-b + (b ** 2 - 4 * a * c) ** 0.5) / (2 * a)
    ans2 = (-b - (b ** 2 - 4 * a * c) ** 0.5) / (2 * a)
    
    # 2개의 값을 동시에 return 합니다.
    return ans1, ans2

# 받을 때도 2개의 변수를 쉼표로 나열해 각각 받아냅니다.
r1, r2 = calc_root(1, 2, -8)
print(f"첫 번째 해: {r1}, 두 번째 해: {r2}")
```

함수에 재료(`매개변수`)를 넣고, 함수가 묵묵히 일한 공정 결과를 밖으로 빼내는(`return`) 이 완전한 사이클이야말로 파이썬 프로그래밍의 가장 아름다운 심장입니다.
