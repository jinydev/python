# 26 모르는 코드를 찾는 기술, 구글 검색

코딩을 하다 보면 십중팔구 "오늘 날짜를 파이썬으로 어떻게 띄우지?", "리스트를 무작위로 섞으려면 어떻게 하지?" 같은 의문이 듭니다. 이때 가장 강력한 도구는 구글 검색창입니다.

### 프로그래머의 기본 검색 3원칙
1. **검색은 반드시 '구글(Google)'에서 합니다.** (다른 포털 사이트보다 전 세계 개발자들의 기술 데이터가 압도적으로 많습니다.)
2. **검색어 앞에 항상 `python3` 또는 `파이썬3`를 붙입니다.** (오래된 파이썬 2버전 코드가 검색되는 것을 방지합니다.)
3. **가급적 '영어 명사+동사' 조합으로 검색합니다.**

만약 오늘 날짜를 구하고 싶을 때, 한국어로 `파이썬3 오늘 날짜`라고 쳐도 좋은 글이 나옵니다. 하지만 잘 안 나온다면 용기를 내어 `python3 how to get today date` 라고 영어로 적어보세요.

# 27 거인들의 도서관, 공식 문서(Official Docs) 파헤치기

검색 결과 최상단에 자주 뜨는 스택오버플로(Stack Overflow)는 "이 에러 어떻게 고쳐요?" 같은 구체적인 질문에 단답형 해답을 줍니다.
반면, 특정 모듈에 어떤 재미있는 도구들이 더 숨어있는지 전체적으로 쓱 훑어보고 싶다면 **파이썬 공식 문서(Python Documentation)**를 읽는 것이 정석입니다.

* 공식 문서 사이트 주소: `docs.python.org`

구글에 `python3 random module` 이라고 치면 가장 맨 위에 공식 문서가 나타납니다. 만약 다른 잡다한 사이트들이 나와서 짜증 난다면 `site:` 명령어를 써서 파이썬 공식 페이지만 콕 집어서 검색할 수도 있습니다.
* 구글 검색어 예시: `python3 random number site:python.org`

### 공식 문서를 읽는 요령
공식 문서는 두껍고 딱딱한 백과사전 같습니다. 영어로 길게 쓰여있다고 겁먹을 필요 없습니다. 우리의 목표는 모든 문장을 해석하는 것이 아니라, 스크롤을 슉슉 내리면서 나에게 필요한 함수명과 예제 코드를 쏙쏙 뽑아먹는 것입니다.

예를 들어 `random` 모듈 문서를 스크롤하다 보면 다음과 같은 흥미로운 함수들을 발견할 수 있습니다.

* `random.choice(seq)` : 리스트 속 아이템 중 원픽을 무작위로 뽑아줌
* `random.randint(a, b)` : a와 b 사이의 정수를 골라줌 (주사위 느낌!)
* `random.shuffle(x)` : 리스트 안의 순서를 폭탄 맞은 것처럼 뒤죽박죽 섞어버림

이처럼 "이런 함수도 있었네?" 하고 발견하는 재미가 쏠쏠합니다. 막히면 모듈 이름을 찾아 공식 문서로 들어가고, 잘 모르겠으면 스택오버플로를 검색하는 것이 모든 전문가들이 일하는 방식입니다.
