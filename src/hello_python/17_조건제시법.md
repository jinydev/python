# 57 리스트 컴프리헨션: 한 줄로 끝내는 리스트 만들기

수학 시간에 배운 '조건제시법'과 똑같습니다. "이러이러한 조건을 만족하는 원소들을 모아서 집합으로 만들어라"라는 명령을 파이썬 코드로 그대로 번역한 것입니다.

**목표**: 1부터 5까지 숫자를 각각 3배 곱한 리스트 만들기

**코드: 초보자의 방식 (for문)**
```python
result = []
for i in range(1, 6):
    result.append(i * 3)

print(result) # [3, 6, 9, 12, 15]
```
초보자 시절에는 이렇게 세 줄이 필요했습니다. 하지만 컴프리헨션을 쓰면 대괄호 `[]` 안에서 모든 작업이 끝납니다.

**코드: 고수의 방식 (컴프리헨션)**
```python
# [넣을_값 for 변수 in 반복_가능한_데이터]
result = [i * 3 for i in range(1, 6)]

print(result) # [3, 6, 9, 12, 15]
```

### if문까지 한 줄에 구겨 넣기!
이번엔 1부터 10까지 숫자 중에서 **짝수만 골라서 제곱**해 보겠습니다.

```python
# [넣을_값 for 변수 in 데이터 if 조건]
even_squares = [x**2 for x in range(1, 11) if x % 2 == 0]

print(even_squares) # [4, 16, 36, 64, 100]
```
어떤가요? 이 코드는 다른 프로그래밍 언어 사용자들의 부러움을 한 몸에 받는 파이썬만의 아름다운 문법입니다.

# 58 딕셔너리 컴프리헨션: 한 줄로 이름표 붙이기
</div>

리스트를 대괄호 `[]`로 묶어서 하나로 만들었듯이, 딕셔너리도 중괄호 `{}`를 사용하면 단 한 줄로 키(Key)와 값(Value)의 쌍을 뚝딱 만들어 낼 수 있습니다. 

리스트 두 개를 하나로 합쳐서 딕셔너리를 만들 때 가장 많이 쓰이는 마법의 함수 `zip()`과 함께 사용해 보겠습니다. `zip()`은 옷의 지퍼(Zip)를 올리듯, 두 리스트의 같은 위치에 있는 요소들을 나란히 짝지어 줍니다.

**목표**: 과일 이름 리스트와 가격 리스트를 합쳐서 '{과일이름: 가격}' 형태의 딕셔너리 만들기

**코드: 딕셔너리 컴프리헨션과 zip()의 만남**
```python
fruits = ["사과", "바나나", "수박"]
prices = [1000, 2000, 15000]

# {키: 값 for 키_변수, 값_변수 in zip(리스트1, 리스트2)}
menu = {f: p for f, p in zip(fruits, prices)}

print(menu)
# {'사과': 1000, '바나나': 2000, '수박': 15000}
```

또는 앞서 배운 `enumerate()` 함수와 결합해 순서대로 출석 번호를 매기는 딕셔너리를 만들 수도 있습니다.

```python
names = ["펭수", "뽀로로", "루피"]

# {키: 값 for 인덱스, 값 in enumerate(리스트)}
roster = {f"{i+1}번": name for i, name in enumerate(names)}

print(roster)
# {'1번': '펭수', '2번': '뽀로로', '3번': '루피'}
```

컴프리헨션은 파이썬을 파이썬답게(Pythonic) 만들어 주는 최고의 도구입니다. 처음에는 눈에 잘 안 들어오겠지만 자꾸 연습하다 보면 평범한 `for`문보다 훨씬 빠르고 명확하게 리스트와 딕셔너리를 찍어낼 수 있게 됩니다!

## 💻 실습: 딕셔너리 합체 마술

**문제** 두 개의 리스트 `keys = ["이름", "나이", "직업"]` 와 `values = ["코난", 10, "탐정"]` 이 있습니다. 컴프리헨션과 `zip()`을 이용하여 이것을 하나의 딕셔너리인 `profile`로 합쳐보세요.

---
<details>
<summary><b>정답 확인하기</b></summary>

**해답**
```python
keys = ["이름", "나이", "직업"]
values = ["코난", 10, "탐정"]

profile = {k: v for k, v in zip(keys, values)}
```
</details>
