# 부록: 개발자 생존 가이드 - 단골 에러 대처법
</div>

초보자든 전문가든 프로그래밍을 하다 보면 하루에도 수십 번씩 에러(오류)의 붉은 경고창을 마주하게 됩니다. 에러는 여러분의 코드를 망가뜨리는 악당이 아니라, **"여기가 이상해요! 고쳐주세요!"**라고 친절하게 알려주는 조수입니다. 
파이썬에서 가장 자주 마주치는 11가지 에러의 정체와, 그 메시지를 해독하는 법을 알아봅시다.

---

### 디버깅(Debugging)의 2대 황금 원칙
1. **맨 아랫줄의 에러 이름부터 읽어라!** (가장 확실한 힌트입니다)
2. **에러가 났다고 가리키는 화살표(`^`) 주변이나 그 바로 윗줄을 의심하라!**

---

## 1. SyntaxError (문법 에러)
**원인**: 파이썬의 문법 규칙을 어겼을 때 발생합니다. 외국인에게 한국어 문법을 틀리게 말한 것과 같습니다.
* **따옴표나 괄호의 짝을 맞추지 않았을 때** (가장 흔함)
* `if`나 `for` 뒤에 콜론(`:`)을 빼먹었을 때
* 예약어(`True`, `for` 등)나 숫자로 변수 이름을 지으려 할 때

```python
# 에러 발생 예시
print("안녕하세요)  # 닫는 따옴표가 없습니다! (EOL while scanning string literal)
1st_place = "나" # 변수명은 숫자로 시작할 수 없습니다!
```

## 2. IndentationError / TabError (들여쓰기 에러)
**원인**: 파이썬의 생명인 '들여쓰기' 줄이 어긋났을 때 발생합니다.
* 스페이스바(Space) 4칸을 치다가 갑자기 3칸만 쳤을 때
* 스페이스와 탭(Tab)이 눈에 보이지 않게 섞여 있을 때 (TabError)

## 3. NameError (이름 에러)
**원인**: 파이썬이 생전 처음 보는 '이름'을 불렀을 때 발생합니다.
* 변수를 만들지도 않고 쓰려고 할 때
* 변수 이름에 오타가 났을 때 (예: `apple`을 `aple`로 적음)

```python
# 에러 발생 예시
score = 100
print(scroe) # scroe라는 변수는 정의된 적 없습니다! (name 'scroe' is not defined)
```

## 4. AttributeError (속성 에러)
**원인**: 그 데이터(객체)가 가지고 있지도 않은 기능(메서드)을 억지로 쓰려고 할 때 발생합니다.
* 리스트의 `.index()`를 `.indax()`로 오타를 냈을 때
* 정수(int)에 대고 문자열 기능인 `.replace()`를 쓰려고 할 때

```python
# 에러 발생 예시
number = 10
number.append(20) # 숫자에 리스트처럼 항목을 추가할 수 없습니다! ('int' object has no attribute 'append')
```

## 5. TypeError (타입 에러)
**원인**: 기능이나 연산자에 어울리지 않는 '잘못된 종류의 데이터'를 들이밀었을 때 발생합니다.
* 숫자와 문자를 기호(`+`)로 억지로 더하려고 할 때
* 함수가 요구하는 재료(매개변수)의 개수를 너무 적게 주거나 많이 줬을 때

```python
# 에러 발생 예시
print("나는 " + 20 + "살입니다.") # 문자와 숫자를 그냥 더할 수 없습니다! (can only concatenate str to str)
```

## 6. ValueError (값 에러)
**원인**: 타입(종류)은 대충 맞는데, 알맹이가 터무니없는 값일 때 발생합니다.
* `int("100")`은 기꺼이 숫자로 바꿔주지만, `int("안녕")`은 숫자로 바꿀 수 없습니다.

```python
# 에러 발생 예시
age = int("스무살") # '스무살'이라는 한글 요소를 수학적인 숫자로 변환할 도리가 없습니다!
```

## 7. UnboundLocalError (지역 변수 참조 에러)
**원인**: 함수 밖에 있는 전역 변수의 값을 함수 안에서 허락 없이 마음대로 덮어씌우려고 할 때 발생합니다. (파이썬의 엄격한 변수 스코프 규칙 때문입니다)

## 8. KeyError & IndexError (접근 실패 에러)
**원인**: 박스 안을 뒤졌는데 내가 찾는 물건이 없을 때 발생합니다.
* **KeyError**: 딕셔너리에 없는 '키(Key)'를 찾을 때
* **IndexError**: 리스트에 총 3개(0, 1, 2)밖에 없는데 10번째 인덱스를 가져오라고 할 때

```python
# 에러 발생 예시
my_list = ["가", "나", "다"]
print(my_list[5]) # 5번 방은 존재하지 않습니다! (list index out of range)
```

## 9. ModuleNotFoundError (모듈 실종 에러)
**원인**: `import` 로 외부 기능을 불러오려 했으나, 파이썬이 그 모듈 파일을 찾지 못했을 때 발생합니다. (이름에 오타가 났거나, 설치가 안 된 패키지일 확률이 높습니다)

## 10. RecursionError (무한 루프/재귀 에러)
**원인**: 함수가 자기 자신을 계속해서 부르다가 파이썬이 정해둔 한계치(보통 1,000번)를 초과해 뻗어버렸을 때 발생합니다. 종료 조건이 없는 코드를 짰을 때 주로 만납니다.

## 11. ZeroDivisionError (0 나누기 에러)
**원인**: 수학적인 금기, 즉 어떤 숫자를 `0`으로 나누려고 할 때 발생합니다.
```python
# 에러 발생 예시
result = 100 / 0 # 파이썬은 이 계산을 단호히 거부합니다! (division by zero)
```

에러와 친해지는 것이야말로 훌륭한 개발자로 성장하는 가장 빠른 지름길입니다. 에러가 나면 두려워 말고 즐겁게 원인을 찾아 코드를 수정해 보세요!
