# 35 조건이 맞는 한 영원히 달린다, while문

`while`은 영어로 "~하는 동안"이라는 뜻입니다. 즉, "어떤 조건이 참(True)인 동안 계속해서 코드를 반복하라"는 의미를 가집니다.
`if`문이 조건을 확인하고 블록 안의 코드를 **한 번만** 실행한다면, `while`문은 코드를 실행한 후 다시 올라가서 조건이 안 맞을 때까지 **수백, 수만 번** 반복합니다.

### 언제 while문을 쓸까?
정확한 횟수는 모르겠지만, **"특정 상황이 올 때까지 계속해라!"**라고 명령할 때 아주 좋습니다. 
게임을 시작할 때, 사용자가 [시작] 버튼을 누를 때까지 끝없이 로딩 화면을 보여주는 것도 `while`문의 역할입니다.

**코드: 올바른 입력 고집하기**
```python
user_input = ""

# 사용자가 끝이라고 입력하지 '않는 동안' 쳇바퀴를 돌립니다.
while user_input != "끝":
    user_input = input("종료하고 싶으면 '끝'이라고 입력하세요: ")
    print(f"당신이 입력한 말: {user_input}")

print("프로그램이 무사히 종료되었습니다!")
```

위 코드를 실행하고 아무 단어나 입력해 보세요. "끝"이라는 단어를 입력하기 전까지는 절대로 다음 코드로 넘어가지 않고 사용자를 끈질기게 괴롭힐 것입니다.

### for문을 while문으로 바꿔보기
원한다면 `for`문과 똑같은 동작을 `while`문으로 강제로 구현할 수도 있습니다.

**코드: 3번 반복하는 while문**
```python
# for i in range(3): 과 동일한 코드입니다.
count = 0
while count < 3:
    print(f"{count}번째 반복입니다.")
    count = count + 1   # 이 코드가 없으면 변수 값이 변하지 않아 '무한 루프'에 빠집니다!
```
다만 `for`문을 쓰면 훨씬 코드가 깔끔해지므로, **횟수나 범위가 정해져 있을 때는 `for`문을, 상황(조건)이 더 중요할 때는 `while`문을 쓴다**고 기억해 두면 좋습니다.

# 36 흐름을 지배하는 주문: break와 continue

반복문 안에서 우리는 두 가지 강력한 조이스틱(`break`, `continue`)을 조작하여 실행 흐름을 쥐락펴락할 수 있습니다. `for`문과 `while`문 양쪽 모두에서 똑같이 사용할 수 있습니다.

### 1. 비상탈출! break
더 이상 쳇바퀴를 굴릴 필요가 없을 때, 그 즉시 반복문을 박살 내고 **완전히 탈출**해 버립니다.
보통 `if`문과 세트로 쓰여 "만약 목표물을 찾았다면 파괴(break)하고 나가라!"는 식의 명령을 내릴 때 사용합니다.

**코드: 첫 번째 3의 배수만 찾고 끝내기**
```python
numbers = [1, 2, 8, 9, 11, 15]

for num in numbers:
    if num % 3 == 0:
        print(f"찾았다! 3의 배수: {num}")
        break  # 9를 찾자마자 미련 없이 반복문을 부수고 나갑니다. 따라서 15는 검사조차 안 합니다.
```

### 2. 다음 타자 나와! continue
반복문을 완전히 끝내는 것이 아니라, 현재 순서를 여기서 멈추고 **"다음 차례(다음 바퀴)로 즉시 넘어가라"**는 뜻입니다. 특정 불량품만 걸러내고 다음 작업을 이어갈 때 무척 유용합니다.

**코드: 짝수만 걸러내고 홀수만 출력하기**
```python
for i in range(1, 6): # 1부터 5까지
    if i % 2 == 0:    # 짝수라면
        continue      # 아래 코드를 무시하고 곧바로 다음 바퀴(다음 숫자)로 턴을 넘깁니다!
    print(i)          # 1, 3, 5만 출력됩니다.
```

`continue`를 영리하게 사용하면 조건문(`if...else...`) 때문에 코드가 오른쪽으로 자꾸 깊숙하게 들어가는(들여쓰기) 불상사를 막아 깔끔하고 시원시원한 코드를 짤 수 있습니다.
