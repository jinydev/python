# 04 개발자들의 필수 무기: 가상환경(Virtual Environment)

파이썬 설치와 에디터 세팅까지 마쳤다면, 본격적인 코드 작성에 앞서 **"가상환경(Virtual Environment)"**이라는 개념을 꼭 알아두어야 합니다. 가상환경은 현대 프로그래밍 생태계에서 선택이 아닌 필수로 꼽히는 아주 중요한 시스템입니다.

## 1. 가상환경이란 무엇이고 왜 필요한가요?

가상환경은 말 그대로 **"프로젝트(폴더)별로 완전히 격리된 독립적인 파이썬 실행 공간"**을 의미합니다. 

스마트폰에 비유해 볼까요? 우리가 스마트폰에 앱을 깔면 기기 전체(시스템 전역)에 설치됩니다. 만약 `A`라는 프로젝트를 할 때는 카카오톡 1.0 버전이 필요한데, `B`라는 프로젝트를 할 때는 최신 카카오톡 2.0 버전이 필요하다고 가정해 봅시다. 
스마트폰 하나에 두 가지 버전을 동시에 깔 수 없으니, 매번 지웠다가 다시 까는 대참사가 일어날 것입니다.

이런 끔찍한 버전 충돌(종속성 문제)을 막기 위해, **1번 프로젝트만의 파이썬 방**, **2번 프로젝트만의 파이썬 방**을 따로 만들어주는 마법이 바로 가상환경입니다.

- **종속성 충돌 방지**: 각 프로젝트에 딱 맞는 특정 버전의 패키지들을 남의 눈치 보지 않고 마음껏 설치할 수 있습니다.
- **깔끔한 관리**: 내 컴퓨터 전체가 불필요한 패키지들로 더럽혀지는 것을 막아줍니다.
- **쉬운 배포**: 내가 쓰던 가상환경 리스트만 딱 뽑아서 친구에게 주면, 친구도 내 컴퓨터와 100% 똑같은 환경을 1분 만에 세팅할 수 있습니다.

## 2. 파이썬 `venv` 모듈로 가상환경 구축하기

파이썬 3.3 버전부터는 `venv`라는 가상환경 도구가 기본적으로 탑재되어 있어 아주 편리합니다.
터미널(혹은 VS Code 터미널)을 열고, 내 프로젝트 폴더로 이동한 뒤 아래 명령어를 칩니다.

### 1단계: 가상환경 생성하기

```bash
# macOS / Linux (Mac 사용자)
python3 -m venv .venv

# Windows (윈도우 사용자)
python -m venv .venv
```
명령어를 실행하면, 내 프로젝트 폴더 안에 `.venv`라는 이름의 새로운 폴더가 생겨납니다. 여기가 바로 이 프로젝트만을 위한 격리 창고입니다.

### 2단계: 가상환경 켜기 (활성화)
창고를 지었으면 창고 문을 열고 들어가야겠죠? 이것을 활성화(Activation)라고 부릅니다.

```bash
# macOS / Linux (Mac 사용자)
source .venv/bin/activate

# Windows (명령 프롬프트 CMD)
.venv\Scripts\activate.bat

# Windows (파워셸 PowerShell) - VS Code 기본 터미널
.venv\Scripts\Activate.ps1
```

명령어를 치고 나면 터미널 입력창 맨 앞에 `(.venv)`라는 초록색 꼬리표가 붙는 것을 볼 수 있습니다. 
**"성공! 이제부터 네가 설치하는 모든 파이썬 프로그램은 네 컴퓨터 전체가 아니라 이 방 안에만 설치될 거야!"** 라는 뜻을 가진 확실한 입장권입니다.

### 3단계: 가상환경 끄기 (비활성화)
작업이 다 끝나서 방을 나가고 싶다면 무심하게 한 단어만 치면 됩니다.

```bash
deactivate
```
앞에 붙어있던 `(.venv)` 꼬리표가 사라졌다면 완벽하게 방에서 빠져나온 것입니다.

## 3. 설치 패키지 리스트 얼려두기 (Requirements)

가상환경을 켠 `(.venv)` 상태에서 `pip install pandas` 등 유용한 외부 도구들을 설치해 봅니다.
그런 다음, 현업에서 아주 자주 쓰이는 마법사가 있습니다.

```bash
# 이 방에 깔린 모든 패키지 이름과 버전을 텍스트 파일에 기록해 줘!
pip freeze > requirements.txt
```
이렇게 만들어진 `requirements.txt` 파일만 챙겨가면, 다른 컴퓨터나 서버에서도 아래 명령어 한 줄로 완벽히 동일한 가상환경을 복제 조립할 수 있습니다.

```bash
# 기록된 리스트를 보고 똑같이 싹 다 깔아줘!
pip install -r requirements.txt
```

이제 여러분은 파이썬 개발자들이 매일같이 사용하는 가장 스마트한 작업 환경을 온전히 내 것으로 만들었습니다!
