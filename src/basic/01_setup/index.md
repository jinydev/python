# PART 01

## 시작하기

Part 1에서는 본격적인 파이썬 학습에 앞서 개발 환경을 구축하는 방법을 알아봅니다. 파이썬을 컴퓨터에 설치하고, 소스 코드를 작성할 에디터(편집기)를 준비하는 단계입니다. 처음에는 낯설고 번거로울 수 있지만, 한 번 설정해 두면 이후에는 프로그래밍에만 집중할 수 있습니다.
