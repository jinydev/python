# 02 파이썬 제대로 설치했는지 확인하기 & 에디터 준비

여러분의 터미널 혹은 파워셸 창에 `python`을 입력하여 `>>>` 형태의 프롬프트가 표시되었다면, 이는 코드를 칠 때마다 즉시 실행 결과를 반환해 주는 **대화형 환경(Interactive Mode)**으로 성공적으로 진입했다는 뜻입니다.

대화형 셸 사용을 마치고 원래의 커맨드 라인 모드로 돌아가려면, `exit()`를 타이핑한 뒤 `[Enter]`를 누르거나, 윈도우 OS의 경우 `[Ctrl]+[Z]`, macOS의 경우 `[Ctrl]+[D]` 단축키를 누른 후 `[Enter]`를 치면 됩니다.

```text
PS C:\Users\Username> python
Python 3.X.X ...
>>> exit()
PS C:\Users\Username>
```

축하합니다! 이제 본격적인 프로그래밍 학습을 위한 기본 파이썬 엔진 준비가 모두 끝났습니다.

---

> **🛠 파이썬 소스 코드 작성을 위한 에디터 (IDE / Editor)**
> 
> 실제 프로그래밍 업무에서는 파워셸의 흑백 대화창에 한 줄씩 코드를 치지 않습니다. 보통 별도의 코드 에디터를 통해 코드를 쭉 작성한 뒤 `.py` 확장자를 가진 파일로 저장하여 덩어리째 한꺼번에 컴퓨터에게 실행시키는 방식이 가장 널리 쓰입니다.
> 
> 입문자분들께는 다루기 쉽고 속도가 빠른 텍스트 전문 편집기나 파이썬 전용의 통합 개발 환경(IDE) 프로그램 사용을 적극 권장합니다. 이러한 툴들은 코드의 구문 분석(Syntax Highlighting)을 지원하여 변수명이나 내장 함수, 일반 문자열 등을 다채로운 색상으로 입혀주기 때문에 가독성과 개발 효율성을 극대화시켜 줍니다.
>
> ### 💡 추천 에디터: Visual Studio Code (VS Code) 설치하기
> 현재 현업 개발 생태계에서 가장 널리 쓰이는 표준 에디터는 마이크로소프트의 **VS Code**입니다. 가벼우면서도 강력한 확장 프로그램들을 붙여 쓸 수 있어 초보자부터 전문가까지 두루 애용합니다.
> 
> 1. [VS Code 공식 홈페이지(code.visualstudio.com)](https://code.visualstudio.com/)에서 본인의 운영체제(Windows, macOS)에 맞는 설치 파일을 다운로드하고 설치를 마칩니다.
> 2. VS Code를 실행한 후, 좌측 메뉴 바에서 "Extensions(확장)" 뷰 아이콘(네모 블록 4개 모양)을 클릭합니다.
> 3. 검색창에 **"Python"**을 입력하고, Microsoft에서 공식 제공하는 **Python** 확장 패키지를 찾아 설치(Install) 버튼을 누릅니다.
> 4. 이 확장을 설치하면 문법 검사, 자동 완성, 코드 실행 보조 기능들이 추가되어 매우 편리해집니다.
> 
> **맛보기: 간단한 파이썬 소스 파일 만들어서 실행까지 해보기**
> 1. 설치한 VS Code 에디터를 열어 새 문서를 만듭니다.
> 2. `print('Hello!')`라는 구문을 작성해 줍니다.
> 3. 나중에 찾기 편한 디렉터리(예: `내 문서` 폴더 등)를 골라 문서 이름을 `test.py`로 저장합니다. 파이썬 문서는 반드시 끝이 `.py`로 끝나야 합니다.
> 4. VS Code 상단의 메뉴 바에서 **Terminal -> New Terminal**을 클릭하여 터미널 창을 엽니다. (혹은 단축키 `Ctrl + \``)
> 5. 아래쪽 터미널 창에 `python test.py` (또는 Mac의 경우 `python3 test.py`)라고 명령어를 직접 쳐서 실행해 봅니다.
> 6. 화면에 `Hello!`라는 문구가 정상적으로 출력되는 것을 확인합니다.
