# 01 파이썬 설치 가이드

파이썬 기반 애플리케이션을 개발하고 구동하기 위해서는 우선 여러분의 컴퓨터에 파이썬 실행 환경을 갖추어야 합니다.

윈도우(Windows)의 경우 기본적으로 파이썬이 내장되어 있지 않아 사용자가 직접 설치를 진행해야 합니다. 반면, 리눅스(Linux) 및 macOS 시스템에는 보통 파이썬이 사전 설치되어 있지만, 구형 버전(Python 2.x)일 가능성이 높으므로 원활한 실습을 위해 최신 버전(Python 3.x)을 새로 설치하는 것을 권장해 드립니다. 안전한 설치를 위해 가급적 공식 웹사이트를 이용하는 것이 좋습니다.

> **💡 참고**
> 본 가이드는 다수 사용자가 활용하는 윈도우 환경을 기준으로 작성되었으나, macOS 환경에 대한 간략한 설치 및 설정 방법도 함께 안내합니다.

1. **파이썬 공식 웹사이트 접속**
   인터넷 브라우저를 열어 파이썬 공식 다운로드 페이지(https://www.python.org/downloads/)에 접속합니다. 메인 화면에 보이는 'Download Python 3.x.x' 버튼을 눌러 설치 파일을 내려받습니다. 다운로드 시점마다 세부 버전 숫자는 다를 수 있지만 앞자리가 '3'으로 시작한다면 학습에 지장이 없습니다.

2. **설치 프로그램 실행 및 PATH 옵션 활성화**
   다운로드가 끝난 파일(예: `python-3.x.x-amd64.exe`)을 더블클릭하여 실행합니다. 
   **[매우 중요]** 설치 마법사의 첫 화면 맨 아래에 위치한 **'Add Python 3.x to PATH'** 체크박스를 반드시 선택한 후 **'Install Now'**를 누르셔야 합니다. 이 항목을 체크해야 터미널이나 명령 프롬프트에서 `python`이라는 간단한 명령어만으로 실행할 수 있습니다. 만약 이를 누락하면 매번 파이썬이 설치된 전체 폴더 경로를 직접 입력해야 하는 번거로움이 생깁니다.

3. **설치 완료 후 파워셸(PowerShell) 실행**
   설치가 정상적으로 되었는지 점검해 볼 단계입니다. 키보드의 `[윈도우 키] + [R]`을 눌러 '실행' 창을 열고, `powershell`이라고 입력한 뒤 [확인] 버튼을 클릭합니다. (시작 탭의 검색창에서 'powershell'을 찾아 실행해도 동일합니다.)

4. **파이썬 프롬프트(>>>) 확인하기**
   검은색 혹은 파란색 배경의 파워셸 창이 나타나면 `python`이라는 단어를 치고 `[Enter]` 키를 누릅니다. 텍스트 몇 줄로 된 파이썬 버전 정보가 출력되고, 그 아랫줄에 `>>>` 모양의 프롬프트가 표시된다면 파이썬이 완벽하게 설치된 것입니다.

```text
Windows PowerShell

PS C:\Users\Username> python
Python 3.X.X ... on win32
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

> **오류 메시지가 나오나요?**
> 파워셸에서 'python' 명령어를 인식할 수 없다는 내용의 빨간색 오류 텍스트가 뜬다면, 설치 과정에서 'Add Python to PATH' 부분을 체크하지 않고 넘어갔을 가능성이 제일 큽니다. 이럴 때는 제어판의 '프로그램 추가/제거'에서 설치된 파이썬을 완전히 지우고 처음부터 환경 변수 추가 체크박스를 선택하여 재설치하는 방법을 추천합니다.

---

> **💻 macOS 시스템의 파이썬 3.x 설치 및 환경 설정**
>
> 1. 공식 사이트에서 macOS용 파이썬 3 설치 패키지(.pkg)를 받아 실행한 뒤, 화면의 안내에 맞추어 설치를 마무리합니다.
> 2. `[Command] + [Space]` 조합키로 Spotlight 검색을 활성화한 후, '터미널(Terminal)'을 검색하여 켭니다.
> 3. 터미널 창에 `python3`을 입력해 봅니다. (macOS에 изначально 내장된 구버전 파이썬이 있으므로 반드시 `python3`라고 입력해야 합니다.)
> 4. `Python 3.x.x`와 같은 버전 문자열이 뜨면 정상입니다.
>
> **편의 설정 팁: `python` 명령어로 단축하기**
> 매번 굳이 `python3`을 다 치는 것이 번거롭다면 다음의 단축(Alias) 설정을 진행해 보세요.
> 1. 터미널의 커맨드 라인에 `nano ~/.zprofile` (구버전 macOS라면 `open -a TextEdit ~/.bash_profile`)을 입력하여 환경 설정 파일을 열어줍니다.
> 2. 문서의 제일 아랫부분에 `alias python=python3` 이라는 코드를 추가합니다.
> 3. 내용을 저장하고 터미널 프로그램을 완전히 껐다가 재실행합니다.
> 4. 이제 단순히 `python`이라고만 명령을 내려도 최신 버전의 Python 3가 구동되는 것을 볼 수 있습니다.
