# 03 첫 파이썬 프로그램, Hello World!

프로그래밍 튜토리얼을 공부할 때 화면에 "Hello, world!"를 띄워보는 것은 오래된 언어 불문 전통 규칙입니다. 우리도 설치된 파이썬을 활용해 컴퓨터와 첫 인사를 해보도록 합시다.

준비해둔 텍스트 편집기나 IDE 프로그램에서 새로운 문서를 만들고, 하단의 파이썬 스크립트를 작성하여 `hello.py`라는 확장자로 저장해 주십시오.

**에디터 작성 코드: hello.py**
```python
print('Hello, world!')
```

코딩 전용 에디터 환경이라면, 이렇듯 짧은 코드라도 파이썬 문법 체계에 맞춰 예쁜 하이라이팅이 적용되었을 것입니다. 
작성에 성공했다면 터미널 창(또는 파워셸)을 띄우고 파일이 든 디렉터리로 콘솔 위치를 이동한 뒤(`cd`), 파이썬 실행 명령을 내려 코드를 테스트해 보겠습니다.

**결괏값 확인**
```text
PS C:\Users\Username\Documents> python hello.py
Hello, world!
```

화면 콘솔에 `Hello, world!` 문구가 무사히 나타났다면 모든 과정이 완벽합니다. 행여나 원치 않는 에러 문구와 마주하셨다면 아래의 체크리스트를 점검해 보시기 바랍니다.

> **💡 코드가 동작하지 않고 빨간색 오류 메시지가 나오나요?**
> 
> 1. **저장 상태 점검**: 에디터에 타이핑만 완료하고 파일 저장을 잊어버리는 사례가 흔히 발생합니다. 윈도우 단축키 `[Ctrl]+[S]`(macOS라면 `[Cmd]+[S]`)를 활용해 최종 작업물이 확실히 디스크에 저장되도록 해주세요.
> 2. **오탈자 점검**: 텍스트를 감싸는 따옴표나, 바깥 괄호 기호를 하나 덜 썼을 확률이 제일 큽니다. 예를 들어 `print('Hello, world!)` 처럼 뒤쪽 작은따옴표를 빠뜨린다면, 파이썬 인터프리터가 `SyntaxError: EOL while scanning string literal` 등의 문법 위반 에러를 뿜어냅니다.

이제 방금 우리가 작성해 본 코드 한 줄 속 중요한 뼈대들의 의미를 가볍게 확인해 보겠습니다.

*   `print`: 파이썬에 기본적으로 탑재되어 있는 **내장 함수(Built-in Function)**입니다. 모니터로 일정한 데이터를 찍어내(print) 주는 역할을 하며 반드시 영문 소문자를 사용해야 합니다.
*   `()`: 괄호 기호는 해당 함수를 호출하고 실행시킨다는 의미를 지니며, 내부 공간을 이용해 재료(인자)를 던져줍니다. 함수에 쓰인 괄호는 열렸으면 반드시 닫혀야 하는 짝맞춤 규칙을 갖습니다.
*   `'Hello, world!'`: 화면에 실제로 드러나도록 지시한 핵심 **문자열(String)** 자료입니다.
*   따옴표 (`'` 혹은 `"`): "이 안을 채운 내용은 복잡한 파이썬 명령어가 아니고 단순하게 화면에 표출할 글자 뭉치(텍스트)입니다!" 하고 컴퓨터에게 힌트를 주는 구분 기호입니다.

위의 기호들이 각각 부여받은 쓰임새가 어떻게 얽혀 돌아가는지 희미하게나마 윤곽이 잡히시나요? 초반에는 위치나 짝을 헷갈려 에러 메시지를 수시로 경험하겠지만, 직접 반복해서 타이핑해 보면 금방 손과 머리에 자연스럽게 녹아들게 될 것입니다.
