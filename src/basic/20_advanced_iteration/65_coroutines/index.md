# 65 핑퐁 게임하듯 대화하는 함수: 코루틴(`coroutine`)

이전 장에서 배운 제너레이터는 함수의 흐름을 일시 정지하고 밖에 있는 사람(우리가 쓴 메인 코드)에게 짠! 하고 "데이터를 꺼내주는" 멋진 재주(`yield`)를 갖고 있었습니다.
그런데 파이썬 개발자들은 문득 아주 재미있고 기발한 생각을 냈습니다.

*"함수 밖으로 데이터를 꺼내는 것뿐만 아니라, 거꾸로 일시 정지해 있는 함수 안으로 **새 데이터를 쏙 밀어 넣을 수는** 없을까?"*

이 기발한 역발상으로 탄생한 것이 바로 핑퐁(탁구) 게임처럼 밖과 안이 양방향으로 데이터를 주고받으며 통신하는 **코루틴(Coroutine)**입니다!

## 1. 받기만 하는 `yield`

제너레이터에서는 `yield 값` 형태로 응답을 밖으로 보냈었죠? 코루틴에서는 **`변수 = yield`** 형태로 위치를 바꾸어, 함수 밖에서 자기를 향해 던져주는 데이터를 두 팔 벌려 받습니다.

밖에서 이 일시 정지된 코루틴 함수 안으로 새 데이터를 던져 넣을 땐 **`send()`** 라는 강력한 전송 메서드를 사용합니다.

```python
def ping_pong_robot():
    while True:
        # 누군가 밖에서 나한테 데이터를 던지면 그 값을 ball에 쏙 저장합니다.
        ball = yield 
        print(f"야호! 로봇이 [{ball}](을)를 강하게 튕겨냅니다!")

# 코루틴 로봇 전원 켜기
robot = ping_pong_robot()

# [중요!] 로봇을 첫 가동시키기 위해선 준비 과정이 필요합니다.
# 처음에 비어있는 값(None)을 던져서 첫 yield 대기선까지 도착하게 만들어야 합니다!
robot.send(None) 
# (next(robot) 이라고 써도 똑같은 효과가 납니다)

# 자, 이제 준비된 로봇에게 핑퐁 공(데이터)을 밖에서 던져 넣어봅시다!
robot.send("핑")       # 야호! 로봇이 [핑](을)를 강하게 튕겨냅니다!
robot.send("퐁!")      # 야호! 로봇이 [퐁!](을)를 강하게 튕겨냅니다!
robot.send("불꽃 스매쉬!") # 야호! 로봇이 [불꽃 스매쉬!](을)를 강하게 튕겨냅니다!
```

## 2. 핑퐁을 치며 밖으로 응답 뱉기 (산출과 입력을 동시에!)

코루틴의 진짜 마법은 데이터를 받는 것(`yield` 왼쪽에 변수)과 동시에 다른 가공된 값을 밖으로 산출(`yield` 오른쪽에 결과값)할 수 있다는 점입니다.

`반환받는변수 = yield 산출할값` 처럼 양옆으로 적으면, 나에게 들어온 공(입력)을 받아 내부 로직으로 똑똑하게 가공한 다음, 다시 밖으로 스파이크(결과)를 날릴 수 있습니다.

```python
def running_average_bot():
    """들어오는 숫자들을 기억하여 그때그때의 평균을 대답하는 로봇"""
    total = 0
    count = 0
    average = 0
    
    while True:
        # 1. 오른쪽 average(현재 평균)를 밖으로 던져줍니다.
        # 2. 그리고 일시 정지! 누군가 숫자를 send() 하면 그걸 new_number에 저장
        new_number = yield average
        
        # 내부 로직 가동!
        total += new_number
        count += 1
        average = total / count

# 1. 평균 계산기 전원 켜기
avg_bot = running_average_bot()
# 2. 예열하기 (첫 번째 yield 대기선까지 달려서 초기값 0을 받아냄)
print("초기 상태:", avg_bot.send(None)) 

# 3. 숫자들을 밖에서 슉슉 던져주면, 바로바로 뱃속에서 평균을 계산해 대답합니다!
print("10 입력 -> 평균:", avg_bot.send(10)) # 평균: 10.0
print("20 입력 -> 평균:", avg_bot.send(20)) # 평균: 15.0
print("90 입력 -> 평균:", avg_bot.send(90)) # 평균: 40.0
```

## 3. 코루틴의 전원 끄기 (`close`)

위의 핑퐁 로봇들은 무한 루프(`while True`) 대기 상태에 있기 때문에 내버려 두면 프로그램이 끝날 때까지 메모리 한쪽에서 계속 기다립니다. 일이 끝나면 친절하게 전원을 꺼주는 예의가 필요합니다.

```python
# 퇴근할 시간이 되면 로봇을 끕니다.
avg_bot.close()

# 끈 로봇한테 또 데이터를 던지면?
# "더 이상 일 안 해요!" 라는 StopIteration 경고 에러가 터집니다.
# avg_bot.send(100)  (에러 발생!)
```

이 코루틴 특유의 **"정지 -> 응답 -> 재개 -> 통신"** 구조는, 훗날 여러분이 수만 명의 동시 접속자를 처리하는 서버 통신이나 대용량 데이터 비동기 다운로드(파이썬의 마법 비기 `async`/`await`)를 다룰 때 매끄럽게 돌아가게 해주는 가장 거대한 심장부 역할을 합니다!
