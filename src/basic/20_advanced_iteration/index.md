# PART 20 끝없는 데이터의 연금술: 반복자와 제너레이터

파이썬의 `for`문은 매우 편리하지만, 수천만 개의 리스트를 통째로 컴퓨터 메모리에 올려두면 프로그램이 버티지 못하고 뻗어버립니다. 이번 파트에서는 필요한 순간마다 데이터를 **"딱 하나씩만 즉석에서 만들어내는"** 파이썬 고수들의 최강의 무기, 반복자(Iterator)와 제너레이터(Generator), 그리고 코루틴(Coroutine)의 마법을 배웁니다.
