# PART 06 데이터를 한 줄로 꿰어보자, 리스트

만약 학생 30명의 수학 점수를 파이썬에 기록해야 한다면 `score1`, `score2`, `score3`... 이렇게 변수를 30개나 만들어야 할까요? 만약 전교생 1000명의 데이터라면 끔찍한 일이 될 것입니다. 이처럼 수많은データを 하나의 변수 이름표 아래에 기차 칸처럼 줄지어 보관하는 파이썬의 핵심 창고, **리스트(List)**에 대해 파헤쳐 봅니다.
