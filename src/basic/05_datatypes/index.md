# PART 05 자료의 형태, 자료형(Data Type)

프로그래밍에서 다루는 데이터는 그 쓰임새에 따라 알맞은 형태를 가집니다. 요리할 때 고기를 써는 칼과 채소를 다듬는 칼이 다르듯, 파이썬에서도 숫자, 텍스트 등 데이터의 성격에 맞춰 '자료형'을 구분합니다. 이번 파트에서는 문자열을 더욱 다채롭게 조작하는 방법과, 숫자를 세밀하게 구분하는 법, 그리고 사용자의 입력을 직접 받아보는 방법을 배웁니다.
