# PART 07 멈출 수 없는 기계 장치, for 반복문

리스트 안에 수십, 수백 개의 데이터가 담겨 있다고 상상해 보세요. 이것들을 일일이 꺼내어 출력하거나 계산하려면 수백 줄의 똑같은 코드를 타건(打鍵)해야 할 것입니다. 이렇게 반복되는 노동으로부터 우리를 구원해 줄 프로그래밍의 핵심 문법, **`for` 반복문**을 파헤쳐 봅니다.
