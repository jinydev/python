# PART 23 바깥세상과 소통하기: 파일 입출력과 데이터 포맷

지금까지 우리가 만든 변수와 데이터들은 파이썬 프로그램이 꺼지면 허공으로 영원히 사라져 버렸습니다. 이번 파트에서는 우리가 힘들게 계산한 결과물이나 수집한 데이터를 안전하게 컴퓨터 하드디스크에 보관(파일 쓰기)하고, 인터넷이나 다른 프로그램에서 넘어온 복잡한 데이터 형식들(JSON, CSV)을 예쁘게 파이썬 안으로 불러오는(파일 읽기) 실전 파일 통신 기법을 배우게 됩니다.
