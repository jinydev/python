# PART 22 고오급 텍스트 처리: 정규 표현식 (Regex)

크롤링을 하거나 방대한 데이터를 수집하다 보면, 텍스트가 예쁘게 정리되어 있지 않고 쓰레기 문자와 섞여 개판인 경우가 많습니다. 기본 문자열 조작 기능(`replace`, `split`)만으로는 한계가 명확할 때, 이 복잡한 문자열 속에서 원하는 특정 패턴만을 정교하게 추려내어 데이터를 세척하고 가공하는 초강력 마법이 바로 **정규 표현식(Regular Expression, 줄여서 Regex)**입니다. 

문자열에서 마법처럼 원하는 정보만 뽑아내는 탐정의 세계로 들어가 보겠습니다!
