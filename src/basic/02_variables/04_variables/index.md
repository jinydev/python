# 04 값을 기억하는 상자, 변수(Variable)와 바인딩(Binding)

컴퓨터 프로그래밍의 관점에서 '변수'란 어떤 숫자나 문자와 같은 데이터(값)를 임시로 덜어 담아두고 이름을 붙여 놓는 '마법의 상자'와 같습니다.
하지만 엄밀히 말하면 파이썬의 변수는 박스라기보다는, 실제 데이터가 머무는 메모리의 주소를 가리키는 **이름표(주소 레퍼런스)**에 불과합니다. 이처럼 "이름(변수)"과 "데이터(객체)"가 서로 연결되는 과정을 **바인딩(Binding)**이라고 합니다.

우선 아래의 코드를 직접 에디터에 타이핑하고 `variable.py`로 저장한 다음 실행을 거치며 변수가 왜 필요한지 느껴보겠습니다.

**작성할 코드: variable.py**
```python
print('안녕하세요. 제 이름은 파이썬입니다. 나이는 30살이에요.')
```

만일 위 문장에서 시시각각 변할 수 있는 중요 데이터인 '파이썬'이라는 이름과 '30'이라는 나이를 분리해 출력하고 싶다면 출력 함수 내에서 쉼표(`,`)를 쓸 수 있습니다. `print` 명령어에 쉼표로 각 항목을 쪼개서 넘겨주면, 자동으로 띄어쓰기가 적용되어 하나의 자연스러운 문장으로 결합됩니다.

**분리하여 수정한 코드**
```python
print('안녕하세요. 제 이름은', '파이썬', '입니다. 나이는', 30, '살이에요.')
```

이제 이 코드를 한 단계 더 발전시켜 구문 안에 '변수(이름표)'를 도입해 봅시다.

**변수를 적용한 코드**
```python
name = '파이썬'
age = 30

print('안녕하세요. 제 이름은', name, '입니다. 나이는', age, '살이에요.')
```

화면에 출력되는 최종 메시지는 변수를 쓰기 전과 토시 하나 다르지 않습니다. 하지만 이 코드의 재사용성과 유연성은 하늘과 땅 차이로 벌어졌습니다!

방금 작성한 코드 속 `name`과 `age`가 바로 우리가 배울 '변수'입니다. 변수를 선언하는 문법은 직관 그 자체입니다.
`변수명 = 보관하려는 값`

여기서 한 가지 중대한 오해를 짚고 넘어가야 합니다. 파이썬에서의 등호(`=`) 연산자는 수학 시간의 '좌변과 우변이 완벽히 동치이다'라는 의미가 절대로 아닙니다. **"오른쪽에 놓인 데이터 객체에 왼쪽의 변수 이름표를 달아주어라(바인딩하라)"**는 적극적인 행동 명령입니다.

### 파이썬 변수의 핵심: 동적 타입 (Dynamic Typing)
변수가 가지는 매력 중 하나는 한 번 담아둔 값을 언제든 전혀 다른 형태의 값으로 엎어버릴(덮어쓸) 수 있다는 사실입니다. 자바나 C언어 같은 정적 타입 언어와 달리, 파이썬은 변수를 선언할 때 타입을 미리 지정하지 않습니다 (동적 바인딩).

**덮어쓰기 코드**
```python
name = '파이썬'    # 문자열 객체와 바인딩됨
age = 30         # 정수형 객체와 바인딩됨
print('안녕하세요. 제 이름은', name, '입니다. 나이는', age, '살이에요.')

# 데이터 교체 작업! 서로 다른 타입의 값도 아주 자유롭게 재할당할 수 있습니다.
name = '자바'
age = "스물다섯"    # 정수였던 변수에 문자열을 넣어도 문제없습니다.
print('안녕하세요. 제 이름은', name, '입니다. 나이는', age, '살이에요.')
```

결과적으로 문장의 전체적인 틀과 구조는 고정한 채, 상자 속 내용물만 갈아끼우는 방식으로 다채로운 결괏값을 손쉽게 뽑아낼 수 있는 것입니다.

## 🛠 꼭 지켜야 할 파이썬 변수 이름 짓기 규칙
여러분이 마음대로 변수 이름을 지을 수 있지만, 전 세계 파이썬 개발자들이 합의한 몇 가지 권장 표기법(Naming Convention)과 절대규칙이 존재합니다. 

1. **알파벳, 숫자, 언더바(`_`)**로만 구성해야 하며 빈칸이나 특수문자는 쓸 수 없습니다.
2. 변수와 함수의 이름은 **모든 글자를 소문자로 표기하며 띄어쓰기 대신 언더바**를 사용합니다. (예: `user_name`, `age_list`) 이를 스네이크 케이스(Snake Case)라고 부릅니다.
3. 변수 이름의 맨 첫 글자는 절대 **숫자(0~9)로 시작할 수 없습니다.** (예: `1st_place`는 에러 발생)
4. **파이썬 예약어금지**: 구조에 쓰이는 파이썬 고유 문법 단어(`if`, `for`, `True`, `class`, `False`, `and`, `def` 등)는 파이썬이 독점하고 있으므로 여러분의 변수명으로 절대 쓸 수 없습니다.

가상 공간에 변수 이름만 던져놓고 아무런 값을 할당하지 않은 채 호출(`print(student_name)`)하게 되면, 네임스페이스에 해당 식별자가 없어 `NameError` 라는 오류가 발생하니 오타에 항상 주의해야 합니다!
