# 07 간편한 실습 환경, REPL 모드

매번 텍스트 에디터를 켜고 코드를 타이핑한 후 `.py` 확장자로 저장한 다음 셸(터미널)에서 다시 불러와 실행하는 일련의 과정이 귀찮게 다가오신 적 있나요?
문법이 헷갈려 잠깐 테스트해 보고 싶거나 아주 직관적인 연산 결괏값이 필요할 때, 굳이 파일을 만들지 않고도 즉석에서 코드를 입력해 엔터를 치면 곧바로 응답을 받을 수 있는 마법 같은 환경이 존재합니다. 바로 파이썬이 제공하는 대화형 테스트 베드인 **REPL(Read-Eval-Print Loop)**입니다.

자, 터미널(혹은 파워셸)을 열고 무심코 `python`이라고만 타이핑하고 `[Enter]`를 눌러보세요.
화면 상단에 파이썬 버전을 안내하는 문구가 지나간 뒤, 세 개의 꺾쇠인 `>>>` (프롬프트 기호)가 나타나 당신의 다음 지시를 목빠지게 기다릴 것입니다.

이 환경에서는 사용자가 넘겨준 한 줄의 코드를 곧바로 확인(Eval)하여 철저하게 연산한 뒤, 바로 다음 줄에 그 결과값이나 에러를 여과 없이 뱉어냅니다(Print).

**REPL 사용 체험기**
```text
PS C:\Users\Username> python
>>> 10 + 20
30
>>> "안녕" + "하세요"
'안녕하세요'
>>> 10 / 0
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ZeroDivisionError: division by zero
```
위의 마지막 예시처럼 수학적 금기인 '0으로 나누기'를 시도해 보면, 파이썬이 정확히 어떤 부분에서 불편함을 느끼는지(`ZeroDivisionError`) 즉각적으로 피드백을 주므로 문법과 에러를 몸에 익히는 데 최고의 훈련장이라 할 수 있습니다.

REPL에서 볼일을 모두 마쳤다면 당황하지 말고 `exit()`을 입력한 뒤 엔터를 누르면 원래의 검은 셸 화면으로 자연스럽게 귀환할 수 있습니다.
