# 05 사람을 위한 메모, 주석(Comment)

스크립트 언어로 작성된 프로그램은 기본적으로 컴퓨터의 실행을 전제로 한 명령어 모음집입니다. 하지만 프로젝트를 진행하다 보면, 나중에 코드를 살펴볼 나 자신이나 협업하는 팀원들을 위해 소스 코드 곳곳에 친절한 설명을 남겨야 하는 상황이 자주 발생합니다. 이럴 때 빛을 발하는 도구가 바로 '주석(Comment)'입니다.

만약 아무런 안전장치 없이 그냥 평범한 한글 문장으로 코드 중간에 해설을 쓴다면, 이를 해석하지 못한 파이썬 엔진은 즉시 문법 에러(`SyntaxError`)를 뿜어내며 프로그램의 숨통을 끊어버립니다.

**실패하는 사례**
```python
여기는 사용자의 나이를 더하는 로직입니다!
age = 20
```

이러한 불상사를 막기 위해 해시 기호(`#`)를 사용합니다. 코드 입력 도중 `#` 문자가 등장하면, 파이썬은 그 줄에 위치한 `#`부터 문장의 맨 마지막까지 등장하는 모든 글자를 투명인간 대하듯 무시하고 흔적 없이 넘깁니다.

**올바른 주석 활용법**
```python
# 여기는 사용자의 나이를 더하는 로직입니다. 파이썬은 이 텍스트를 철저히 무시합니다.
age = 20
print('나이:', age)  # 실제 파이썬 명령어 우측 끝단에 이렇게 짤막한 메모를 덧붙일 수도 있습니다.
```

메모장의 역할뿐 아니라 주석은 또 다른 훌륭한 용도로 활용됩니다. 내가 짠 코드의 특정 부분을 당분간 실행 목록에서 열외시키고 싶을 때, 코드를 아예 다 지워버리는 대신 앞머리에 슬쩍 `#` 기호만 얹어두면 해당 구간이 비활성화됩니다. 실제 실무에서 까다로운 버그 위치를 추적할 때 지겹도록 사용하는 핵심 기술입니다.

한 줄이 아니라 수십 줄에 이르는 장문의 메모를 코드에 끼워 넣고자 할 때는 타이핑 노가다를 피할 수 있습니다. 매 줄 시작 부분에 `#`을 쳐넣지 말고, 커다란 텍스트 블록 전체의 가장 위쪽과 아래쪽을 따옴표 3개 연속(`'''` 또는 `"""`)으로 병풍 치듯 감싸주면 편합니다.

**여러 줄 주석(블록 주석) 활용법**
```python
"""
애플리케이션 명칭: 날씨 정보 크롤러
최초 작성자: 아무개
핵심 기능: 오늘의 날씨를 모니터에 뿌려줍니다.
"""
print("날씨 정보 크롤러 가동 시작!")
```

**Quiz 1** 프로그램 실행 시 터미널 화면에 "이것은 보입니다" 한 문장만 표시되도록, 2번 라인에 존재하는 출력 줄을 주석 기호를 활용하여 은폐해 보세요.
