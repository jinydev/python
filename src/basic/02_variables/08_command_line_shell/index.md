# 08 개발자의 필수 도구, 명령줄 셸(Shell)

여태껏 파이썬이라는 언어를 다루기 위해 우리는 터미널이나 파워셸이라는 까만 창을 열어 마주해왔습니다. 이처럼 오직 키보드 자판과 텍스트 명령어만으로 컴퓨터에게 일을 시키는 환경을 소프트웨어 세계에서는 **CLI(Command Line Interface) 셸**이라고 지칭합니다.
평상시 우리가 더블 클릭으로 폴더를 여닫는 윈도우의 탐색기 혹은 macOS의 파인더 앱(일명 그래픽 셸, GUI)과 목적 자체는 동일하지만, 그것을 제어하는 방식이 상이할 뿐입니다.

프로그래밍의 고수가 되려면 마우스의 의존도를 줄이고 키보드의 문자 입력만으로 내 컴퓨터 구석구석을 누빌 수 있어야 합니다. 개발자들이 숨 쉬듯이 사용하는 핵심 명령어 5가지를 단숨에 요약해 보겠습니다.

> **💡 참고**: 아래 소개할 명령어 세트는 윈도우 파워셸 환경은 물론이고, macOS 테미널과 리눅스의 셸 환경에서도 완벽히 통용되는 글로벌 표준입니다. 앞으로 나오는 디렉터리(Directory)라는 용어는 우리가 아는 폴더(Folder)와 백 퍼센트 동일한 개념입니다.

1. **현재 내 위치 파악: `pwd` (Print Working Directory)**
   프롬프트가 깜빡이는 현재 지점이 컴퓨터 하드디스크의 어떤 폴더인지 전체 경로(Path)를 텍스트로 찍어줍니다. 미로 같은 폴더 속에서 길을 잃었을 때 치는 나침반입니다.

2. **주변 탐색: `ls` (List Segments)**
   내가 몸담고 있는 현재 폴더(디렉터리) 안에 어떠한 파이썬 파일들이나 하위 폴더들이 놓여 있는지 리스트 형태로 싹 보여줍니다.

3. **공간 이동: `cd` (Change Directory)**
   현재 위치에서 다른 특정 폴더로 자리를 옮길 때 사용합니다. `cd 폴더명`을 치면 해당 폴더 안으로 깊숙이 들어갑니다. 만약 들어간 폴더에서 다시 바깥쪽(상위) 폴더로 빠져나오고 싶을 땐 `cd ..` (점 두 개)를 치시면 됩니다.

4. **파일 복사: `cp` (Copy)**
   특정 파일을 똑같이 하나 더 복제해 냅니다. 문법은 `cp 원본이름 복사할새이름`입니다. 가령 `cp main.py backup.py`라고 명령하면 내용물이 완벽히 똑같은 파일이 하나 더 탄생합니다.

5. **파일 지우기: `rm` (Remove)**
   불필요한 파일을 삭제할 때 꺼내드는 명령어입니다. `rm 지울파일이름` 형태로 씁니다. 단, **윈도우 휴지통 같은 안전장치 없이 이 명령어로 날아간 파일은 영원히 하드디스크에서 사라지므로**, 엔터를 누르기 전 손가락이 덜덜 떨리도록 극도로 조심해야 합니다!

> **✨ 작업 효율을 200% 올려주는 꿀팁**: 명령줄 창에서 지루하게 폴더나 파일명을 처음부터 끝까지 다 치지 마세요! 앞의 두세 글자만 선입력한 후 컴퓨터 키보드의 `[Tab]` 버튼을 톡 누르면 이름이 요술처럼 끝까지 자동 완성됩니다. 피로를 줄여주는 마법의 단축키이므로 반드시 손에 익혀두시길 바랍니다.
