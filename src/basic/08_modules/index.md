# PART 08 누군가 만들어둔 마법의 상자, 모듈

파이썬이 전 세계적으로 가장 인기 있는 언어가 된 비결은 무수히 많은 전 세계의 프로그래머들이 만들어 둔 유용한 도구들을 '레고 블록'처럼 내 코드에 쉽게 끼워 맞출 수 있기 때문입니다. 수천 줄의 코드를 직접 짤 필요 없이, 남들이 견고하게 만들어 둔 부품을 조립하는 강력한 기능, **모듈(Module)**에 대해 배웁니다.
