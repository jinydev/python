# 27 거인들의 도서관, 공식 문서(Official Docs) 파헤치기

구글 검색 시 항상 최상단에 뜨는 **스택오버플로(Stack Overflow)**는 "제 코드의 이 에러 로그를 어떻게 해결하나요?" 같이 지극히 구체적이고 당면한 오류를 뚫는 데 특화된 단답형 지식인 사이트입니다.
그에 반해, 특정 모듈의 동작 원리 전체나 그 안에 숨겨져 있는 다채로운 함수 라인업을 차근차근 훑어보고 싶을 때는 주저 없이 **파이썬 공식 문서(Python Documentation)**를 열람하는 것이 엘리트 개발자의 정석입니다.

* 공식 문서 사이트 주소: `docs.python.org`

구글 검색창에 `python3 random module` 이라고 치면 대체로 첫 번째 결과에 공식 문서 링크가 등장합니다. 만약 검색 결과에 개인 블로그나 사제 사이트들이 난입해서 혼란스럽다면, 구글 특수 검색어인 `site:` 명령어를 동원해 오직 파이썬 공식 사이트 도메인 안의 문서만 쏙쏙 골라낼 수 있습니다.
* 구글 핀포인트 검색 예시: `python3 random number site:python.org`

### 공식 레퍼런스 문서를 똑똑하게 탐독하는 요령
공식 문서는 방대하고 두꺼운 영문 위키백과와 다를 바 없습니다. 빼곡한 영어 텍스트를 마주했다고 지레 겁먹고 브라우저를 닫을 필요는 없습니다. 우리의 목적은 영어 논문을 독해하는 게 아니라, 마우스 휠을 휙휙 내리면서 현재 나에게 필요한 '함수명'이나 '사용 예제 코드 덩어리'만 체리피킹 하듯 쏙쏙 뽑아먹는 것입니다.

이를테면 `random` 모듈 목차를 스크롤하며 내리다 보면 아래와 같이 구미가 당기는 유용한 함수들을 연달아 발견할 수 있습니다.

* `random.choice(seq)` : 무작위 리스트 꾸러미 속에서 단 하나의 아이템을 운에 맡겨 뽑아냅니다.
* `random.randint(a, b)` : 숫자 a와 b 범주 내에 있는 정수 하나를 뱉어냅니다 (주사위나 랜덤 대미지 구현에 딱!).
* `random.shuffle(x)` : 깔끔하게 정렬된 리스트 안의 순서를 폭탄을 터트린 것처럼 무자비하게 섞어버립니다.

이처럼 "오, 이런 편의 기능도 이미 구현되어 있었네?" 하고 모듈의 보석을 발굴하는 쏠쏠한 재미가 있습니다. 개발을 하다 벽에 부딪히면 일차적으로 모듈 이름을 가지고 공식 문서를 가볍게 뒤져보고, 그래도 원인을 도통 모르겠다면 스택오버플로의 집단 지성에 질문을 던지는 것이 현업 프로그래머들의 일상적인 업무 루틴입니다.

**Quiz 2** 내 손안에 든 트럼프 카드 패 `cards = ["A", "J", "Q", "K"]` 가 있습니다. `random.shuffle()` 을 구동시켜 이 배열의 순서를 예측할 수 없게 뒤섞어버린 뒤, 다시 바뀐 패의 상태를 출력해 보세요.

```python
import random

# 문제 1의 코드 작성 영역


# 문제 2의 코드 작성 영역
cards = ["A", "J", "Q", "K"]

```

<summary><b>모범 답안 보기</b></summary>

**풀이 1**
```python
import random
lucky = random.randint(1, 10)
print("오늘 당신의 행운 번호:", lucky)
```

**풀이 2**
```python
import random
cards = ["A", "J", "Q", "K"]
# 주의: shuffle 함수는 별도의 return 값 없이 기존 원본 리스트 자체의 심장을 뒤틀어 섞어버립니다.
random.shuffle(cards)
print("완전히 뒤죽박죽 섞인 카드:", cards)
```
