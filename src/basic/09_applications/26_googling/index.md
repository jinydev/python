# 26 막힌 코드를 뚫어주는 일등 공신: 구글링(Googling)

프로그래밍을 하다 보면 백이면 백 "현재 시각을 초 단위까지 어떻게 불러오지?", 혹은 "리스트 안의 아이템들을 무작위로 섞으려면 어떤 함수를 써야 할까?" 같은 장벽에 수시로 부딪히게 됩니다. 이럴 때 개발자들의 가장 든든하고 강력한 무기는 다름 아닌 구글(Google) 검색창입니다.

### 프로그래머를 위한 구글 검색 3대 황금 수칙
1. **검색 포털은 무조건 '구글(Google)'로 통일합니다.** (네이버나 다음과 달리 전 세계 수천만 개발자들의 문제 해결 데이터가 방대하게 누적되어 있습니다.)
2. **검색어 맨 앞에는 항상 `python3` 또는 `파이썬3`라는 키워드를 붙여둡니다.** (이제는 쓰이지 않는 구버전 파이썬 2.x 체계의 낡은 코드가 섞여 나오는 참사를 예방합니다.)
3. **가급적이면 한국어보다는 '영단어 조합(동사+명사)'으로 검색하는 습관을 들입니다.**

예컨대 오늘 날짜 구하는 법을 알고자 할 때, 한국어로 `파이썬3 오늘 날짜 구하기`라고 쳐도 훌륭한 국내 오픈소스나 블로그 글이 뜰 것입니다. 하지만 원하는 결과가 바로 보이지 않는다면 머뭇거리지 말고 `python3 how to get today date` 라고 영문 검색을 시도해 보세요. 정보의 양과 질이 차원이 달라집니다.

**웹에서 퍼온 코드 검증하기**
스택오버플로나 기술 블로그에서 그럴싸한 코드 조각(Snippet)을 발견했다면 눈으로만 대충 읽고 넘기지 말고 무조건 대화형 셸(REPL)이나 실제 스크립트 파일에 복사해 와서 직접 돌려봐야 합니다.

검색한 코드 조각을 바로 REPL에서 한 줄 실행해 봅니다.
```python
>>> datetime.date.today()
Traceback (most recent call last): ...
NameError: name 'datetime' is not defined
```
만약 이렇게 시뻘건 에러 메시지가 떴다고 해서 당황할 필요가 전혀 없습니다! 내가 긁어온 예제 코드의 맨 위쪽을 다시 꼼꼼히 훑어보세요. 분명 소스 코드 어딘가에 `import datetime` 이라는 핵심적인 한 줄이 빠져있었을 것입니다. 이 모듈 호출 구문을 보충해 주고 다시 실행하면 에러 없이 완벽하게 작동할 것입니다.

```python
>>> import datetime
>>> print(datetime.date.today())
2026-03-15
```
