# PART 09 프로그래머의 진짜 능력, 구글링과 공식 문서 활용하기

모든 문법과 함수를 머릿속에 완벽히 외우고 있는 프로그래머는 이 세상에 단 한 명도 없습니다. 실력 있는 개발자란 머리가 똑똑한 사람이 아니라, **'내가 원하는 것을 어디서, 어떻게 찾을지 아는 사람'**입니다. 스스로 문제를 해결하는 자생력을 기르기 위해, 프로그래밍의 가장 중요한 기술인 '검색(Googling)'과 공식 문서 활용법을 배웁니다.
