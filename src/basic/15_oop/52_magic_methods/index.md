# 52 파이썬 코어의 은밀한 마법진: 매직 메서드(Magic Method)

수많은 메서드 중에서도 유독 앞뒤로 언더바가 두 개씩 장착된 모양새(`__`)를 한 녀석들을 묶어 매직 메서드라고 부릅니다. 이들은 굳이 내가 소리 내어 `orc_warrior.뭐시기함수()`라고 번거롭게 호출하지 않아도, **특수한 조건이 달성되면 파이썬 엔진이 알아서 눈치껏 백그라운드에서 발동**시켜주는 매우 신비롭고 편리한 마법입니다.

### 1. 진정한 객체 창조주: `__new__`
클래스를 호출해 인스턴스를 만들 때, 사실 가장 먼저 물밑에서 발동되는 진짜 생성자는 `__new__`입니다. 이 녀석이 텅 빈 메모리 공간(객체)을 먼저 할당해 주어야, 비로소 아래의 `__init__`이 그 공간에 속성을 채워 넣을 수 있습니다.

### 2. 탄생의 순간을 기리는 마법: `__init__` (초기화)
`__new__`가 만들어준 빈 인스턴스가 세상 빛을 보며 튀어나오는 그 찰나의 순간, 딱 한 번 자동 실행되는 '초기화(Initialize) 전용' 메서드입니다. 객체가 스폰될 때마다 귀찮게 밖에서 일일이 속성값을 주입할 필요 없이, 태어남과 동시에 강제적으로 필수 정보(이름, 체력 등)를 세팅받도록 족쇄를 채워놓습니다.

### 3. 운명을 다했을 때: `__del__` (소멸자)
인스턴스의 사용이 완전히 끝나고 파이썬의 가비지 컬렉터(청소부)에 의해 메모리에서 삭제되기 직전에, 마지막 유언을 남기듯 자동으로 실행해 주는 소멸자 메서드입니다. 주로 연결된 네트워크 리소스를 안전하게 끊을 때 사용합니다.

### 4. 깔끔한 자기소개 마법: `__str__`
멀쩡한 인스턴스를 무턱대고 `print()` 에 밀어 넣으면 뜻 모를 메모리 주소(깨진 글자 모양)가 출력되곤 합니다. 이때 이 마법을 걸어두면 "나를 화면에 그릴 땐 이렇게 예쁜 문장 포맷으로 변환해서 보여주렴" 하고 친절한 자기소개 멘트를 반환하도록 통제할 수 있습니다.

### 보너스: 다이어트 마법 `__slots__`
파이썬의 각 인스턴스는 나중에라도 자유롭게 속성을 무한히 추가할 수 있도록 내부에 `__dict__` 라는 커다란 해시 테이블을 몰래 들고 다닙니다. 무척 유연하지만, 수십만 개의 데이터 객체를 찍어낼 땐 메모리 소모의 주범이 됩니다.
클래스 선언 직후 `__slots__ = ['이름', '체력']` 같은 리스트를 적어두면, 파이썬이 거대한 테이블 대신 딱 필요한 칸만 고정으로 파주어 **메모리 사용량을 획기적으로 줄여주는** 고수들의 테크닉입니다.

**코드: 흑마법이 깊게 깃든 궁극의 용사 클래스**
```python
class FantasyHero():
    # 영웅이 탄생의 울음을 터뜨리는 순간, 이름과 직업을 필수로 입력받도록 룰을 짭니다.
    def __init__(self, char_name, char_job):
        self.name = char_name     # 막 스폰된 녀석(self)의 이름칸에 건네받은 변수를 장착시킵니다.
        self.job = char_job
        print(f"빰빠밤! 눈부신 빛의 전사 {self.name} 님이 서버에 새로 강림하셨습니다!")

    # 이 영웅 객체를 print()로 냅다 찍을 때 화면에 노출시킬 폼나는 명함(문구)을 세팅합니다.
    def __str__(self):
        return f"[{self.job}] Lv.1 겁 없는 초보자 {self.name}"

# 영웅이 메모리상에 소환되는 바로 이 1초, __init__ 마법진이 폭발적으로 가동됩니다!
my_new_hero = FantasyHero("아더왕", "성기사")

# 객체 자체를 그냥 print에 들이밀면, 파이썬이 은밀하게 __str__ 마법을 꺼내 문구를 치환해 버립니다.
print(my_new_hero)
```

**콘솔 출력창**
```text
빰빠밤! 눈부신 빛의 전사 아더왕 님이 서버에 새로 강림하셨습니다!
[성기사] Lv.1 겁 없는 초보자 아더왕
```
여기까지 잘 따라오신 여러분은, 흩어진 데이터와 함수들을 근사하게 하나의 객체로 빚어내어 복잡한 현실 세계를 가상 코드로 멋지게 건축할 수 있는 어엿한 파이썬 조형사가 되었습니다!
