# 67 줄서기와 쌓기의 미학: 스택, 큐, `deque`, `heapq`

컴퓨터가 수많은 일들을 빠르고 에러 없이 처리할 때는, 메모리에 들어오는 데이터를 **'어떤 규칙으로 줄 세울 것인지'**가 엄청나게 중요합니다. 파이썬이 제공하는 특급 **데이터 줄서기 도구**들을 알아봅시다!

## 1. 스택(Stack)과 큐(Queue)의 기초

- **스택(Stack)**: 프링글스 감자칩 통을 상상해 보세요! 밑이 꽉 막힌 좁은 통 모양이라, **제일 마지막에 넣은 데이터가 제일 먼저 나옵니다.** (LIFO: Last-In, First-Out)
- **큐(Queue)**: 놀이공원에 줄 서는 것을 생각하면 됩니다. 통의 위아래가 뚫려있어, **가장 먼저 줄을 선 데이터가 가장 먼저 놀이기구를 타고 나갑니다.** (FIFO: First-In, First-Out)

파이썬의 기본 리스트(`.append()`, `.pop()`)를 이용해 대충 흉내 낼 수도 있지만, 파이썬은 진짜 실무 프로들이 쓰는 멋진 툴을 따로 챙겨뒀습니다.

---

## 2. 양쪽이 뻥 뚫린 고속도로 파이프: `collections.deque`

양쪽으로 자유롭게 들어오고 나갈 수 있는 마법의 파이프 큐를 **Deque**(데크)라고 부릅니다. 일반 리스트에서 맨 앞의 데이터를 빼거나 넣는 작업(`.insert(0, X)`)은 엄청나게 느리지만, `deque`는 아주 **빛의 속도로 앞뒤 양방향 어디서든 데이터를 넣고 뺄 수 있습니다!** 보통 큐를 구현할 땐 무조건 이것을 씁니다.

```python
from collections import deque

# 양쪽이 뚫린 파이프(데크) 만들기
pipe = deque([2, 3])

pipe.append(4)     # 오른쪽(보통)으로 밀어 넣기
print(pipe)        # deque([2, 3, 4])

pipe.appendleft(1) # 특별 기능! 왼쪽(맨 앞)으로 강제 밀어 넣기!
print(pipe)        # deque([1, 2, 3, 4])

pipe.popleft()     # 왼쪽(맨 앞)에서 가장 먼저 서 있는 놈 빼기!
print(pipe)        # deque([2, 3, 4])
```
이 녀석은 `pipe.rotate(1)` 기능도 있어서 마치 회전초밥 기계나 컨베이어 벨트처럼 데이터를 뱅글뱅글 섞어 돌릴 수도 있답니다!

## 3. 실전 정밀 줄서기 통제: `queue` 모듈

`deque`가 속도에 미친 녀석이라면, 내장 `queue` 모듈은 말 그대로 대기열을 세우는 깐깐한 전문가 도구 상자입니다. 특히, 여러 작업이 동시에 돌아가는 환경에서 **수용 인원(용량)이 꽉 차거나 텅텅 비었을 때를 완벽하게 통제**해 줍니다. 

```python
import queue

# 최대 2명만 설 수 있는 깐깐한 줄(Queue)을 만듭니다!
q = queue.Queue(maxsize=2)

q.put(1) # 대기열 줄 서기!
q.put(2) # 줄 서기!

print("꽉 찼나요?", q.full())  # True
print("몇 명 있나요?", q.size()) # 2

# 맨 앞사람 빼기
print(q.get()) # 1번 데이터가 볼일을 보러 나감 (빈자리가 생김)
```

## 4. 가장 작은 녀석만 쏙쏙 편애하기: `heapq` 모듈

만약 커다란 상자 안에 무작위로 여러 숫자가 마구잡이로 섞여 있는데, 계속해서 "상자 안에 있는 것 중 **가장 작은 놈** 당장 나와!"라고 지속적으로 닦달해야 한다면 어떨까요? 뽑을 때마다 리스트를 전체 정렬(`sort()`)하는 건 무식하고 느린 행동입니다. 

**`heapq` (힙 큐)** 모듈은 이럴 때 쓰는 전용 정렬 마법 상자입니다.

```python
import heapq

# 마구 섞인 숫자들의 모임
box = [20, 10, 30, 50, 40]

# 1. 힙 정렬 구조로 변신! (파이썬이 보이지 않는 마법의 트리 구도로 재배치합니다)
heapq.heapify(box)
print(box) 
# [10, 20, 30, 50, 40] -> 무조건 제일 앞에 '가장 작은 값'이 언제나 튀어나옵니다!

# 2. 제일 작은 놈 나와! (heappop)
print(heapq.heappop(box)) # 10이 빠져나옴! (빠져나오면 2등이 1등 자리로 대기 탐)
print(heapq.heappop(box)) # 20이 빠져나옴!

# 3. 새로운 놈 추가! (heappush)
# 박스에 15를 던져 넣으면, 알아서 자기 자리를 찾아 들어가 대기합니다.
heapq.heappush(box, 15) 
print(heapq.heappop(box)) # 15가 스멀스멀 1등으로 빠져나옴!
```
숫자를 막 던져 넣어도, 늘 **가장 우선순위가 높은(값이 작은) 데이터가 항상 출구(인덱스 0) 앞에 즉각 대기**하도록 유지해주는 초강력 우선순위 정렬 상자랍니다!
