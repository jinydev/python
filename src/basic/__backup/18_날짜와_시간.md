# 59 datetime 모듈: 시각(Point in Time) 다루기
</div>

### 현재 시각 가져오기
스마트폰에서 시계를 보듯 파이썬 코드 세상의 현재 시각을 확인할 수 있습니다.

**REPL 실습**
```python
>>> import datetime
>>> now = datetime.datetime.now()
>>> now
datetime.datetime(2023, 10, 24, 15, 30, 0, 123456)
```
출력순서는 왼쪽부터 차례대로 `연, 월, 일, 시, 분, 초, 마이크로초`입니다.

### 과거와 미래의 특정 시점 지정하기
타임머신을 타고 과거로 가거나 미래 특정 날짜의 알람을 맞추는 것처럼, 프로그래머가 임의로 시간을 지정하여 인스턴스를 생성할 수 있습니다.

**REPL 실습**
```python
>>> new_year = datetime.datetime(2024, 1, 1)
>>> new_year
datetime.datetime(2024, 1, 1, 0, 0)
```

### 시각과 시각 빼기 (남은 디데이 구하기)
새해 첫날까지 시간이 얼마나 남았는지 궁금할 때는 미래 시점(`new_year`)에서 현재 시점(`now`)을 빼주기만 하면 됩니다.

**REPL 실습**
```python
>>> d_day = new_year - now
>>> d_day
datetime.timedelta(days=68, seconds=30600, microseconds=876544)
>>> print(f"새해까지 {d_day.days}일 남았습니다!")
새해까지 68일 남았습니다!
```

이 연산의 결과는 `datetime` 타입이 아닙니다. 두 시점 사이의 "길이(기간)"를 나타내는 또 다른 주인공, **`timedelta`** 타입입니다.

## 💻 실습: 디데이 계산기

**문제** 내 생일(또는 임의의 미래 날짜)을 담은 `birthday` 변수(예: 2024년 12월 25일)를 만들고, 오늘부터 며칠이 남았는지 숫자만 출력해 보세요.

<details>
<summary><b>정답 확인하기</b></summary>

**해답**
```python
import datetime

# 올해 크리스마스를 목표로 설정!
birthday = datetime.datetime(2024, 12, 25)

# 두 날짜의 차이를 구한 다음 '.days'를 통해 일수만 추출합니다.
left_days = (birthday - today).days

```

# 60 timedelta: 시간(Duration) 더하고 빼기
</div>

`datetime.datetime`이 달력에 핀을 꽂은 **특정 좌표(시각)**라면, `datetime.timedelta`는 하루, 한 달, 백 일 같은 **길이(시간)**를 의미합니다.

특정 시각 좌표에 길이를 더하면 미래의 좌표를 알아낼 수 있습니다!

### 100일 기념일 파워 계산
우리 커플이 오늘 사귀기 시작했다면, 100일 기념일은 정확히 언제일까요?

**REPL 실습**
```python
>>> import datetime
>>> today = datetime.datetime.now()

# 100일이라는 '길이'를 만듭니다.
>>> hundred_days = datetime.timedelta(days=100)

# 오늘(시각) + 100일(길이) = 미래의 날짜(시각)
>>> anniversary = today + hundred_days
>>> print(f"우리의 100일은 {anniversary.year}년 {anniversary.month}월 {anniversary.day}일!")
우리의 100일은 2024년 2월 1일! (결과는 오늘 날짜에 따라 다릅니다)
```

### 아침 9시로 시간 강제 고정하기 (`replace`)
특정 디데이나 알람의 기준이 늘 '오전 9시 정각'이라면, 날짜에 더하기 연산을 하기 전에 기본 시각을 오전 9시로 교체(`replace`)해 두면 아주 편리합니다.

**REPL 실습**
```python
# 지금 시간에 상관없이 오직 '시, 분, 초'만 09:00:00 으로 강제로 덮어씌웁니다.
>>> today_morning = datetime.datetime.now().replace(hour=9, minute=0, second=0)

# 여기서 하루를 더하면 아주 깔끔하게 내일 아침 9시를 구할 수 있습니다.
>>> tomorrow_morning = today_morning + datetime.timedelta(days=1)
```

이처럼 날짜와 시간의 덧셈 뺄셈은 `datetime` 클래스와 `timedelta` 클래스의 찰떡 궁합으로 완벽하게 제어할 수 있습니다.

## 💻 실습: 마감일 자동 연장기

**문제** 오늘 밤 11시 59분 59초를 나타내는 `deadline` 변수를 만드세요. 그 다음, `deadline`에 정확히 **7일**을 더 연장한 `new_deadline` 변수를 만들고 출력해 보세요.

<details>
<summary><b>정답 확인하기</b></summary>

**해답**
```python
import datetime

# 1. 오늘의 날짜를 기반으로 밤 11:59:59 로 세팅합니다.
deadline = datetime.datetime.now().replace(hour=23, minute=59, second=59)

# 2. 7일(길이)을 더해줍니다!
new_deadline = deadline + datetime.timedelta(days=7)

print(f"새로운 마감기한은 {new_deadline} 입니다.")
```
</details>
