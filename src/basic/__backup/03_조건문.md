# PART 03 구조적인 흐름 제어, 조건문

지금까지 배운 변수와 데이터 타입이 프로그래밍의 '재료'였다면, 지금부터 다룰 제어문은 재료들을 요리하는 '레시피'와도 같습니다. 파이썬이 단순히 위에서 아래로 순서대로만 작동한다면 똑똑한 프로그램을 만들 수 없습니다. 상황에 따라 다르게 행동하도록 지시하는 가장 기본적인 제어 도구, '조건문(if문)'에 대해 집중적으로 알아봅니다.

# 09 상황에 따른 행동 지침, if문

우리가 사용하는 대부분의 프로그램은 사용자의 선택이나 주변 상황에 맞춰 다르게 작동합니다. 쇼핑몰에서 잔액이 충분하면 결제 성공 창을, 부족하면 잔액 부족 알림을 띄우는 식입니다. 파이썬에서는 이러한 분기 처리를 `if`문이라고 부릅니다. 

간단한 예시를 통해 구조를 살펴보겠습니다. 새 파일을 `if_test.py`로 만들고 아래의 코드를 작성해 봅니다.

**코드: if_test.py**
```python
members = 4
pizza_slices = 8

if members <= pizza_slices / 2:
    print('1인당 2조각씩, 평화로운 피자 파티입니다!')

if members > pizza_slices:
    print('피자 조각이 부족해요. 가위바위보를 준비합시다!')
```

위 코드를 실행해 보면 `members`(4)가 `pizza_slices / 2` (4)보다 같거나 작다는 조건이 참이 되므로 첫 번째 메시지만 화면에 출력됩니다. 

if문의 기본 공식은 아래와 같습니다.

1. **`if` 키워드**: "만약~" 이라는 조건의 시작을 알립니다.
2. **조건식**: 코드를 실행할지 말지 결정하는 판단 기준입니다. (예: `members > pizza_slices`)
3. **콜론(`:`)**: 조건 분명의 끝을 알리는 필수 기호입니다. 파이썬에게 "이제부터 조건이 맞으면 할 일을 적을게"라고 예고하는 셈입니다.
4. **들여쓰기(Indentation)**: `Space` 키 4번(또는 `Tab`)을 이용해 들여쓰기를 합니다. 들여쓰기된 내용만이 if 조건의 영향을 받습니다.
5. **실행할 코드**: 조건식이 사실(참)일 때만 작동하는 진짜 명령입니다.

if 뒤의 조건식이 거짓이라면 파이썬은 해당 코드들을 통째로 무시하고 안전하게 그 다음 코드로 넘어갑니다. 부등호의 방향이나 변수에 들어간 숫자를 요리조리 바꿔보며 테스트하면 흐름을 빠르게 익힐 수 있습니다.

# 10 진실게임의 규칙, 조건식

if문의 핵심은 결국 `if` 키워드 바로 뒤에 오는 **'조건식'**입니다. 이 식은 반드시 계산을 거치고 나면 `True`(참) 또는 `False`(거짓) 둘 중 하나의 진리에 도달해야만 합니다.

조건식을 이루는 가장 흔한 재료는 두 값의 크기를 비교하는 '비교 연산자'와 논리적인 결합을 돕는 '논리 연산자(Boolean Operator)'들입니다.

파이썬 대화형 셸(REPL)을 켜고 직접 비교해 보겠습니다.

**크기 비교하기**
```text
>>> 5 < 10
True
>>> 20 > 50
False
```

가장 헷갈리기 쉬운 것은 '같거나 크다/작다'의 표현식입니다. 컴퓨터 자판에는 $\le$ 기호가 없으므로 `=`를 뒤에 붙여서 `>=` 나 `<=` 라고 표기해야 합니다. 실수로 `=<` 와 같이 순서를 뒤집으면 문법 에러가 발생하니 주의하세요.

또 하나 매우 중요한 규칙이 있습니다!
파이썬에서 두 문자나 숫자가 **'똑같다'**고 물어보고 싶을 때는 등호를 두 번 연속으로 쓴 `==` 기호를 사용해야 합니다.

```text
>>> 100 == 100
True
>>> 10 = 10
SyntaxError: can't assign to literal
```

앞에서도 배웠듯 파이썬에서 하나짜리 `=`은 단순히 "오른쪽 값을 왼쪽에 집어넣어라(대입)"는 뜻입니다. 비교의 목적으로 쓰면 에러가 폭발합니다.
반대로 '서로 다르다'를 의미하려면 `!=` 기호를 사용합니다. (`!` 표시는 프로그래밍에서 부정의 의미를 자주 띱니다.)

**문장 여러 개를 엮기: 논리 연산자**
조건을 까다롭게 조합해야 할 때, 파이썬은 영어 문법처럼 자연스러운 `and`, `or`, `not`을 제공합니다.

*   `and` (그리고): 양쪽 조건이 **모두** 완벽히 `True`일 때만 전체를 `True`로 인정합니다.
*   `or` (또는): 양쪽 중 **단 하나라도** `True`라면 관대하게 전체를 `True`로 만들어줍니다.
*   `not` (반대): 기존 조건의 결과를 정반대로 뒤집습니다. (청개구리 연산자)

```text
>>> score = 85
>>> rank = 2
>>> score > 80 and rank <= 3  # 두 조건을 모두 만족하므로 True
True
>>> not (score > 90)          # 90점이 넘지 '않는' 것이 맞으므로 True
True
```

# 11 묶음 단위로 움직이는 코드, 블록(Block)

파이썬 코드에서 들여쓰기된 한 덩어리의 구역을 '블록'이라고 부릅니다.
블록은 하나의 통제권 아래 놓여, 조건이 실행되면 블록 전체 코드가 차례대로 실행되고, 조건이 맞지 않으면 통째로 건너뛰어집니다.

**코드 예시**
```python
if True:
    print("이곳은 하나의 블록입니다.")
    print("이것도 같은 블록 소속입니다.")
    print("들여쓰기가 유지되는 한 모두 운명 공동체입니다.")
print("들여쓰기가 끝났으므로, 여기는 블록 바깥의 딴 세상입니다.")
```

블록에 있어 가장 중요한 절대 원칙은, **"어떤 일이 있어도 같은 블록 내에서는 들여쓰기 칸 수가 완벽히 100% 일치해야 한다"**는 것입니다. 실수로 스페이스바를 한 칸 더 치거나 덜 쳤다면 파이썬은 즉시 가차 없는 `IndentationError`(들여쓰기 에러)를 토해냅니다.

물론, 큰 블록 안에 작은 블록을 마트료시카 인형처럼 중첩해서 넣을 수도 있습니다.

**블록 중첩 예시**
```python
if True:
    print("첫 번째 바깥 블록 입장")
    
    if False:
        print("안쪽 블록 1 - 이 부분은 거짓이므로 무시됩니다.")
    
    if True:
        print("안쪽 블록 2 - 조건을 만족했으므로 이것은 실행됩니다.")

print("모든 if 흐름 완전 종료!")
```

위의 예시처럼 `if` 블록 안에서 다시 `if`문을 시작하면, 이전보다 한 단계(4칸 추가) 더 들여쓰기를 진행하여 새로운 세부 블록을 형성합니다. 안쪽 블록은 항상 가장 가까운 바깥 블록의 통제를 받기 때문에 바깥 블록의 조건이 `False`로 막혀버리면 그 안에 있는 조건이 제아무리 참이라도 절대 빛을 볼 수 없습니다.

# 12 모든 경우의 수를 처리하기: if - elif - else

`if`문만으로 만든 프로그램은 조건에 맞지 않을 경우 침묵해버립니다. 하지만 실전에서는 조건이 맞지 않은 나머지 경우(Otherwise)에 대해서도 지시를 내려야 할 때가 많죠. 이를 위해 `else`가 존재합니다.

`else`는 `if` 뒤에 그림자처럼 따라붙으며 **"앞의 조건이 모조리 틀렸을 때, 무조건 마지막에 이 코드를 실행해라"**라는 뜻을 지닙니다. 구조상 `else` 뒤에는 조건식이 따로 붙지 않으며 콜론(`:`)만 찍어줍니다.

**숫자 맞추기 예제**
```python
guess = 7
answer = 7

if guess == answer:
    print("정답입니다!")
else:
    print("아쉽네요. 다음 기회에!")  # 앞의 조건이 다 틀릴 경우 무조건 실행
```

세상 일이 항상 A 아니면 B로 예쁘게 두 갈래만 있는 것은 아닙니다. 신호등만 해도 빨간불, 노란불, 초록불로 분기하죠. 이때 `else` 안에서 또다시 `if-else`를 중첩하기 시작하면, 들여쓰기가 계속 깊어지면서 코드가 계단 모양으로 끝없이 오른쪽으로 빨려 들어가는 끔찍한 사태(스파게티 코드)가 발생합니다.

이런 상황을 우아하게 해결해주는 마법의 키워드가 바로 **`elif`** (else if의 줄임말)입니다.

**신호등 예제 구현하기**
```python
traffic_light = "노랑"

if traffic_light == "초록":
    print("안전하게 건너세요.")
elif traffic_light == "노랑":
    print("서둘러 건너거나 멈출 준비를 하세요.")
elif traffic_light == "빨강":
    print("절대 멈춰!")
else:
    print("신호등 고장! 주변을 잘 확인하세요.")
```

`elif`는 여러 조건을 동등한 들여쓰기 선상에서 1열 종대로 늘어놓을 수 있어 가독성을 극대화합니다. 파이썬은 위에서부터 한 줄씩 검사하다가, 조건이 맞는 곳을 단 하나라도 발견하면 즉시 해당 블록을 실행하고 **나머지 아래의 `elif`나 `else`는 쳐다보지도 않고 전체 덩어리를 종료**합니다.

만능 분기처리 3형제 `if`, `elif`, `else`만 있으면 이 세상의 어떠한 복잡한 조건이라도 깔끔한 로직으로 구현할 수 있습니다!
