# PART 16 유전자 물려주기: 상속과 다형성

클래스를 열심히 만들다 보면 "어? 이 코드는 아까 만들었던 클래스랑 완전 똑같은데?"라는 생각이 들 때가 있습니다. 똑같은 코드를 두 번 적는 것은 프로그래머들이 제일 싫어하는 짓입니다. 이번 장에서는 기존 클래스의 코드를 한 줄도 베끼지 않고 통째로 내 것으로 만드는 마법, **상속(Inheritance)**을 배웁니다.

# 53 상속: 부모의 능력을 그대로 물려받기

RPG 게임에서 '전사'와 '마법사' 클래스를 만든다고 생각해 봅시다. 두 직업은 공격 방식은 다르지만, '걷기'나 '말하기' 같은 기본적인 사람의 행동은 공유합니다. 
이럴 때, 공통된 행동을 묶어 '인간(부모)' 클래스로 만든 다음 두 직업(자식)에게 능력을 **상속**해 줄 수 있습니다.

**코드: 상속받는 자식 클래스**
```python
# 1. 부모가 될 기본 클래스를 만듭니다.
class Human():
    def walk(self):
        print("터벅터벅 걷습니다.")
    def eat(self):
        print("맛있게 밥을 먹습니다.")

# 2. 클래스 이름 뒤 괄호 안에 부모 이름을 넣으면 상속 완료!
class Warrior(Human):
    # 전사만의 전용 기술을 추가합니다.
    def slash(self):
        print("검으로 강하게 베기!")

class Wizard(Human):
    def cast_magic(self):
        print("불덩어리 발사!")

# 전사 인스턴스를 하나 소환해 볼까요?
conan = Warrior()

conan.slash()  # 자기가 가진 고유 기술도 정상 작동하고,
conan.walk()   # 만들지도 않은 부모의 walk 기능까지 공짜로 쓸 수 있습니다!
```

**실행 결과**
```text
검으로 강하게 베기!
터벅터벅 걷습니다.
```

부모 클래스의 기능을 자식 클래스가 그대로 물려받아 사용합니다. 단, 현실 세계의 상속과 달리 파이썬에서는 자식에게 상속해 주어도 부모의 재산(코드)이 줄어들지 않고 원본이 그대로 남아있습니다!

# 54 메서드 오버라이드(Override): 청출어람, 부모를 덮어쓰다

부모에게 기능을 물려받긴 했는데, 그 방식이 마음에 들지 않아 나만의 방식으로 바꾸고 싶을 때가 있습니다. 전사는 걷더라도 일반 '터벅터벅'이 아니라 '위풍당당하게' 걸어야 멋있습니다. 
이때는 자식 클래스에 **부모와 똑같은 이름의 메서드**를 한 번 더 적어주면 됩니다. 이것을 **덮어쓰기(Override)**라고 부릅니다.

**코드: 내 방식대로 덮어쓰기**
```python
class Human():
    def walk(self):
        print("터벅터벅 걷습니다.")

class Warrior(Human):
    # 부모와 똑같은 이름으로 다시 정의하면 부모의 기능은 무시되고 덮어쓰여집니다!
    def walk(self):
        print("위풍당당하게 전진합니다!")

conan = Warrior()
conan.walk() 
```

**실행 결과**
```text
위풍당당하게 전진합니다!
```

# 55 super(): 부모의 능력을 호출하는 주문

가끔은 부모의 기술을 완전히 덮어버리는(오버라이드) 게 아니라, **부모의 기본기를 활용하면서 내 필살기를 덧붙이고 싶을 때**가 있습니다.
예를 들어, 캐릭터가 전직(초기화)될 때 '이름'은 인간(부모)의 기능으로 초기화하고, '소속 길드'만 전사(자식)가 따로 입력받고 싶다면 어떻게 할까요?

이때 `super()`라는 특별한 함수를 쓰면, 자식 안에서 부모를 마음껏 불러낼 수 있습니다.

**코드: 부모의 초기화 기능 훔쳐 쓰기**
```python
class Human():
    def __init__(self, name):
        self.name = name

class Warrior(Human):
    def __init__(self, name, guild):
        # 1. '이름' 세팅은 부모(Human)의 __init__ 에게 떠넘깁니다!
        super().__init__(name)
        # 2. '길드' 세팅만 내가 알아서 처리합니다.
        self.guild = guild
        
    def show_info(self):
        print(f"[{self.guild} 소속] 위대한 전사 {self.name}님이 등장했습니다!")

conan = Warrior("코난", "사자단")
conan.show_info()
```

이처럼 `super()`를 활용하면 겹치는 코드를 확 줄이면서도 훨씬 효율적인 프로그램을 짤 수 있습니다!

# 56 나만의 에러(예외) 만들기

지금까지 `ValueError` 같은 파이썬의 기본 에러들만 잡아보았습니다. 하지만 로그인 기능을 만들다 보면 `"아이디가 이미 있습니다"`, `"비밀번호가 너무 짧습니다"` 같은 나만의 특별한 에러 신호가 필요해집니다.

클래스의 상속을 이용하면 파이썬의 가장 높은 에러인 `Exception`을 부모로 상속받아 **나만의 에러 클래스**를 만들 수 있습니다.

**코드: 나만의 커스텀 에러 폭발시키기**
```python
# Exception(모든 에러의 부모)을 상속받아 나만의 에러라는 이름표를 달아줍니다.
class ShortPasswordError(Exception):
    pass

def sign_up(password):
    if len(password) < 4:
        # 내 마음에 안 들면 내가 직접 만든 에러를 강제로 뿜어냅니다!
        raise ShortPasswordError("비밀번호는 최소 4글자 이상이어야 합니다.")
    print("회원가입 완료!")

# 이제 try-except 로 남들이 아닌 오직 '나의 에러'만 골라서 잡을 수 있습니다!
try:
    sign_up("abc")
except ShortPasswordError as e:
    print(f"가입 실패 경고: {e}")
```

나만의 규격을 가진 에러 시스템을 만들면 프로그램 관리가 엄청나게 편해집니다! 이제 여러분은 단순한 문법을 넘어 프로그래머답게(OOP답게) 설계하는 진짜 기술을 손에 쥐게 되었습니다.
