# 04 값을 기억하는 상자, 변수(Variable)

프로그래밍에서 변수는 데이터(값)에 임시로 이름을 붙여 담아두는 '상자'라고 생각하면 이해하기 쉽습니다.

먼저 코드를 통해 변수의 필요성을 알아봅시다. 아래 코드를 에디터에 작성하고 `variable.py`로 저장한 뒤 실행해 보세요.

**코드: variable.py**
```python
print('안녕하세요. 제 이름은 파이썬입니다. 나이는 30살이에요.')
```

만약 문장에서 핵심 데이터인 '파이썬'과 '30'을 따로 분리해서 출력하려면 쉼표(`,`)를 활용할 수 있습니다. `print` 함수에 쉼표로 항목들을 구분하여 전달하면 한 칸씩 띄어서 하나의 문장처럼 보여줍니다.

**수정된 코드**
```python
print('안녕하세요. 제 이름은', '파이썬', '입니다. 나이는', 30, '살이에요.')
```

이때 텍스트 데이터인 '파이썬' 양옆에는 따옴표가 있지만, 숫자 30 양옆에는 따옴표가 빠져있는 것을 눈여겨보세요. 숫자는 따옴표 없이도 파이썬이 완벽하게 이해할 수 있기 때문입니다.

자, 이제 이 문장을 '변수'를 활용해 업그레이드해 보겠습니다.

**변수를 활용한 코드**
```python
name = '파이썬'
age = 30

print('안녕하세요. 제 이름은', name, '입니다. 나이는', age, '살이에요.')
```

**실행 결과**
결과는 변수를 사용하기 전과 완전히 동일합니다. 하지만 코드의 유연성이 크게 달라졌습니다!

위 코드에서 `name`과 `age`가 바로 변수입니다. 코드 작성법은 매우 직관적입니다.
`변수이름 = 저장할 값`

여기서 주의할 점이 있습니다! 파이썬에서 등호(`=`) 기호는 수학에서처럼 '왼쪽과 오른쪽이 같다'는 뜻이 아니라, **"오른쪽에 있는 값을 왼쪽 변수(이름)에 집어넣어라(대입/할당해라)"**라는 의미입니다. 

변수의 가장 큰 장점은 저장된 값을 언제든지 다른 값으로 덮어쓸 수 있다는 점입니다.

**코드**
```python
name = '파이썬'
age = 30
print('안녕하세요. 제 이름은', name, '입니다. 나이는', age, '살이에요.')

# 값을 다른 데이터로 교체하기
name = '자바'
age = 25
print('안녕하세요. 제 이름은', name, '입니다. 나이는', age, '살이에요.')
```

이처럼 구조는 그대로 둔 채 변수 내의 데이터만 바꿔 다양한 결과를 쉽게 만들어낼 수 있습니다.

# 05 사람을 위한 메모, 주석(Comment)

코드는 기본적으로 컴퓨터가 실행하기 위한 명령어들의 집합입니다. 하지만 코드를 작성하는 사람이나 나중에 코드를 유지 보수할 동료를 위해 코드 파일 안에 설명을 남겨두어야 할 때가 많습니다. 이때 사용하는 것이 바로 주석입니다.

만약 일반적인 텍스트로 코드에 설명을 적어두고 실행하면, 파이썬은 이를 이해하지 못해 즉각 `SyntaxError` (문법 오류)를 발생시킵니다. 

**오류가 나는 상황**
```python
여기부터는 나이를 계산하는 코드입니다!
age = 20
```

이럴 때 샵 기호(`#`)를 사용하면 훌륭한 메모장이 됩니다. 파이썬은 코드 중에 `#`을 발견하면, 그 줄의 `#`부터 끝까지의 모든 내용을 투명인간 취급하며 무시하고 건너뜁니다.

**코드**
```python
# 여기부터는 나이를 계산하는 코드입니다. 파이썬은 이 줄을 무시합니다.
age = 20
print('나이:', age)  # 코드의 오른쪽 끝에 이렇게 짧은 설명을 덧붙일 수도 있습니다.
```

주석은 단순 메모 용도 외에도 매우 유용하게 쓰입니다. 특정 코드가 잠시 실행되지 않도록 막아두고 싶을 때, 코드를 통째로 삭제하는 대신 맨 앞에 `#`만 붙여두면 일시적으로 코드를 비활성화할 수 있습니다. 버그를 잡을 때 자주 쓰이는 팁입니다.

여러 줄에 걸쳐 긴 주석을 달고 싶다면, 매 줄마다 `#`을 붙이는 대신 따옴표 3개(`'''` 또는 `"""`)로 해당 텍스트 묶음을 위아래로 감싸주면 됩니다.

**코드**
```python
"""
프로그램 이름: 날씨 알리미
작성자: 홍길동
이 코드는 날씨 정보를 화면에 보여줍니다.
"""
print("날씨 알리미 시작!")
```

# 06 데이터의 종류: 숫자와 문자열

파이썬이 데이터를 다루는 방식을 이해하려면 자료의 '형태(Type)'를 구분해야 합니다. 가장 기본이 되는 두 가지가 바로 숫자(Number)와 문자열(String)입니다.

**코드: number.py**
```python
language = 'Python'  # 따옴표가 있으므로 '문자열'
version = 3          # 따옴표가 없으므로 '숫자'

print(language, '버전은', version, '입니다.')
```

눈으로 보기에는 똑같은 `3`이어도, `3`과 `'3'`은 파이썬 내부에서 엄격하게 구분됩니다. 
가장 큰 차이는 수리적 '연산'이 가능한가 하는 점입니다.

숫자는 수학처럼 사칙연산을 자연스럽게 수행할 수 있습니다.

**코드**
```python
plus = 5 + 2      # 더하기 결과: 7
minus = 5 - 2     # 빼기 결과: 3
multiply = 5 * 2  # 곱하기 결과: 10 (주의: x가 아니라 * 기호 사용)
divide = 5 / 2    # 나누기 결과: 2.5 (주의: ÷가 아니라 / 기호 사용)
power = 5 ** 2    # 거듭제곱 결과: 25 (5의 2승)
remainder = 5 % 2 # 나머지 결과: 1 (5를 2로 나눈 나머지)

print(plus, minus, multiply, divide, power, remainder)
```

반면, 문자열끼리 덧셈을 시도하면 연산을 하는 것이 아니라 두 글자를 기차처럼 물리적으로 이어 붙여줍니다.

**코드**
```python
str_sum = '20' + '24'
num_sum = 20 + 24

print('문자열 더하기:', str_sum)
print('숫자 더하기:', num_sum)
```

**실행 결과**
```text
문자열 더하기: 2024
숫자 더하기: 44
```

절대 잊어서는 안 되는 규칙 하나! 파이썬에서 **문자열과 숫자를 서로 더하려고 시도하면 명백한 에러(TypeError)**가 발생합니다. 파이썬 입장에서는 이 둘을 이어 붙여야 할지, 수학적으로 더해야 할지 알 수 없기 때문입니다.

# 07 간편한 실습 환경, REPL 모드

매번 에디터를 열고 `.py` 파일로 저장한 뒤 셸에서 실행하는 과정이 번거롭게 느껴지나요? 
간단한 문법을 테스트하거나 가벼운 계산이 필요할 때는 파일 저장 없이 바로 코드를 쳐보고 엔터를 칠 수 있는 모드가 있습니다. 바로 파이썬의 대화형 실행 환경인 **REPL(Read-Eval-Print Loop)**입니다.

터미널이나 파워셸을 켜고 그냥 `python` 이라고만 치고 엔터를 쳐보세요.
설치 버전을 알리는 안내 문구 아래에 `>>>` 모양의 프롬프트가 당신의 명령을 기다릴 것입니다.

이 모드에서는 코드를 한 줄 입력할 때마다 즉시 평가(Eval)되어 팩트폭격기처럼 바로 아래에 결과를 출력(Print)해 줍니다. 

**REPL 사용 예시**
```text
PS C:\Users\Username> python
>>> 10 + 20
30
>>> "안녕" + "하세요"
'안녕하세요'
>>> 10 / 0
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ZeroDivisionError: division by zero
```
위처럼 고의로 오류를 내보면(0으로 나누기) 파이썬이 어떤 불만을 제기하는지도 즉각적으로 확인할 수 있어 문법 학습에 제격입니다. 

볼일을 다 마쳤다면 `exit()`을 입력하고 엔터를 치면 원래의 커맨드 환경으로 빠져나오게 됩니다.

# 08 개발자의 필수 도구, 명령줄 셸(Shell)

지금까지 터미널이나 파워셸 창을 통해 파이썬을 실행해 왔습니다. 이처럼 시커먼 화면에 글자로만 명령을 내리는 환경을 **CLI(Command Line Interface) 셸**이라고 부릅니다.
평소 우리가 마우스로 더블클릭해서 폴더를 여는 윈도우 탐색기나 macOS의 파인더 같은 환경(그래픽 셸, GUI)과 목적은 같으나 방법이 다를 뿐입니다. 

숙련된 개발자가 되려면 마우스 대신 키보드만으로 컴퓨터를 자유자재로 조작하는 명령줄 셸에 익숙해져야 합니다. 대표적인 5가지 생존 명령어를 빠르게 알아보겠습니다. 

> **💡 참고**: 아래 명령어들은 윈도우 파워셸은 물론, macOS와 리눅스 터미널에서도 공통적으로 매우 잘 작동합니다. 디렉터리(Directory)는 일상생활에서 말하는 폴더(Folder)와 완전히 같은 개념입니다.

1. **지도를 펼치다: `pwd` (Print Working Directory)**
   현재 내가 컴퓨터 내부의 어느 폴더 위치에 들어와 있는지를 전체 경로로 보여줍니다. 길을 잃었을 때 나침반 역할을 합니다.

2. **주위를 둘러보다: `ls` (List Segments)**
   내가 현재 서 있는 디렉터리 창고 안에 어떤 파일과 하위 폴더들이 있는지 목차를 쭉 나열해 줍니다.

3. **이동하기: `cd` (Change Directory)**
   다른 폴더로 들어갈 때 씁니다. `cd 폴더이름`을 치면 그 폴더 내용물로 진입합니다. 만약 현재 폴더에서 한 칸 상위 부모 폴더로 빠져나가고 싶다면 `cd ..` (마침표 두 개)를 입력하면 됩니다.

4. **복제 마법: `cp` (Copy)**
   파일을 복사합니다. 사용법은 `cp 원본파일 새파일` 입니다. 예를 들어 `cp test.py test_backup.py`라고 치면 순식간에 파일이 하나 더 생깁니다.

5. **파괴 마법: `rm` (Remove)**
   파일을 삭제합니다. 사용 방식은 `rm 삭제할파일` 입니다. 단, **그래픽 셸(휴지통)과 달리 `rm`으로 지운 파일은 휴지통을 거치지 않고 영구 삭제**되므로 사용할 때 극도의 주의가 필요합니다!

> **✨ 꿀팁**: 명령줄 셸에서 파일이나 폴더 이름을 칠 때, 처음 두세 글자만 치고 키보드의 `[Tab]` 키를 누르면 이름이 마법처럼 자동으로 완성됩니다! 수고를 덜어주는 최고의 지름길이니 꼭 활용해 보세요.
