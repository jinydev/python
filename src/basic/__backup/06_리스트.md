# 20 데이터를 하나로 묶는 마법, 리스트

리스트는 이름 그대로 여러 개의 아이템을 나열해 놓은 목록입니다.
파이썬에서 리스트를 만드는 방법은 아주 간단합니다. 대괄호 `[ ]` 안에 원하는 값들을 쉼표(`,`)로 구분해서 넣어주면 끝입니다.

**코드: 무지개와 로또 번호**
```python
colors = ['빨강', '주황', '노랑', '초록', '파랑', '남색', '보라']
lotto_numbers = [7, 12, 23, 31, 40, 45]

print(colors)
print(lotto_numbers)
```

**실행 결과**
```text
['빨강', '주황', '노랑', '초록', '파랑', '남색', '보라']
[7, 12, 23, 31, 40, 45]
```

리스트 전체를 출력할 수도 있지만, 보통은 리스트 속에 들어있는 특정 데이터 하나만 콕 집어서 몰래 빼내 쓰고 싶을 때가 많습니다. 이때는 리스트 이름 뒤에 대괄호를 붙이고, 데이터의 **위치 번호(인덱스)**를 적어주면 됩니다.

**코드: 데이터 콕 집어내기**
```python
colors = ['빨강', '주황', '노랑', '초록', '파랑', '남색', '보라']
print(colors[1])
```

> **🚨 치명적인 함정: 파이썬의 번호표는 0번부터 시작합니다!**
> 위 코드를 무심코 실행하면 '빨강'이 나올 것 같지만, 실제 결과는 **'주황'**이 출력됩니다.
> 일상생활에서는 1부터 숫자를 세지만, 파이썬을 포함한 대부분의 프로그래밍 언어는 숫자를 **0부터 셉니다.**
> 따라서 리스트의 첫 번째 항목은 `0번`, 두 번째 항목은 `1번`이 됩니다.

만약 7개의 색깔이 들어있는 무지개 리스트에서 무심코 `print(colors[7])`을 요청하면 어떻게 될까요? 파이썬은 "7번 칸은 비어있어요!"라며 `IndexError` (인덱스 범위 초과 오류)를 뿜어냅니다. (7개 항목의 인덱스는 0번부터 6번까지입니다.)

**음수 인덱스의 마술**
파이썬만의 아주 편리하고 독특한 기능이 있습니다. 바로 뒤에서부터 번호를 매기는 음수(-) 인덱스입니다.
리스트의 맨 마지막 항목을 꺼내고 싶을 때, 굳이 리스트의 길이를 끙끙 세어보지 않아도 쿨하게 `-1`을 던져주면 됩니다.

```python
print(colors[-1])  # 맨 뒤에서 첫 번째: '보라' 출력
print(colors[-3])  # 맨 뒤에서 세 번째: '파랑' 출력
```

# 21 자유자재로 다루는 리스트 조작법

리스트는 돌로 만든 조각상이 아니라 찰흙처럼 말랑말랑합니다. 한 번 만들고 나서도 값을 마음대로 바꾸고, 더하고, 빼고, 지울 수 있습니다.

### 1. 값 교체하기
가장 흔한 작업은 특정 칸에 들어있는 내용물을 다른 것으로 슬쩍 교체하는 것입니다. 변수에 값을 대입하듯이 인덱스로 위치를 지정한 뒤 새 값을 덮어씌웁니다.

```python
cart = ['우유', '빵', '계란']
cart[1] = '시리얼'  # 1번 칸(두 번째)의 '빵'을 '시리얼'로 교체
print(cart)  # 출력: ['우유', '시리얼', '계란']
```

### 2. 값 추가하기 (append & +)
쇼핑하다가 목록에 새로운 물건을 맨 끝에 끼워 넣고 싶을 때는 두 가지 마법을 쓸 수 있습니다.

* **`.append()` 활용**: 리스트 내부의 전용 함수(메서드)를 호출해 값을 엉덩이에 찰싹 붙여 넣습니다.
* **`+` 기호 활용**: 리스트끼리 더하기 기호로 이어 붙입니다. (문자열 이어붙이기 편을 떠올려 보세요!)

```python
numbers = [1, 2, 3]

# 방법 1: append로 엉덩이에 추가
numbers.append(4)
print(numbers)  # [1, 2, 3, 4]

# 방법 2: 리스트끼리 더해서 새로운 배열 만들기
new_numbers = numbers + [5, 6]
print(new_numbers)  # [1, 2, 3, 4, 5, 6]
```
> `append`는 기존 바구니 자체를 크게 늘리는 것이고, `+` 연산자는 바구니 두 개를 쏟아서 새로운 큰 바구니 하나를 새로 사는 개념입니다.

### 3. 포함 여부 검사하기 (`in`)
그 수많은 쇼핑 목록 중에 내가 '사과'를 이미 담았던가? 헷갈릴 때가 있죠. 파이썬에서는 놀랍도록 사람 말과 똑같은 `in` 키워드로 이를 검사할 수 있습니다. 결과는 당연히 팩트체크(`True` 혹은 `False`)로 반환됩니다.

```python
cart = ['우유', '시리얼', '계란']

if '계란' in cart:
    print("계란은 이미 장바구니에 있습니다!")
```

### 4. 값 삭제하기 (`del` & `.remove()`)
잘못 담은 물건을 뺄 차례입니다. 삭제도 두 가지 방식이 있습니다.

* **위치를 알아서 핀셋으로 빼기 (`del`)**: 인덱스를 알고 있다면, 파이썬의 내장 키워드 `del`을 사용해 저격합니다.
* **이름으로 수배해서 지우기 (`remove`)**: 몇 번째 칸인지 모르겠다면 이름표를 직접 넘겨 지우게 합니다.

```python
inventory = ['방패', '포션', '검', '포션']

# 위치를 저격하여 파괴 (1번 칸의 포션 파괴)
del inventory[1]
print(inventory)  # ['방패', '검', '포션']

# 가장 먼저 발견되는 '포션'이라는 이름의 아이템 파괴
inventory.remove('포션')
print(inventory)  # ['방패', '검']
```
> `remove`는 리스트 안에 똑같은 값이 여러 개 있더라도 제일 앞에서 만난 단 하나만 지우고 만족해버리니 주의해야 합니다.
