# 0. 파이썬 개발환경 구축

이 장에서는 2026년 기준 최신 파이썬 버전의 설치 방법과 현대적인 개발 환경을 구축하는 방법을 다룹니다.
실무에서 필수적으로 사용되는 파이썬 핵심 도구들과 가상환경(Virtual Environment)의 개념 및 활용법을 익힙니다.

## 학습목표

1. **파이썬 설치 및 설정**: 운영체제별 최신 파이썬 엔진 설치 과정을 숙지하고, 기본적인 런타임 환경을 이해합니다.
2. **개발 도구(IDE) 구축**: 생산성을 높이기 위한 VS Code 중심의 개발 환경 단축키, 확장을 포함하여 효율적으로 세팅합니다.
3. **가상환경 완전 정복**: 패키지 충돌을 방지하고 프로젝트별 독립적인 공간을 유지하는 가상환경의 동작 원리를 파악하고 적용합니다.

## 📖 학습 목차

### [00.01_파이썬 설치 가이드 (2026)](./install/)
운영체제별로 파이썬을 쉽게 설치하는 방법을 안내합니다.
최신 버전의 변경점과 코드 에디터 설정 방법을 가이드합니다.

### [00.02_가상환경 (Virtual Environment)](./venv/)
프로젝트 환경을 분리하여 관리하는 가상환경 기술을 배웁니다.
`venv` 모듈을 사용한 활성화 및 패키지 관리 기법을 상세히 다룹니다.
