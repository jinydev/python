# 5. Mapping/Set 자료형

## 학습목표

1. 본 단원의 핵심 개념을 정확히 이해하고 파이썬 동작 원리를 파악합니다.
2. 예제 실습을 통해 실무에서 자주 사용되는 필수 구문과 패턴을 익힙니다.
3. 세부 주제에 대한 이해도를 높여 체계적으로 코드를 설계하고 구조화하는 능력을 기릅니다.

## 📖 학습 목차

### [05.01_파이썬](./section1/)
파이썬 언어 특유의 문법과 철학에 기반한 코드 작성 기초 사례를 살펴봅니다.
효율적이고 간결한 파이썬만의 개발 방식을 자연스럽게 몸에 익힙니다.

### [05.02_딕셔너리(dict)](./dict/)
키와 값의 쌍으로 이루어진 딕셔너리의 구조와 고속 데이터 검색 원리를 이해합니다.
복잡한 매핑 데이터를 효율적으로 저장하고 추출하는 기법을 실습합니다.

### [05.03_set](./section2/)
중복을 허용하지 않고 순서가 없는 Set 자료형의 고유한 논리적 특성을 배웁니다.
교집합, 합집합 등 수학적 집합 연산을 통해 쉽게 데이터를 필터링합니다.
