# Chapter 5. 매핑과 집합 (Mapping & Set)

파이썬에서 **매핑(Mapping)** 구조는 고유한 '키(Key)'와 실제 데이터인 '값(Value)'을 1대1로 연결하여, 방대한 데이터 속에서도 원하는 정보를 즉시 찾아내는 강력한 자료형입니다. 이와 유사하게 **집합(Set)** 구조는 오로지 고유한 '키(Key)' 역할의 데이터만을 모아 수학적인 집합 연산(교집합, 합집합 등)을 지원합니다.
