# 2. 파이썬 문장

## 학습목표

1. 본 단원의 핵심 개념을 정확히 이해하고 파이썬 동작 원리를 파악합니다.
2. 예제 실습을 통해 실무에서 자주 사용되는 필수 구문과 패턴을 익힙니다.
3. 세부 주제에 대한 이해도를 높여 체계적으로 코드를 설계하고 구조화하는 능력을 기릅니다.

## 📖 학습 목차

### [02.01_문장](./section1/)
파이썬 프로그램을 구성하는 가장 기본적인 단위인 문장의 구조를 익힙니다.
올바른 문장 작성을 통해 의도한 대로 동작하는 코드를 만듭니다.

### [02.02_프로그램](./section2/)
여러 문장들이 모여 하나의 프로그램으로 실행되는 흐름과 구조를 배웁니다.
단위 프로그램 작성부터 전체 시스템 관점까지의 연결성을 이해합니다.

### [02.03_함수](./function/)
자주 사용하는 코드를 재사용 가능한 단위로 묶는 함수 생성 및 호출 방법을 학습합니다.
매개변수와 반환값을 통해 코드의 모듈성과 효율성을 극대화합니다.

### [02.04_모듈(module)_패키지(package)](./module/)
파이썬 코드를 파일 단위로 나누어 관리하는 모듈 및 패키지 시스템을 배웁니다.
코드의 구조화와 외부 라이브러리 활용 능력을 기릅니다.

### [02.05_네임스페이스(Namespace)](./namespace/)
변수나 함수 등을 식별하기 위해 사용하는 이름의 개념과 중요성을 학습합니다.
이름이 실제 메모리의 객체와 어떻게 연결되는지 파악합니다.

### [02.06_단순한](./section3/)
해당 주제의 기본 원리와 핵심 기능을 파이썬의 관점에서 구체적으로 학습합니다.
실전 예제를 바탕으로 실무 환경에서 적극 활용할 수 있는 역량을 차근히 기릅니다.
