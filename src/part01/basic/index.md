# 1. 파이썬 기본 핵심 understanding

## 학습목표

1. 본 단원의 핵심 개념을 정확히 이해하고 파이썬 동작 원리를 파악합니다.
2. 예제 실습을 통해 실무에서 자주 사용되는 필수 구문과 패턴을 익힙니다.
3. 세부 주제에 대한 이해도를 높여 체계적으로 코드를 설계하고 구조화하는 능력을 기릅니다.

## 📖 학습 목차

### [01.01_값(value)](./value/)
파이썬에서 데이터가 메모리에 어떻게 저장되고 표현되는지 원리를 이해합니다.
모든 데이터가 객체(Object) 형태로 존재한다는 파이썬의 핵심 철학을 다룹니다.

### [01.02_이름(name)](./name/)
변수나 함수 등을 식별하기 위해 사용하는 이름의 개념과 중요성을 학습합니다.
이름이 실제 메모리의 객체와 어떻게 연결되는지 파악합니다.

### [01.03_데이터](./data/)
컴퓨터 프로그램에서 처리되는 다양한 데이터의 형태와 구조를 알아봅니다.
효율적인 데이터 처리를 위한 기본적인 원칙들을 배웁니다.

### [01.04_바인딩(binding)](./binding/)
이름(변수)과 실제 값(객체)이 메모리 상에서 어떻게 매핑(바인딩)되는지 학습합니다.
할당 연산이 이루어질 때 파이썬 내부의 동작 과정을 깊이 이해합니다.

### [01.05_내장](./builtin/)
파이썬이 기본적으로 제공하는 내장 함수와 객체들의 종류 및 활용법을 익힙니다.
별도 모듈 없이 즉시 사용할 수 있는 유용한 도구들을 배워 효율을 높입니다.
