# 6. 정수형 검색

## 학습목표

1. 본 단원의 핵심 개념을 정확히 이해하고 파이썬 동작 원리를 파악합니다.
2. 예제 실습을 통해 실무에서 자주 사용되는 필수 구문과 패턴을 익힙니다.
3. 세부 주제에 대한 이해도를 높여 체계적으로 코드를 설계하고 구조화하는 능력을 기릅니다.

## 📖 학습 목차

### [06.01_정수](./integer/)
가장 기본적인 숫자형 클래스인 정수에 대한 내부 저장 기법을 학습합니다.
진법 변환과 다양한 수식 활용을 통한 정수 연산의 기초를 다룹니다.

### [06.02_슬라이싱(slicing)](./slicing/)
시퀀스 데이터의 특정 구간을 손쉽게 잘라내 추출하는 슬라이싱 기법을 배웁니다.
복잡한 컬렉션 데이터를 다룰 때 필수적인 빠른 조작 능력을 마스터합니다.

### [06.03_지능형(comprehension)](./comprehension/)
기존의 데이터를 직관적이고 간결하게 새로운 구조로 변환하는 컴프리헨션을 학습합니다.
리스트, 딕셔너리 등을 단 몇 줄의 코드로 작성하는 효율적인 방법을 익힙니다.

### [06.04_문자열](./string/)
텍스트 데이터를 다루기 위한 문자열 자료형의 생성과 조작 방법을 집중적으로 배웁니다.
문자열 포매팅 및 다양한 문자열 내부 메서드 활용법을 익힙니다.
