# Chapter 4. 시퀀스 (Sequence)

파이썬의 시퀀스 자료형은 여러 데이터가 순서를 가지고 연속적으로 나열된 구조를 뜻합니다. 요소들은 고유의 인덱스(Index)를 갖고 있어 위치를 기반으로 조회가 가능하며 문자열, 리스트, 튜플 등이 여기에 속합니다.
