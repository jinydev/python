# 8주차: 3학기 중간고사 📝

축하합니다! 여러분은 이제 GUI 개발, 네트워크 통신, 데이터 직렬화, 그리고 데이터베이스 설계까지 마스터했습니다. 이제 실무 응용 능력을 점검하는 중간고사를 치릅니다.

---

## 📋 시험 범위 및 핵심 체크리스트

### 1. GUI 개발
- [ ] 이벤트 루프의 작동 원리를 이해하고 설명할 수 있는가?
- [ ] `grid()` 배치 관리자를 사용하여 복잡한 레이아웃을 설계할 수 있는가?
- [ ] 커스텀 위젯을 만들기 위해 클래스 상속을 활용할 수 있는가?

### 2. 네트워크 프로그래밍
- [ ] TCP와 UDP의 차이점을 신뢰성과 속도 관점에서 설명할 수 있는가?
- [ ] 소켓을 사용하여 간단한 서버-클라이언트 통신을 구현할 수 있는가?
- [ ] HTTP 요청/응답 구조와 REST API의 개념을 이해하는가?

### 3. 데이터 처리 및 DB
- [ ] JSON 직렬화/역직렬화의 개념과 `json` 모듈 사용법을 익혔는가?
- [ ] SQL의 기본 쿼리문(SELECT, INSERT, UPDATE, DELETE)을 작성할 수 있는가?
- [ ] ORM(SQLAlchemy)을 사용하여 객체 지향적으로 DB를 조작할 수 있는가?

## ✍️ 중간고사 실습 문제 (예시)

**[문제 1]** 다음 시나리오를 구현하는 프로그램을 작성하시오. (30점)
- `requests` 라이브러리를 사용하여 외부 API에서 JSON 데이터를 가져온다.
- 가져온 데이터를 `sqlite3` 또는 `SQLAlchemy`를 사용하여 DB에 저장한다.
- 저장된 데이터를 조회하여 화면에 출력한다.

**[문제 2]** TCP 소켓 통신을 이용하여, 클라이언트가 보낸 메시지를 서버가 모두 대문자로 바꾸어 다시 보내주는 'Uppercase Echo Server'를 구현하시오. (20점)

**[문제 3]** `Tkinter`를 사용하여 간단한 '메모장' 프로그램을 구현하시오. (30점)
- 텍스트 입력창(`Text`)과 저장 버튼(`Button`)이 있어야 함.
- 저장 버튼을 누르면 입력된 내용을 `memo.txt` 파일에 저장해야 함.

**[문제 4]** ORM의 'N+1 문제'가 무엇인지 설명하고, 이를 해결하기 위한 방법(예: Join)에 대해 서술하시오. (20점)
