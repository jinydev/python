# 3주차: 네트워크 프로그래밍 (1) - 소켓 통신 기초 🌐

우리는 지금까지 내 컴퓨터 안에서만 돌아가는 프로그램을 만들었습니다. 하지만 진정한 프로그램의 힘은 **네트워크**를 통해 다른 컴퓨터와 데이터를 주고받을 때 나타납니다. 이번 시간에는 네트워크 통신의 가장 기초인 **소켓(Socket)** 프로그래밍을 배웁니다.

---

## 1. 네트워크 기초 개념

컴퓨터가 서로 통신하려면 주소와 통로가 필요합니다.

- **IP 주소:** 네트워크 상의 컴퓨터 주소 (예: `192.168.0.1`)
- **포트(Port) 번호:** 컴퓨터 내의 어떤 프로그램으로 데이터를 보낼지 결정하는 문 번호 (예: HTTP는 80, HTTPS는 443)
- **소켓(Socket):** 네트워크 통신의 끝점(End-point). 데이터를 보내고 받는 '콘센트'라고 생각하면 됩니다.

## 🔍 Deep Dive: OS 소켓 버퍼(Kernel Buffer)와 TCP 3-Way Handshake 핸드셰이크 원리

컴퓨터 간의 텍스트 교환은 하드웨어와 운영체제 수준에서 매우 복잡한 구조로 일어납니다.
- **TCP 3-Way Handshake**: 데이터를 주고받기 전에 커널 수준에서 `SYN` ➡️ `SYN-ACK` ➡️ `ACK` 신호를 교환해 가상의 통신 파이프라인(가상회선)을 정립합니다.
- **OS 소켓 버퍼**: 파이썬 `send()` 함수는 상대방 컴퓨터에 데이터를 직접 쏘는 것이 아닙니다. 단지 운영체제 커널의 송신 버퍼(Send Buffer)에 데이터를 채울 뿐이며, 커널이 알아서 백그라운드에서 데이터를 MTU 단위의 패킷으로 잘라 보냅니다. 상대방이 받지 못하거나 커널 버퍼가 가득 차면 파이썬 소켓 함수는 일시 차단(Block)됩니다.

## ☕ Java vs Python 스나이퍼 비교

### 네트워크 소켓 프로그래밍 모델
*   **Java**: 전통적으로 동기식 블로킹 소켓인 `ServerSocket`과 `Socket`을 썼으나, 고성능 처리를 위해 멀티플렉싱 비동기 I/O를 지원하는 **NIO (`ServerSocketChannel`)** 라이브러리가 내장되어 있습니다. 자바의 네트워크 IO는 복잡한 버퍼(ByteBuffer) 설계와 셀렉터(Selector) 개념이 동반되어 문법이 매우 무겁습니다.
*   **Python**: C언어 소켓 라이브러리와 1:1 대응하는 얇고 단순한 `socket` 랩퍼 모듈을 제공하여 초보자도 쉽게 다룰 수 있습니다. 고급 고성능 통신이 필요할 때는 `select` 모듈이나 `asyncio` 기반 소켓 핸들러를 사용하여 심플하게 해결합니다.

## 코딩 영단어 학습 📝

*   **`Socket`**: 소켓. (네트워크 상에서 두 프로그램이 서로 데이터를 주고받을 수 있도록 운영체제 커널이 열어주는 소프트웨어적인 통신 포트 연결부입니다.)
*   **`Handshake`**: 핸드셰이크, 악수. (두 컴퓨터가 신뢰성 있는 연결을 맺기 위해 통신 시작 전에 상호 패킷 신호를 확인하며 연결 상태를 합의하는 상호 작용 절차입니다.)
*   **`Packet`**: 패킷. (네트워크를 통해 전송하기 위해 데이터를 일정한 크기로 분할한 전송 단위로, 헤더 정보와 페이로드가 포함되어 있습니다.)
