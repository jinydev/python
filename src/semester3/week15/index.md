# 15주차: 최종 프로젝트 구현 - 코딩과 디버깅 💻

지난 주에 세운 설계도를 바탕으로 이제 실제 구현에 들어갑니다. 이번 주차의 목표는 **'작동하는 최소 기능 제품(MVP, Minimum Viable Product)'**을 완성하는 것입니다.

---

## 1. 개발 전략: 반복적 개발 (Iterative Development)

한 번에 모든 기능을 완벽하게 만들려고 하면도중에 포기하게 됩니다. 다음과 같은 단계로 개발하세요.

1.  **Core 기능 구현:** 프로그램의 가장 핵심이 되는 기능 하나만 먼저 작동하게 만듭니다. (예: 가계부라면 '내역 저장'부터)
2.  **기능 확장:** 핵심 기능이 작동하면, 하나씩 기능을 추가합니다. (조회 $\rightarrow$ 수정 $\rightarrow$ 삭제)
3.  **UI 입히기:** 기능이 완성되면 GUI를 입혀 사용성을 높입니다.
4.  **테스트 및 버그 수정:** `pytest` 등을 사용하여 예외 상황을 테스트하고 버그를 잡습니다.

---

## 2. 구현 시 주의사항 (Checklist)

개발하면서 다음 사항들을 스스로 체크해 보세요.

- [ ] **OOP 적용:** 클래스를 적절히 나누었는가? 상속과 다형성을 활용했는가?
- [ ] **안정성:** 사용자 입력에 대해 `try-except` 처리가 되어 있는가?
- [ ] **효율성:** 대량의 데이터를 다룰 때 시간 복잡도를 고려했는가? 비동기 처리가 필요한 곳에 적용했는가?
- [ ] **가독성:** 변수 이름이 명확하고, 타입 힌팅을 적용했는가?

---

## 3. 디버깅 팁

버그가 발생했을 때 당황하지 말고 다음 방법을 사용하세요.
- **Print 디버깅:** 변수 값을 중간중간 출력하여 어디서 값이 틀어지는지 확인합니다.
- **디버거(Debugger) 활용:** VS Code의 중단점(Breakpoint)을 설정하여 한 줄씩 실행하며 메모리 상태를 관찰합니다.
- **로그(Log) 기록:** `logging` 모듈을 사용하여 프로그램의 실행 흐름을 파일로 남깁니다.
