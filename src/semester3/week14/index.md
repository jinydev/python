# 14주차: 최종 프로젝트 기획 - 나만의 서비스 설계 📝

이제 모든 이론 학습이 끝났습니다. 마지막 관문은 여러분이 배운 모든 기술을 집약하여 **실제 작동하는 서비스**를 만드는 것입니다. 이번 주에는 무작정 코딩을 시작하는 것이 아니라, 전문 개발자처럼 **기획과 설계**를 먼저 진행합니다.

---

## 1. 프로젝트 주제 선정

단순한 연습용 프로그램이 아니라, **"누군가에게 실제로 도움이 되는 서비스"**를 목표로 합니다.

### 💡 아이디어 가이드
- **GUI + DB + 네트워크:** 실시간 주식/코인 가격 알림이 및 포트폴리오 관리 프로그램.
- **비동기 크롤링 + DB:** 여러 쇼핑몰의 최저가를 비교하여 저장하고 알림을 주는 가격 추적기.
- **OOP + 게임 원리:** 복잡한 스킬 트리와 아이템 시스템이 구현된 턴제 RPG 게임.
- **API + GUI:** 날씨 API와 일정 관리 API를 연동한 스마트 스케줄러.

---

## 2. 요구사항 분석 및 기능 명세서 작성

프로그램이 정확히 어떤 기능을 가져야 하는지 목록을 만듭니다.

**예시: [개인 가계부 프로그램]**
- **필수 기능:**
    - 지출/수입 내역 입력 및 저장 (DB 사용)
    - 월별 지출 합계 조회 (SQL 쿼리)
    - 카테고리별 지출 비율 시각화 (GUI 그래프)
- **추가 기능:**
    - 예산 설정 및 초과 시 경고 알림
    - 데이터를 CSV 파일로 내보내기 (파일 입출력)

---

## 3. 시스템 설계 (Architecture)

코드를 짜기 전, 어떤 구조로 만들지 설계도를 그립니다.

1.  **데이터 모델 설계:** DB 테이블 구조(ERD)를 설계합니다.
2.  **클래스 설계:** 어떤 클래스가 필요하고, 클래스 간의 관계(상속, 포함)는 어떻게 되는지 정의합니다.
3.  **UI/UX 설계:** 화면 구성(와이어프레임)을 간단히 그립니다.
4.  **기술 스택 결정:** 어떤 라이브러리를 사용할지 결정합니다. (예: `PyQt` + `SQLAlchemy` + `aiohttp`)
