# Part 2. 함수와 클래스

이 파트에서는 코드를 재사용하고 객체 지향 프로그래밍(OOP)을 구현하는 핵심 도구인 함수와 클래스에 대해 배웁니다.

## 학습목표

1. **함수의 활용**: 파이썬에서 함수를 정의하고 람다, 내부 함수 등 다양한 형태로 활용하는 방법을 배웁니다.
2. **매개변수와 변수 스코프**: 가변 매개변수와 고정 매개변수를 다루며, 변수의 유효 범위(네임스페이스)를 이해합니다.
3. **객체 지향 프로그래밍(OOP)**: 클래스의 기본 개념부터 캡슐화, 상속, 다형성 등 실무적인 객체 지향 패러다임을 확립합니다.
4. **고급 함수 및 메서드**: 스페셜 메서드를 통한 연산자 오버로딩과 클로저, 데코레이터 등의 고급 기법을 다룹니다.
