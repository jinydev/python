# Chapter 7. 함수 (Function)

어떤 데이터를 입력(Input)하면 정해진 로직을 거쳐 결과물(Output)을 반환하는 재사용 가능한 코드의 묶음을 **함수(Function)**라고 부릅니다. 반복되는 코드를 방지하고 프로그램의 뼈대를 튼튼하게 세우는 필수적인 도구입니다.

파이썬의 함수는 단순히 코드를 묶어두는 문법적 단위를 넘어, **함수 그 자체도 하나의 객체(Object)**라는 독특하고 강력한 특성을 가집니다.
