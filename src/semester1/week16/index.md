## ✍️ 기말고사 실습 문제 (예시)

**[문제 1]** 다음 코드의 시간 복잡도를 분석하고, 더 효율적인 방법으로 개선하여 작성하시오. (20점)
```python
def find_item(lst, target):
    for item in lst:
        if item == target:
            return True
    return False
```

**[문제 2]** 제너레이터를 사용하여 1부터 100만까지의 숫자 중 짝수만 생성하는 함수를 만들고, 이를 사용하여 짝수들의 합을 구하는 코드를 작성하시오. (20점)

**[문제 3]** 파일에서 사용자 정보를 읽어와 딕셔너리에 저장하고, 특정 사용자의 이름을 검색하는 프로그램을 작성하시오. (단, 검색 속도를 높이기 위해 딕셔너리를 활용하고, 파일이 없을 경우의 예외 처리를 포함할 것) (30점)

**[문제 4]** 함수를 인자로 받는 고차 함수를 사용하여, 리스트의 모든 요소에 특정 연산을 적용하는 `apply_operation` 함수를 구현하시오. (30점)
