## ☕ Java vs 🐍 Python 스나이퍼 요약 비교

1. **동작 방식**: Java는 `javac` 번역기로 전체 소스코드를 일괄 번역(`.class`)하지만, Python은 인터프리터가 한 줄씩 실시간 동시통역으로 실행합니다. (사소한 오타에 프로그램 동작 중 멈추는 런타임 에러 주의)
2. **타입 규칙**: Java는 자료형을 선언할 때 강제 지정하는 **정적 타이핑**을 쓰고, Python은 대입하는 리터럴에 의해 런타임에 자동으로 자료형이 결정되는 **동적 타이핑**을 사용합니다.
3. **진짜 상수**: Java는 `final` 키워드로 변수를 잠그지만, Python은 문법적 상수가 없어 **대문자 명명 관례(UPPERCASE)**를 준수하여 상수를 표현합니다.
