# 15주차: 1학기 종합 프로젝트 - CLI 프로그램 제작 🛠️

이제 여러분은 파이썬의 기초부터 알고리즘까지 모두 배웠습니다. 이번 주에는 배운 모든 내용을 쏟아부어 **실제 작동하는 프로그램**을 설계하고 구현해 보겠습니다.

---

## 🎯 프로젝트 목표
**"실생활의 불편함을 해결하는 CLI(Command Line Interface) 프로그램 만들기"**

단순한 계산기가 아니라, 데이터 저장, 예외 처리, 효율적인 알고리즘이 포함된 완성도 높은 프로그램을 만드는 것이 목표입니다.

### ✅ 필수 포함 요구사항
1.  **데이터 저장:** 파일 입출력(`with open`)을 사용하여 프로그램 종료 후에도 데이터가 유지되어야 함.
2.  **예외 처리:** 사용자 입력 오류에 대해 `try-except`를 사용하여 프로그램이 꺼지지 않아야 함.
3.  **함수화:** 기능별로 함수를 분리하고, 적절한 매개변수와 반환값을 사용해야 함.
4.  **효율성:** 데이터 검색이나 정렬 시 배운 알고리즘(예: 이진 탐색)을 적용하여 효율성을 높여야 함.

### 💡 프로젝트 아이디어 예시
*   **개인 가계부:** 수입/지출 내역을 파일에 저장하고, 월별 합계를 계산하며, 특정 항목을 빠르게 검색하는 프로그램.
*   **단어장 프로그램:** 영어 단어와 뜻을 저장하고, 퀴즈를 내며, 틀린 단어만 따로 모아 관리하는 프로그램.
*   **할 일 관리(To-Do List):** 할 일 추가/삭제/완료 표시를 하고, 우선순위에 따라 정렬하여 보여주는 프로그램.

---

## 📅 개발 일정 (마일스톤)

1.  **기획 (1~2일):** 어떤 프로그램을 만들지 결정하고, 필요한 기능 리스트(요구사항)를 작성합니다.
2.  **설계 (3~4일):** 어떤 함수가 필요할지, 파일 구조는 어떻게 할지 설계합니다.
3.  **구현 (5~10일):** 기능을 하나씩 구현하고 테스트합니다.
4.  **리팩토링 및 문서화 (11~14일):** 코드를 더 깔끔하게 다듬고, 사용법(README)을 작성합니다.
