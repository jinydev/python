## ✍️ 중간고사 실습 문제 (예시)

**[문제 1]** 다음 코드의 출력 결과와 그 이유를 서술하시오. (10점)
```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)
```

**[문제 2]** 딕셔너리에서 특정 키를 찾을 때 시간 복잡도가 $O(1)$인 이유를 '해시 함수'와 '인덱스'의 관계를 중심으로 설명하시오. (15점)

**[문제 3]** 사용자로부터 정수 $N$을 입력받아, 1부터 $N$까지의 숫자 중 소수(Prime Number)만 출력하는 프로그램을 작성하시오. (25점)

**[문제 4]** 다음 함수의 실행 결과와 함께, 파이썬의 스코프 규칙(LEGB)을 적용하여 변수 `x`가 어떻게 찾아지는지 단계별로 설명하시오. (20점)
```python
x = 10
def outer():
    x = 20
    def inner():
        print(x)
    inner()
outer()
```
