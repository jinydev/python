# Part 4. 주요 모듈 활용

이 파트에서는 파이썬 생태계를 더욱 강력하게 만들어주는 다양한 표준 라이브러리와 데이터 처리 모듈을 배웁니다.

## 학습목표

1. **내장 모듈 활용**: 자료구조 및 알고리즘 구현을 돕는 collections, bisect 등의 파이썬 핵심 내장 모듈 사용법을 배웁니다.
2. **예외 및 파일 처리**: 안전한 프로그램 수행을 위한 예외 처리(Try-except) 기법과 로컬 파일을 입출력하는 방법을 습득합니다.
3. **텍스트 처리**: 문자열의 인코딩/디코딩 바이트 처리 방식과, 텍스트 검색에 특화된 정규 표현식(Regex)을 다룹니다.
4. **데이터 포맷 핸들링**: 프로젝트에서 흔히 사용되는 XML, JSON, CSV 형식의 데이터를 읽고 쓰는 모듈의 활용 능력을 키웁니다.

### [17. 예외 처리](./exception/)

에러 추적을 위한 traceback 활용과 커스텀 예외 클래스 작성을 통해 상용 수준의 안정성을 갖춥니다.

상황에 맞는 최적의 입출력 모드 설정으로 I/O(Input/Output)의 동작 속도와 안전성을 높입니다.

### [19. 바이트 처리](./bytes/)
문자열 인코딩과 파일 시스템 내부 구조를 관통하는 핵심 개념인 원시 바이트(Bytes) 배열을 파이썬 내부에서 다루는 법을 파악합니다.
객체를 바이트의 연속으로 변경하여 통신하거나 파일에 기록하는 직렬화(Serialization) 기법의 뼈대를 살펴봅니다.

파이썬의 `re` 모듈이 제공하는 함수들의 문법과 일상에서 자주 접하는 탐색 패턴 예시를 습득합니다.
