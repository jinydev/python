# 19. 바이트 처리

## 학습목표

1. 본 단원의 핵심 개념을 정확히 이해하고 파이썬 동작 원리를 파악합니다.
2. 예제 실습을 통해 실무에서 자주 사용되는 필수 구문과 패턴을 익힙니다.
3. 세부 주제에 대한 이해도를 높여 체계적으로 코드를 설계하고 구조화하는 능력을 기릅니다.

## 📖 학습 목차

### [19.01_파이썬](./section1/)
파이썬 언어 특유의 문법과 철학에 기반한 코드 작성 기초 사례를 살펴봅니다.
효율적이고 간결한 파이썬만의 개발 방식을 자연스럽게 몸에 익힙니다.

### [19.02_파일](./section2/)
외부의 데이터를 시스템에서 읽거나 처리 결과를 파일로 안전하게 저장하는 과정을 배웁니다.
텍스트와 이진 모드 입출력 등 파일 입출력 처리의 가장 근원적인 개념을 익힙니다.

### [19.03_직렬화](./section3/)
해당 주제의 기본 원리와 핵심 기능을 파이썬의 관점에서 구체적으로 학습합니다.
실전 예제를 바탕으로 실무 환경에서 적극 활용할 수 있는 역량을 차근히 기릅니다.
