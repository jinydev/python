## ✍️ 중간고사 실습 문제 (예시)

**[문제 1]** 다음 클래스 구조에서 `Employee` 객체의 `work()` 메서드를 호출했을 때 어떤 결과가 나오며, 그 이유를 MRO 순서와 함께 설명하시오. (15점)
```python
class A:
    def work(self): print("A working")
class B(A):
    def work(self): print("B working")
class C(A):
    def work(self): print("C working")
class Employee(B, C):
    pass
```

**[문제 2]** `BankAccount` 클래스를 설계하시오. (25점)
- 잔액(`__balance`)은 Private으로 설정하여 외부에서 직접 수정할 수 없게 할 것.
- `@property`를 사용하여 잔액을 조회하고, 입금/출금 메서드를 통해도 잔액이 변경되도록 할 것. (단, 출금 시 잔액 부족 시 에러 발생)

**[문제 3]** `Shape`라는 추상 클래스를 만들고, 이를 상속받는 `Circle`과 `Square` 클래스를 구현하여 각각의 넓이를 계산하는 다형성 코드를 작성하시오. (30점)
