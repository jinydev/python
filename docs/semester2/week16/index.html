16주차: 2학기 기말고사 및 마무리 🎓

2학기 동안 여러분은 단순한 코딩을 넘어 소프트웨어 설계(Software Architecture)의 정수를 배웠습니다. 캡슐화부터 디자인 패턴, 그리고 실제 배포 과정까지, 이제 여러분은 ‘개발자’로서의 전문성을 갖추게 되었습니다.

📋 기말고사 범위 및 핵심 체크리스트

1. OOP 심화 설계

  • 디자인 패턴(싱글톤, 팩토리, 전략, 옵저버)의 목적과 구현 방법을 이해하는가?
  • 상황에 맞는 적절한 디자인 패턴을 선택하여 설계할 수 있는가?

2. 구조 및 안정성

  • 패키지 구조를 설계하고 절대/상대 경로 임포트를 적절히 사용할 수 있는가?
  • 타입 힌팅과 mypy를 사용하여 정적 분석을 수행할 수 있는가?
  • pytest를 이용한 유닛 테스트를 작성하고 TDD 사이클을 이해하는가?

3. 배포 및 패키징

  • pyproject.toml을 작성하고 패키지를 빌드(.whl)할 수 있는가?
  • 시맨틱 버저닝의 원칙을 이해하고 버전을 관리할 수 있는가?
  • PyPI 배포 프로세스를 이해하고 있는가?

✍️ 기말고사 최종 프로젝트: “나만의 파이썬 라이브러리 제작”

이번 학기의 최종 결과물은 단순한 코드가 아니라, 실제로 배포 가능한 수준의 라이브러리를 만드는 것입니다.

🛠️ 프로젝트 요구사항

  1. 기능성: 특정 목적(예: 데이터 처리, 수학 계산, 텍스트 분석 등)을 가진 유용한 기능을 구현할 것.
  2. 설계: 최소 한 가지 이상의 디자인 패턴을 적용하고, 추상 클래스를 사용하여 확장 가능하게 설계할 것.
  3. 안정성: 모든 주요 기능에 대해 유닛 테스트(pytest)를 작성하고 통과할 것.
  4. 표준화: pyproject.toml을 작성하고, 시맨틱 버저닝을 적용하여 빌드할 것.
  5. 문서화: README.md에 설치 방법, 사용법, API 명세서를 상세히 작성할 것.

🌟 2학기를 마치며

여러분은 이제 클래스를 만들 줄 아는 사람에서, 시스템을 설계할 줄 아는 사람으로 성장했습니다.

3학기 예고: 3학기에는 이 모든 이론적 무기를 가지고 실전 응용 개발에 뛰어듭니다. GUI, 네트워크, 데이터베이스, 그리고 파이썬의 끝판왕인 비동기 프로그래밍(Asyncio)을 통해 실제 서비스 수준의 애플리케이션을 제작하게 될 것입니다. 수고 많으셨습니다!
