1주차 2교시: Tkinter 기초 - 첫 번째 윈도우 만들기 (2/3) 🖥️

지난 시간에는 GUI의 개념과 이벤트 루프의 원리를 배웠습니다. 이제 실제로 파이썬의 표준 라이브러리인 Tkinter를 사용하여 화면에 윈도우를 띄우고 위젯을 배치해 보겠습니다.

1. Tkinter 기본 구조 분석

Tkinter 프로그램은 항상 다음과 같은 3단계 구조를 가집니다.

1.1 기본 코드 템플릿

import tkinter as tk

# 1. 메인 윈도우 생성
root = tk.Tk()
root.title("나의 첫 GUI 프로그램")
root.geometry("400x300") # 가로x세로 크기 설정

# 2. 위젯 생성 및 배치
label = tk.Label(root, text="안녕하세요, 파이썬 GUI 세계에 오신 것을 환영합니다!")
label.pack() 

# 3. 이벤트 루프 시작
root.mainloop()

1.2 단계별 상세 설명

  1. tk.Tk():
    • 메인 윈도우 객체를 생성합니다. 모든 위젯은 이 root 윈도우 위에 올라갑니다.
    • 프로그램의 ‘심장’과 같은 존재입니다.
  2. root.title() / root.geometry():
    • 윈도우의 제목 표시줄 텍스트와 초기 크기를 설정합니다.
  3. 위젯 생성:
    • tk.Label(root, ...)와 같이 첫 번째 인자로 부모 위젯(여기서는 root)을 지정해야 합니다.
  4. root.mainloop():
    • 앞서 배운 이벤트 루프를 실제로 실행하는 함수입니다.
    • 이 함수가 호출되는 순간 프로그램은 사용자의 입력을 기다리는 대기 상태가 되며, 코드는 여기서 멈춰 대기합니다.

2. 핵심 위젯 (Core Widgets) 살펴보기

GUI를 구성하는 기본 부품들을 위젯(Widget)이라고 합니다. 가장 자주 사용되는 5가지 핵심 위젯을 배웁니다.

2.1 텍스트 표시: Label

  • 용도: 읽기 전용 텍스트나 이미지를 화면에 표시합니다.
  • 주요 옵션:
    • text: 표시할 문자열
    • fg (foreground): 글자 색상 (예: “red”, “#FF0000”)
    • bg (background): 배경 색상
    • font: 폰트 설정 (예: ("Arial", 12, "bold"))

2.2 사용자 입력: Entry

  • 용도: 사용자로부터 한 줄의 텍스트 입력을 받습니다.
  • 주요 옵션:
    • width: 입력창의 너비
    • show: 입력 내용을 숨김 (예: show="*", 비밀번호 입력창 구현 시 사용)

2.3 클릭 상호작용: Button

  • 용도: 클릭 시 특정 동작을 수행하게 합니다.
  • 핵심 옵션: command
    • 버튼을 눌렀을 때 실행할 함수 이름을 전달합니다. (함수를 호출하는 ()를 붙이지 않고 이름만 전달하는 것이 포인트입니다.)

2.4 여러 줄 입력: Text

  • 용도: 메모장처럼 여러 줄의 텍스트를 입력받거나 표시합니다.
  • 특징: Entry보다 훨씬 강력한 텍스트 조작 기능을 제공합니다.

2.5 그룹화 컨테이너: Frame

  • 용도: 위젯들을 논리적으로 묶어주는 투명한 상자입니다.
  • 특징: 위젯들을 Frame에 넣고, 그 Frame을 배치하면 내부 위젯들이 함께 움직입니다. 레이아웃 설계의 핵심입니다.

3. 위젯 배치 관리자 (Geometry Managers)

위젯을 생성만 한다고 화면에 나타나지 않습니다. 반드시 배치 관리자를 통해 위치를 지정해줘야 합니다.

3.1 pack(): 단순 적재 방식

  • 특징: 위젯을 위에서 아래로, 혹은 왼쪽에서 오른쪽으로 차례대로 쌓습니다.
  • 장점: 매우 빠르고 간단하게 배치할 수 있습니다.
  • 단점: 정밀한 위치 조정이 어렵습니다.
  • 주요 옵션: side (TOP, LEFT, RIGHT, BOTTOM), padx, pady (여백 설정)

3.2 grid(): 격자 배치 방식

  • 특징: 엑셀 시트처럼 행(row)과 열(column)을 지정하여 배치합니다.
  • 장점: 가장 체계적이고 정밀한 레이아웃을 만들 수 있어 실무에서 가장 많이 사용됩니다.
  • 주요 옵션: row, column, columnspan (열 병합), rowspan (행 병합)

3.3 place(): 절대 좌표 방식

  • 특징: 픽셀 단위로 x, y 좌표를 직접 지정합니다.
  • 장점: 원하는 위치에 정확히 배치할 수 있습니다.
  • 단점: 윈도우 크기가 변할 때 위젯 위치가 고정되어 있어 유연성이 떨어집니다.

✍️ 2교시 실습 및 과제

실습 1: 기본 윈도우 구성

  • Label, Entry, Button을 사용하여 간단한 인사말 프로그램 창을 만들고, 윈도우 제목과 크기를 설정해 보세요.

실습 2: 배치 관리자 비교

  • pack()과 grid()를 사용하여 동일한 구성의 위젯들을 배치해 보고, 어떤 차이가 있는지 직접 확인해 보세요.

과제: 나만의 명함 만들기

  • Frame을 사용하여 배경색을 지정하고, 그 안에 자신의 이름, 연락처, 이메일 등을 Label 위젯을 적절히 배치하여 ‘디지털 명함’ 창을 만들어 보세요.
