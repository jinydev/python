3학기. 응용 개발 및 시스템 프로그래밍 🖥️

파이썬의 다양한 고급 시스템 도구들을 다루어보고, GUI, 데이터베이스, 네트워크, 그리고 병렬/비동기 기법을 융합한 실제 서비스와 게임 프로젝트를 완성합니다.

📅 주차별 학습 목차

01주차. GUI 개발 기초 - 윈도우 인터페이스와 이벤트 루프

이벤트 루프의 개념과 데스크탑 그래픽 인터페이스인 Tkinter를 이용해 윈도우 창과 버튼을 연동하는 기초를 다집니다.

  • 1교시: GUI 개발 기초 - 화면에 생명력 불어넣기
  • 2교시: Tkinter 기초 - 첫 번째 윈도우 만들기
  • 3교시: 이벤트 연결과 동적 UI 업데이트

02주차. GUI 심화 - 위젯 배치 알고리즘과 데이터 시각화 뷰어

위젯 배치 레이아웃 매니저를 깊이 이해하고, 실시간 데이터를 시각화하는 커스텀 대시보드 윈도우를 작성합니다.

03주차. 네트워크 프로그래밍 (1) - 소켓 통신 기초

TCP/UDP 네트워크 전송 계층 소켓 통신의 기본 개념을 학습하고, 에코 서버-클라이언트를 구축합니다.

04주차. 네트워크 프로그래밍 (2) - HTTP와 REST API

HTTP 프로토콜 규격을 학습하고, requests 라이브러리를 사용해 타사 공공 API와 통신하는 기법을 실습합니다.

05주차. 데이터 처리 - JSON과 XML, 그리고 직렬화

데이터 패킷 형식인 JSON/XML 파일 포맷을 직렬화/역직렬화(Serialization)하여 가공하는 기술을 익힙니다.

06주차. 데이터베이스 기초 - 영구적인 데이터 저장소

경량화 관계형 데이터베이스인 SQLite3를 연동하고 기본적인 SQL 질의어 연산 및 최적화 방법을 학습합니다.

07주차. ORM (Object Relational Mapping) - 객체와 DB의 연결

SQLAlchemy 라이브러리를 다루며 객체와 데이터베이스 행을 매핑해 효율적인 쿼리 관리를 구축해 봅니다.

08주차. 3학기 중간고사

데스크탑 그래픽(GUI)과 로컬 DB 데이터를 상호 조회/수정할 수 있는 연동 실습 평가를 치릅니다.

09주차. 멀티스레딩 (Threading) - 동시성 프로그래밍

파이썬의 가장 큰 내부적 특징인 GIL(Global Interpreter Lock)을 심층 이해하고, 다중 스레드의 동시성 한계를 극복하는 기법을 다룹니다.

10주차. 멀티프로세싱 (Multiprocessing) - 진정한 병렬 처리

여러 CPU 코어를 효율적으로 쥐어짜는 멀티프로세스 생성을 통해 하드웨어 자원을 극대화하는 병렬 컴퓨팅을 실습합니다.

11주차. 비동기 프로그래밍 (1) - asyncio와 코루틴

스레드와 프로세스를 점유하지 않고 동작하는 싱글스레드 논블로킹 I/O와 async/await 코루틴 실행 원리를 살펴봅니다.

12주차. 비동기 프로그래밍 (2) - 고성능 크롤러 제작

비동기 HTTP 클라이언트인 aiohttp를 연계하여 대용량 비정형 데이터를 초고속으로 긁어모으는 비동기 수집기를 구현합니다.

13주차. 게임 개발 원리 - 실시간 상호작용 구현

시간 프레임에 연산 주기를 조율하는 게임 루프(Game Loop), 충돌 판정 등 파이썬 기반 게임 물리 엔진의 기초를 익힙니다.

14주차. 최종 프로젝트 기획 - 나만의 서비스 설계

앞서 배운 기술적 도구들을 융합해 실생활 문제를 해결하는 소프트웨어 기획서 및 UML 설계도를 그립니다.

15주차. 최종 프로젝트 구현 - 코딩과 디버깅

계획한 모듈 설계대로 GUI, DB, 비동기 기능 등을 통합 개발하고 오동작 버그들을 추적 및 개선합니다.

16주차. 최종 마무리 및 마스터 인증

완성된 소프트웨어의 실기 작동 및 코드를 발표하며 파이썬 마스터 코스를 최종 수료합니다.
