1학기. 파이썬 기초 및 컴퓨터 과학 원리 🐍

프로그래밍 기초부터 컴퓨터 과학의 핵심 원리까지 — 도로시 탐험대와 함께 떠나는 16주간의 파이썬 대탐험 도로시 탐험대 마스터 그룹

파이썬 문법의 완전한 마스터와 프로그래밍적 사고(Computational Thinking)의 확립을 목표로 합니다.

👨‍🏫 이호진 교수님 AI & CS 멘토 | 1학기 학습 목표와 방향
단순히 문법을 외우는 코딩이 아닌, 메모리에서 변수가 어떻게 참조되고 인터프리터가 코드를 어떻게 해석하는지 컴퓨터 과학의 본질적 원리를 함께 깨우쳐 나갈 것입니다.
👧 도로시 (Dorothy) 주니어 메이커 | 신나는 코딩 탐험 준비 완료!
토토, 지니! 우리 함께 1학기 동안 매주 하나씩 차근차근 배워서 멋진 소프트웨어를 완성해보자!

📅 주차별 학습 목차

01주차. 파이썬과 개발 환경

인터프리터 vs 컴파일러의 차이를 이해하고, 가상환경(venv)을 구축하여 첫 파이썬 코드를 실행합니다.

  • 1세션: 파이썬 소개 및 인터프리터 원리
  • 2세션: 파이썬 설치 및 개발 환경 구축
  • 3세션: 파이썬 기초 문법과 문제 해결

02주차. 변수와 메모리

변수 선언 시 메모리에서 참조(Reference)가 작동하는 원리와 동적 타이핑에 대해 심도 있게 배웁니다.

  • 1세션: 변수의 개념과 값 할당
  • 2세션: CPython의 동적 타입과 메모리 구조
  • 3세션: 다중 대입(Swap)과 메모리 라이프사이클 & PEP 8 작명 가이드

03주차. 기본 자료형 (1) - 숫자와 문자열

정수, 실수, 문자열의 내부 기계적 표현과 유니코드 및 인코딩에 대해 학습합니다.

04주차. 기본 자료형 (2) - 컨테이너 자료형

리스트, 튜플, 셋, 딕셔너리의 특징과 해시 테이블(Hash Table)의 원리를 살펴봅니다.

05주차. 제어문 (1) - 조건문과 논리 연산

코드 실행 흐름을 제어하는 조건문과 단락 평가(Short-circuit evaluation) 메커니즘을 배웁니다.

06주차. 제어문 (2) - 반복문과 이터레이터

반복문(for, while)의 다양한 쓰임새와 이터레이터(Iterator) 및 제너레이터(Generator)의 기초 원리를 파헤칩니다.

07주차. 함수 기초 - 모듈화와 매개변수의 원리

파이썬의 매개변수 전달 방식인 Call by Object Reference와 스코프(LEGB 규칙)를 이해합니다.

08주차. 1학기 중간고사

1~7주차에서 학습한 이론적 개념과 간단한 실습 과제를 테스트합니다.

09주차. 함수 심화 - 고급 매개변수와 함수형 프로그래밍

파이썬의 일급 객체(First-class Object) 특성을 활용한 람다(Lambda), 고차 함수 및 데코레이터 기초를 학습합니다.

10주차. 모듈과 패키지 - 대규모 프로젝트 개발의 기초

표준 라이브러리 활용법과 sys.path 모듈 검색 경로를 다루어 큰 단위로 프로그램을 구성하는 방법을 학습합니다.

11주차. 파일 입출력 - 데이터 영구 보관과 파이썬 데이터 분석 실습

컨텍스트 매니저(with문)의 원리를 이해하고, 데이터 분석 라이브러리(Matplotlib 등)와 연계해 봅니다.

12주차. 예외 처리 - 버그와 충돌 방어막 세우기

코드 런타임 오류에 대처하는 예외 계층 구조와 사용자 정의 예외 처리 전략을 수립합니다.

13주차. 알고리즘 기초 (1) - 시간 복잡도와 Big-O

소프트웨어 효율을 정량화하여 측정하는 시간 복잡도와 Big-O 표기법의 개념을 배웁니다.

14주차. 알고리즘 기초 (2) - 정렬과 탐색

기본 정렬 알고리즘의 동작 방식과 이진 탐색 등 탐색 구조를 비교 분석합니다.

15주차. 1학기 종합 프로젝트 - CLI 프로그램 제작

1학기 동안 익힌 지식을 총동원하여 터미널 환경에서 실행되는 CLI 기반 프로그램을 완성합니다.

16주차. 1학기 기말고사 및 마무리

전체 과정에 대한 종합 평가를 진행하고 프로젝트 시연 및 코드를 리뷰합니다.
