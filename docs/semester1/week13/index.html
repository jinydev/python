13주차: 알고리즘 기초 (1) - 시간 복잡도와 Big-O ⏱️

이제 우리는 코드를 ‘작동하게’ 만드는 단계를 넘어, ‘효율적으로’ 만드는 단계를 배울 것입니다. 똑같은 결과가 나오는 코드라도, 어떤 코드는 0.1초 만에 끝나고 어떤 코드는 1시간이 걸릴 수 있습니다. 이를 측정하는 기준이 바로 시간 복잡도입니다.

1. 시간 복잡도 (Time Complexity)

시간 복잡도는 알고리즘이 실행될 때 입력 값의 크기($n$)에 따라 연산 횟수가 어떻게 증가하는가를 나타낸 것입니다. 실제 시간을 초 단위로 재는 것이 아니라, 연산 횟수를 세는 것입니다.

1.1 Big-O 표기법

가장 최악의 경우를 가정하여 표기하는 방식입니다. (Worst-case scenario)

표기법 명칭 특징 예시
$O(1)$ 상수 시간 입력 크기와 상관없이 항상 일정 리스트의 인덱스로 값 찾기
$O(\log n)$ 로그 시간 입력이 커질수록 증가 폭이 줄어듦 이진 탐색 (Binary Search)
$O(n)$ 선형 시간 입력 크기에 비례하여 증가 리스트 전체를 한 번 훑기
$O(n \log n)$ 선형-로그 시간 효율적인 정렬 알고리즘의 속도 퀵 정렬, 병합 정렬
$O(n^2)$ 제곱 시간 입력 크기의 제곱으로 증가 (매우 느림) 이중 for문 (버블 정렬)

2. 왜 Big-O를 알아야 할까요?

데이터가 10개일 때는 $O(n)$이나 $O(n^2)$이나 차이가 거의 없습니다. 하지만 데이터가 100만 개가 되면 이야기가 달라집니다.

  • $O(n)$: 100만 번 연산 $\rightarrow$ 순식간에 종료
  • $O(n^2)$: 1조 번 연산 $\rightarrow$ 컴퓨터가 며칠 동안 돌아가야 함

따라서 효율적인 알고리즘을 선택하는 것은 대규모 데이터를 다루는 현대 프로그래밍에서 필수적입니다.

3. 간단한 시간 복잡도 분석 연습

# 예제 1: O(1)
def print_first(lst):
    print(lst[0])

# 예제 2: O(n)
def print_all(lst):
    for x in lst:
        print(x)

# 예제 3: O(n^2)
def print_pairs(lst):
    for x in lst:
        for y in lst:
            print(x, y)

🔍 Deep Dive: 공간 복잡도(Space Complexity)와 메모리 관리

시간만 아끼는 것이 전부는 아닙니다. 알고리즘이 실행되는 동안 얼마나 많은 메모리를 사용하는가를 나타내는 공간 복잡도(Space Complexity) 역시 중요합니다.

  • $O(1)$ 공간 복잡도: 고정된 몇 개의 변수만 사용하는 알고리즘. (예: 두 변수의 스왑, 단순 카운트 변수)
  • $O(n)$ 공간 복잡도: 입력 크기에 비례하여 새로운 메모리 공간(배열, 리스트 등)을 확보하는 알고리즘. (예: 입력 배열을 복사하여 새 배열을 생성하는 작업)

✍️ 이번 주 연습 문제

문제 1. 다음 코드의 시간 복잡도를 Big-O 표기법으로 나타내고 그 이유를 설명해 보세요.

def find_sum(n):
    total = 0
    for i in range(n):
        total += i
    return total

문제 2. (심화) $O(n)$ 알고리즘과 $O(n^2)$ 알고리즘의 차이를 실제 연산 횟수로 비교해 보세요. (입력 값 $n$이 10일 때와 1000일 때 각각 몇 번의 연산이 일어나는지 계산해 보세요.)

문제 3. 우리 주변의 일상생활에서 $O(1)$에 해당하는 사례와 $O(n)$에 해당하는 사례를 하나씩 찾아 적어보세요. (예: 사전에서 단어 찾기 vs 책의 모든 페이지 읽기)

☕ Java vs C++ vs Python 스나이퍼 비교

리스트(배열) 동적 크기 조절 메커니즘과 복잡도

  • Java (ArrayList): 배열 공간이 꽉 차면 기존 용량의 약 1.5배 크기의 새 배열을 힙 메모리에 생성하고 기존 데이터를 복사합니다. 이때 복사 작업 자체는 $O(n)$이지만, 평균적으로는 분할 상환(Amortized) $O(1)$ 시간 복잡도를 가집니다.
  • C++ (std::vector): 컴파일러마다 다르지만 대개 용량이 부족하면 기존의 2배 크기로 새로운 연속 메모리 영역을 선점하여 복사합니다. 역시 분할 상환 $O(1)$ 성능을 보장합니다.
  • Python (list): CPython 엔진 내부에서 동적 배열 크기 확장 패턴은 과할당 비율을 특유의 수식(Growth Factor: new_allocated = (size_t)newsize + (newsize >> 3) + (newsize < 9 ? 3 : 6))에 따라 유동적으로 관리하여 메모리 파편화를 예방하고 최상의 평균 $O(1)$ 추가 성능을 냅니다.

67 줄서기와 쌓기의 미학: 스택, 큐, deque, heapq

컴퓨터가 수많은 일들을 빠르고 에러 없이 처리할 때는, 메모리에 들어오는 데이터를 ‘어떤 규칙으로 줄 세울 것인지’가 엄청나게 중요합니다. 파이썬이 제공하는 특급 데이터 줄서기 도구들을 알아봅시다!

1. 스택(Stack)과 큐(Queue)의 기초

  • 스택(Stack): 프링글스 감자칩 통을 상상해 보세요! 밑이 꽉 막힌 좁은 통 모양이라, 제일 마지막에 넣은 데이터가 제일 먼저 나옵니다. (LIFO: Last-In, First-Out)
  • 큐(Queue): 놀이공원에 줄 서는 것을 생각하면 됩니다. 통의 위아래가 뚫려있어, 가장 먼저 줄을 선 데이터가 가장 먼저 놀이기구를 타고 나갑니다. (FIFO: First-In, First-Out)

파이썬의 기본 리스트(.append(), .pop())를 이용해 대충 흉내 낼 수도 있지만, 파이썬은 진짜 실무 프로들이 쓰는 멋진 툴을 따로 챙겨뒀습니다.

2. 양쪽이 뻥 뚫린 고속도로 파이프: collections.deque

양쪽으로 자유롭게 들어오고 나갈 수 있는 마법의 파이프 큐를 Deque(데크)라고 부릅니다. 일반 리스트에서 맨 앞의 데이터를 빼거나 넣는 작업(.insert(0, X))은 엄청나게 느리지만, deque는 아주 빛의 속도로 앞뒤 양방향 어디서든 데이터를 넣고 뺄 수 있습니다! 보통 큐를 구현할 땐 무조건 이것을 씁니다.

from collections import deque

# 양쪽이 뚫린 파이프(데크) 만들기
pipe = deque([2, 3])

pipe.append(4)     # 오른쪽(보통)으로 밀어 넣기
print(pipe)        # deque([2, 3, 4])

pipe.appendleft(1) # 특별 기능! 왼쪽(맨 앞)으로 강제 밀어 넣기!
print(pipe)        # deque([1, 2, 3, 4])

pipe.popleft()     # 왼쪽(맨 앞)에서 가장 먼저 서 있는 놈 빼기!
print(pipe)        # deque([2, 3, 4])

이 녀석은 pipe.rotate(1) 기능도 있어서 마치 회전초밥 기계나 컨베이어 벨트처럼 데이터를 뱅글뱅글 섞어 돌릴 수도 있답니다!

3. 실전 정밀 줄서기 통제: queue 모듈

deque가 속도에 미친 녀석이라면, 내장 queue 모듈은 말 그대로 대기열을 세우는 깐깐한 전문가 도구 상자입니다. 특히, 여러 작업이 동시에 돌아가는 환경에서 수용 인원(용량)이 꽉 차거나 텅텅 비었을 때를 완벽하게 통제해 줍니다.

import queue

# 최대 2명만 설 수 있는 깐깐한 줄(Queue)을 만듭니다!
q = queue.Queue(maxsize=2)

q.put(1) # 대기열 줄 서기!
q.put(2) # 줄 서기!

print("꽉 찼나요?", q.full())  # True
print("몇 명 있나요?", q.size()) # 2

# 맨 앞사람 빼기
print(q.get()) # 1번 데이터가 볼일을 보러 나감 (빈자리가 생김)

4. 가장 작은 녀석만 쏙쏙 편애하기: heapq 모듈

만약 커다란 상자 안에 무작위로 여러 숫자가 마구잡이로 섞여 있는데, 계속해서 “상자 안에 있는 것 중 가장 작은 놈 당장 나와!”라고 지속적으로 닦달해야 한다면 어떨까요? 뽑을 때마다 리스트를 전체 정렬(sort())하는 건 무식하고 느린 행동입니다.

heapq (힙 큐) 모듈은 이럴 때 쓰는 전용 정렬 마법 상자입니다.

import heapq

# 마구 섞인 숫자들의 모임
box = [20, 10, 30, 50, 40]

# 1. 힙 정렬 구조로 변신! (파이썬이 보이지 않는 마법의 트리 구도로 재배치합니다)
heapq.heapify(box)
print(box) 
# [10, 20, 30, 50, 40] -> 무조건 제일 앞에 '가장 작은 값'이 언제나 튀어나옵니다!

# 2. 제일 작은 놈 나와! (heappop)
print(heapq.heappop(box)) # 10이 빠져나옴! (빠져나오면 2등이 1등 자리로 대기 탐)
print(heapq.heappop(box)) # 20이 빠져나옴!

# 3. 새로운 놈 추가! (heappush)
# 박스에 15를 던져 넣으면, 알아서 자기 자리를 찾아 들어가 대기합니다.
heapq.heappush(box, 15) 
print(heapq.heappop(box)) # 15가 스멀스멀 1등으로 빠져나옴!

숫자를 막 던져 넣어도, 늘 가장 우선순위가 높은(값이 작은) 데이터가 항상 출구(인덱스 0) 앞에 즉각 대기하도록 유지해주는 초강력 우선순위 정렬 상자랍니다!

2. 줄서기와 쌓기: stack, queue, heapq

컴퓨터가 수많은 일들을 처리할 때는, 데이터를 어떻게 줄 세울 것인지가 엄청나게 중요합니다. 파이썬이 제공하는 특급 줄서기 도구들을 알아볼까요?

2.1 스택(Stack)과 큐(Queue)의 기초

  • 스택(Stack): 프링글스 감자칩 통을 상상해 보세요! 밑이 꽉 막힌 통에 데이터를 넣기 때문에, 제일 나중에 넣은 데이터가 제일 먼저 나옵니다. (LIFO: Last In First Out)
  • 큐(Queue): 놀이공원에 줄 서는 것을 생각하면 됩니다. 가장 먼저 줄을 선 데이터가 가장 먼저 놀이기구를 탑니다. (FIFO: First In First Out)

파이썬의 기본 리스트(.append(), .pop())를 이용해 대충 흉내 낼 수도 있지만, 파이썬은 진짜 프로들이 쓰는 멋진 툴을 따로 준비해 뒀습니다.

2.2 실전 줄서기: queue 모듈

queue 모듈은 말 그대로 줄을 세우는 전문 도구 상자입니다. 용량이 꽉 차거나 텅텅 비었을 때를 완벽하게 통제해 줍니다.

import queue

# 최대 2명만 설 수 있는 줄(Queue)을 만듭니다!
q = queue.Queue(maxsize=2)

q.put(1) # 줄 서기!
q.put(2) # 줄 서기!

print(q.full())  # 꽉 찼나요? -> True
print(q.qsize()) # 몇 명 있나요? -> 2

# 맨 앞사람 빼기
print(q.get()) # 1번이 놀이기구 타러 나감

2.3 양쪽 뚫린 마법 터널: collections.deque

양쪽으로 들어오고 나갈 수 있는 마법의 파이프 큐를 Deque(데크)라고 부릅니다. 리스트의 .insert(0, X)는 매우 느리지만, deque는 아주 빛의 속도로 앞뒤 어디서든 데이터를 넣고 뺄 수 있습니다!

from collections import deque

# 양쪽 뚫린 파이프(데크) 만들기
pipe = deque([2, 3])

pipe.append(4)     # 오른쪽(보통)으로 밀어 넣기
print(pipe)        # deque([2, 3, 4])

pipe.appendleft(1) # 특별히 왼쪽(앞)으로 밀어 넣기!
print(pipe)        # deque([1, 2, 3, 4])

pipe.popleft()     # 왼쪽에서 빼기!
print(pipe)        # deque([2, 3, 4])

이 녀석은 rotate를 써서 마치 회전초밥 기계처럼 데이터를 뱅글뱅글 위상을 섞어 돌릴 수도 있답니다!

2.4 가장 작은 녀석만 쏙쏙: heapq 모듈

만약 상자 안에 무작위로 여러 숫자가 막 섞여 있는데, 계속해서 “상자 안에 있는 것 중 가장 작은 놈 당장 나와!”라고 명령해야 한다면 어떨까요? heapq(힙 큐) 모듈은 이럴 때 쓰는 전용 도구입니다.

import heapq

# 섞인 숫자들의 모임
box = [20, 10, 30, 50, 40]

# 1. 힙 정렬 명령! (파이썬이 마법의 구도로 재배치합니다)
heapq.heapify(box)
print(box) # [10, 20, 30, 50, 40] -> 제일 앞에 가장 작은 값이 튀어나옵니다!

# 2. 제일 작은 놈 나와! (heappop)
print(heapq.heappop(box)) # 10이 빠져나옴!
print(heapq.heappop(box)) # 20이 빠져나옴!

그 외에도 heappush로 새로운 숫자를 상자에 던져 넣으면, 알아서 자리를 찾아 쏙쏙 들어가고 가장 작은 값을 언제나 1번으로 대기시켜주는 초강력 정렬 마법 상자랍니다!
