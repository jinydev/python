1주차 2세션: 파이썬 설치 및 개발 환경 구축 🛠️

파이썬 설치 가이드

운영체제별 파이썬 설치 가이드 (Windows, macOS, Linux)

파이썬을 제대로 사용하기 위해 자신의 컴퓨터 환경에 맞는 파이썬을 설치해야 합니다.

  • Windows 설치 요령:
    • 공식 웹사이트(python.org)에서 최신 안정화 버전(Stable Release)을 다운로드합니다.
    • 설치 시 “Add Python to PATH” 옵션을 반드시 체크해야 합니다! (체크하지 않으면 명령 프롬프트에서 파이썬 명령어를 인식하지 못합니다.)
  • macOS 설치 요령:
    • macOS는 기본적으로 시스템 파이썬이 설치되어 있으나 최신 개발용 버전으로 교체하기 위해 공식 웹사이트의 .pkg 파일 혹은 Homebrew 패키지 관리자(brew install python)를 통해 설치하는 것을 추천합니다.

파이썬 설치 경로와 환경 변수(PATH)의 비밀

컴퓨터가 임의의 실행 경로에서 python이라는 명령어를 입력받았을 때, 컴퓨터는 하드디스크 전체를 검색하는 것이 아니라 환경 변수(PATH)에 사전 등록된 폴더들만 탐색합니다. 환경 변수 등록이 되지 않으면 명령어 탐색이 실패하여 command not found 오류가 출력됩니다.

파이썬 설치 확인 및 개발 도구

터미널에서 파이썬 설치 확인하기

설치가 완료되었다면 터미널(Command Prompt 또는 macOS Terminal)을 열고 파이썬이 정상 설치되었는지 버전을 확인합니다.

python --version
# 또는
python3 --version

대화형 모드(REPL) 실행해보기

터미널에 python 또는 python3를 입력하고 Enter를 누르면 >>> 프롬프트가 표시되는 대화형 모드(REPL)에 진입합니다.

>>> 1 + 2
3
>>> print("Hello World")
Hello World
>>> exit()  # 종료할 때

REPL은 Read(읽고), Evaluate(평가하고), Print(출력하고), Loop(반복한다)의 약자로, 파이썬 한 줄의 동작을 바로 테스트하기 최적인 장난감 상자입니다.

코드 에디터 선택: VS Code 설치 및 셋업

실무에서는 긴 소스코드를 작성하기 위해 REPL 대신 전용 텍스트 에디터인 VS Code (Visual Studio Code)를 사용합니다.

  1. VS Code 공식 홈페이지에서 OS 버전에 맞는 설치 프로그램을 다운로드합니다.
  2. 좌측 메뉴의 Extensions(확장 프로그램) 탭에서 “Python” (Microsoft 공식) 확장팩을 검색하여 인스톨합니다.
  3. 이 확장팩은 자동 완성(IntelliSense), 구문 에러 검출, 코드 서식 정리(Linting) 기능을 제공하여 코딩 속도를 비약적으로 늘려줍니다.

가상환경(Virtual Environment) 구축

가상환경이 필요한 이유

만약 내가 여러 개의 파이썬 프로그램 프로젝트를 만들고 있다면, 각각의 프로젝트마다 요구하는 모듈의 버전이 다를 수 있습니다. 컴퓨터 전체에 모듈을 한꺼번에 설치하면 버전 충돌이 발생해 기존 프로그램이 오작동할 수 있습니다. 따라서 프로젝트마다 독립된 방을 격리하여 관리해 주는 것이 바로 가상환경입니다.

가상환경 생성 및 활성화 방법 (venv)

파이썬에는 기본 내장된 가상환경 모듈 venv가 제공됩니다. 터미널에서 내 프로젝트 폴더로 이동한 뒤 다음 명령어를 입력합니다.

1. 가상환경 생성 (.venv라는 이름으로 격리 폴더 생성):

python -m venv .venv

2. 가상환경 활성화:

  • macOS/Linux: 
    source .venv/bin/activate
  • Windows: 
    .venv\Scripts\activate

    활성화가 완료되면 터미널 프롬프트 앞에 (.venv)라는 꼬리표가 붙어, 현재 가속환경 방에 잘 들어와 있음을 증명합니다.

첫 파이썬 프로그램 Hello World!

VS Code에서 첫 파이썬 파일 생성

이제 실제 파일로 저장해 실행해 봅시다.

  1. VS Code에서 hello.py라는 새 파일을 생성합니다.
  2. 파이썬 파일 확장자는 반드시 .py이어야 파이썬 인터프리터가 읽을 수 있습니다.

print() 함수로 세상에 인사하기 (Hello World)

생성한 파일에 다음과 같이 소스코드를 적어 넣습니다.

# 이것은 주석입니다. 컴퓨터는 무시하고 사람만 읽어요.
print("Hello, Python World!")
print("나는 이제 파이썬 마스터가 될 거야! 🚀")

저장(Ctrl + S / Cmd + S)한 후, VS Code 터미널에서 실행 명령을 입력합니다:

python hello.py

파이썬 주석의 첫걸음

파이썬에서 # 기호로 시작하는 줄은 컴퓨터가 전혀 해석하지 않는 주석(Comment) 영역입니다. 주석은 코드에 대한 상세한 설명, 참고사항, 혹은 특정 코드 줄을 일시적으로 비활성화(Comment-out)할 때 유용하게 활용됩니다.

SyntaxError 디버깅 체험

코드를 적다가 마감 기호인 큰따옴표나 괄호를 빼먹는 등의 철자/기호 오타를 저지르면 파이썬은 실행 시작 즉시 문법 에러(SyntaxError)를 던지며 중단됩니다.

print("Hello World  # 에러 유발 코드

에러가 발생하면 파이썬이 던지는 에러 메시지(파일명, 에러가 발생한 라인 번호, 에러의 상세 원인)를 꼼꼼히 읽어 오타를 교정해 나가는 디버깅 연습이 최고의 코딩 학습입니다.

2세션 마무리

2세션 코딩 영단어

  • Setup: 설정, 설치. (프로그래밍 도구를 사용할 수 있게 환경을 마련하는 작업입니다.)
  • Virtual: 가상의. (컴퓨터 메모리 딴에 논리적으로 격리된 가상 공간을 에뮬레이션할 때 자주 쓰입니다.)
  • Syntax: 구문, 문법. (구문 구조의 정합성이 파이썬 표준에 어긋날 때 SyntaxError가 발생합니다.)
