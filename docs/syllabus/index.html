🐍 파이썬 마스터 클래스: 기초부터 심화까지 (Syllabus)

본 강좌는 중학생의 눈높이에서 시작하여, 컴퓨터 공학 전공 대학 2학년 수준의 프로그래밍 역량을 갖추는 것을 목표로 합니다. 단순히 코드를 짜는 법이 아니라, “컴퓨터가 어떻게 생각하는가”를 함께 배웁니다.

📅 1학기: 파이썬 기초 및 컴퓨터 과학 원리

목표: 파이썬 문법 마스터 및 프로그래밍적 사고(Computational Thinking) 확립

주차 주제 핵심 내용 (심도) 비고
1주 파이썬과 개발 환경 인터프리터 vs 컴파일러, 가상환경(venv)의 필요성 설치 및 설정
2주 변수와 메모리 동적 타이핑, 메모리 주소와 참조(Reference), 가비지 컬렉션 기초 ⚠️ 심화
3주 기본 자료형 (1) 정수, 실수, 문자열의 내부 표현, 유니코드와 인코딩  
4주 기본 자료형 (2) 리스트, 튜플, 셋, 딕셔너리 (해시 테이블의 원리) ⚠️ 심화
5주 제어문 (1) 조건문과 논리 연산, 단락 평가(Short-circuit evaluation)  
6주 제어문 (2) 반복문(for, while), 이터레이터(Iterator)와 제너레이터(Generator) 기초 ⚠️ 심화
7주 함수 기초 매개변수 전달 방식 (Call by Object Reference), 스코프(LEGB 규칙) ⚠️ 심화
8주 중간고사 1~7주차 이론 및 실습 평가  
9주 함수 심화 일급 객체(First-class Object), 람다(Lambda), 고차 함수 ⚠️ 심화
10주 모듈과 패키지 sys.path, 모듈 검색 경로, 표준 라이브러리 활용  
11주 파일 입출력 스트림(Stream) 개념, 컨텍스트 매니저(with문)의 원리  
12주 예외 처리 예외 계층 구조, 사용자 정의 예외, 에러 핸들링 전략  
13주 알고리즘 기초 (1) 시간 복잡도와 공간 복잡도 (Big-O 표기법) ⚠️ 심화
14주 알고리즘 기초 (2) 정렬(Sorting)과 탐색(Searching) 알고리즘  
15주 종합 프로젝트 CLI 기반의 실용적인 프로그램 설계 및 구현  
16주 기말고사 전체 범위 평가 및 프로젝트 발표  

🧠 2학기: 객체지향 프로그래밍(OOP) 및 소프트웨어 설계

목표: 유지보수가 가능한 구조적 코드 설계 능력 배양

주차 주제 핵심 내용 (심도) 비고
1주 OOP 패러다임 절차지향 vs 객체지향, 클래스와 인스턴스의 개념  
2주 클래스 기초 생성자(__init__), 속성과 메서드, self의 정체  
3주 캡슐화와 정보 은닉 접근 제어자(Private/Protected), 프로퍼티(@property)  
4주 상속과 다형성 상속 구조, 메서드 오버라이딩, super()의 작동 원리  
5주 다중 상속과 MRO MRO (Method Resolution Order), C3 선형화 알고리즘 ⚠️ 심화
6주 추상 클래스와 인터페이스 abc 모듈, 추상 메서드, 인터페이스 설계 원칙 ⚠️ 심화
7주 매직 메서드 (Dunder) __str__, __repr__, __len__, __getitem__ 등 ⚠️ 심화
8주 중간고사 OOP 설계 및 구현 능력 평가  
9주 디자인 패턴 (1) 싱글톤(Singleton), 팩토리(Factory) 패턴 ⚠️ 심화
10주 디자인 패턴 (2) 전략(Strategy), 옵저버(Observer) 패턴 ⚠️ 심화
11주 패키지 구조 설계 __init__.py의 역할, 절대 경로 vs 상대 경로 임포트  
12주 타입 힌팅 (Type Hinting) typing 모듈, 정적 분석 도구(mypy) 활용  
13주 유닛 테스트 unittest 및 pytest 프레임워크, TDD 기초  
14주 배포 및 패키징 (1) pyproject.toml, setuptools, Wheel 포맷  
15주 배포 및 패키징 (2) PyPI 배포 과정 및 버전 관리 (Semantic Versioning)  
16주 기말고사 라이브러리 수준의 패키지 제작 및 배포 프로젝트  

🖥️ 3학기: 응용 개발 및 시스템 프로그래밍

목표: 실제 서비스 구현 및 고급 파이썬 기능 정복

주차 주제 핵심 내용 (심도) 비고
1주 GUI 개발 기초 Tkinter/PyQt 구조, 이벤트 루프(Event Loop)의 원리  
2주 GUI 심화 커스텀 위젯 제작, 레이아웃 매니저 최적화  
3주 네트워크 프로그래밍 (1) TCP/UDP 소켓 통신, 클라이언트-서버 모델 ⚠️ 심화
4주 네트워크 프로그래밍 (2) HTTP 프로토콜, requests 라이브러리, REST API  
5주 데이터 처리 (JSON/XML) 직렬화(Serialization)와 역직렬화, 파싱 전략  
6주 데이터베이스 기초 SQLite3, SQL 쿼리 최적화, 관계형 DB 설계  
7주 ORM (Object Relational Mapping) SQLAlchemy 기초, 객체와 DB 테이블의 매핑 ⚠️ 심화
8주 중간고사 GUI 및 DB 연동 응용 프로그램 구현 평가  
9주 멀티스레딩 (Threading) GIL (Global Interpreter Lock)의 이해와 한계 ⚠️ 심화
10주 멀티프로세싱 (Multiprocessing) 프로세스 간 통신(IPC), 병렬 처리 최적화 ⚠️ 심화
11주 비동기 프로그래밍 (1) asyncio, async/await, 코루틴(Coroutine)의 원리 ⚠️ 심화
12주 비동기 프로그래밍 (2) 비동기 I/O, aiohttp를 이용한 고성능 크롤러 ⚠️ 심화
13주 게임 개발 원리 게임 루프, 델타 타임, 간단한 물리 엔진 구현  
14주 최종 프로젝트 기획 요구사항 분석, UML 설계, 마일스톤 설정  
15주 최종 프로젝트 구현 기능 구현 및 버그 수정, 코드 리뷰  
16주 기말고사 최종 프로젝트 발표 및 시연  

💡 학습 가이드

  • 교과서 스타일: 모든 강의는 개념 설명 $\rightarrow$ 작동 원리(Deep Dive) $\rightarrow$ 코드 예제 $\rightarrow$ 연습 문제 순으로 구성됩니다.
  • 심화 표시(⚠️): 이 부분은 대학 전공 수준의 내용입니다. 중학생 학습자가 어려워할 수 있으나, 원리를 이해하면 프로그래밍 실력이 비약적으로 상승하는 구간입니다.
  • 실습 중심: 이론 학습 후 반드시 해당 주차의 실습 과제를 완료해야 다음 단계로 넘어갑니다.
